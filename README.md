An anime-style desktop companion for Codex. The current character is Longmei (龙妹). The app runs alongside Codex without modifying its application bundle or `app.asar`. It is an independent project, not an official OpenAI product or plugin.

The app's Chinese name is **桌边小崽** (“Desk-side Cub”). **Electron is the only maintained desktop host.** On November 19, 2026 the project retired the old Swift/AppKit application, its installer, login service and control scripts. The macOS-specific helpers used by Electron remain. The maintained workspace plays pets through Electron video; the old Qt player is only for historical comparison and is not a runtime dependency. This change does not migrate old profiles or validate a new installer.
