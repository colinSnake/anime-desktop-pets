## 文档约定

1. 根目录 `README.md` 用英文，`README.zh.md` 用中文；其余自维护说明以中文为主。
2. 命令、路径、配置字段、模型标识保持原样，不把机器标识翻译成中文。
3. “已实现”只说明存在实现；“已验证”必须指明检查方式与实际覆盖范围。
4. 尚未实现的共享 packages、Studio、现有 Codex 任务联动和主题不能写成现有能力；
   完整动作由上游辅助应用提供，不能宣称原生重写或双向任务适配已经完成。
5. 验证记录只追加或修正真实事实；不要因文档更新而声称重新测试了全部功能。
6. 原始许可证与上游来源声明保留原文，其权利与测试声明不代表本项目的授权或测试结果。
7. 涉及运行方式、接口或功能状态变更时，同步更新两个根 README 和相关专题文档。
8. 不保存 API key、账号、聊天内容或未经脱敏的运行输出。
9. 根 README 只保留项目定位、能力边界、最短入门步骤和文档入口；算法参数、协议、版本更新与测试明细放入专题文档和验证记录，不逐轮追加到 README。
