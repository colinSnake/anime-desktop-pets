## 命名方向

项目是一个包含多个 AI 助手角色的动漫风格桌宠系列。白龙只是其中一个角色，不应让 `Dragon` 成为整个项目名称的主题；`AI` 也不是需要放进名称的产品卖点。角色和平台关键词可放在 GitHub Description、Topics 和 README 正文中，便于搜索并说明对应关系。

项目展示名：**Anime Desktop Pets**

推荐的 GitHub 仓库名：`anime-desktop-pets`

推荐理由：名称简短直白，直接说明动漫桌宠这一产品类别；使用复数可容纳不同助手对应的多个角色，不绑定某一种生物或平台。

README 标题与项目展示名已统一。当前产物为 `build/桌边小崽.app`，确认安装后的目标为 `~/Applications/桌边小崽.app`；仓库目录与远端仓库使用 `anime-desktop-pets`。
