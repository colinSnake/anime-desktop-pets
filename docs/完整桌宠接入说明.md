# 完整动画桌宠接入说明

更新日期：2026-11-19。

## 1. 当前入口

常规 macOS 工作区通过 [Electron 视频播放器](本地开发与使用指南.md#桌宠默认视频播放器)播放固定 v0.5.1 WebM 归档中的 35 段原片。先执行 `pnpm run dev:desktop --check` 可只离线检查；`pnpm run dev:desktop` 不会自动开宠、复用或停止旧实例。当前不是 Windows/Linux 播放器或独立发行包。下文 `v0.4.1-mac.3` 和 prepared 构建仅用于历史 Qt 对照，不是工作区的依赖。

## 2. 获取与完整性检查

固定来源：`chihayaanon210-spec/bailong-desktop-pet-macos` 的 `v0.4.1-mac.3`，
不是动态选择“最新版”。本机为 Apple Silicon，仅适配此 arm64 发布包。

| 项目 | 固定值 |
| --- | --- |
| 发布包 | `BailongPet-Mac-0.4.1-mac.3-arm64.zip` |
| 大小 | 734,924,315 字节，约 701 MiB |
| SHA-256 | `c7df79f2b7e3fb90736e3ed8fb21be2fd6f8fe2d3982c494f0ee1c68004ccdb2` |
| Bundle ID | `local.bailongpet.macos` |
| 构建号 | `3` |

在仓库根目录运行：

```bash
python3 scripts/prepare-full-pet.py fetch
python3 scripts/prepare-full-pet.py check
```

下载仅访问 GitHub 官方发布地址，使用有界并发 Range 与分块续传，不运行归档中的程序。
完整归档先校验固定大小和 SHA-256，再检查路径、链接与解压大小，然后用 `ditto` 保留 App 结构。
继续验证签名、可执行文件、25 动作和实际播放文件；不删除隔离属性、不改签名、不绕过安全提示。

本地内容均被 Git 忽略：

```text
.local/
  downloads/                    # 原始 ZIP、未完成下载块与下载日志
  pets/bailong-0.4.1-mac.3/
    BailongPet.app               # 未修改的完整上游应用
    source.json                 # 固定来源与哈希，不包含密钥
  reports/                      # 离线自检结果
```

网络中断后重跑获取命令可复用完整下载块。哈希、版本或素材检查失败时停止，
不会静默使用不完整 App，也不会为了显示角色自动回退静态图。

## 3. 历史 prepared 播放器

仅重跑旧 Qt 对照时，按[增强层构建指南](桌宠增强与性能构建.md)准备隔离环境、源码和素材。普通 Electron 启动不读取旧 `PET_PLAYER_SOURCE` 或 `PET_PLAYER_ASSETS`，也不会回退 Qt。旧 Swift 宿主及其配置、静态降级打包和控制命令已经退役。

## 5. 离线解码与交互自检

```bash
python3 scripts/prepare-full-pet.py self-test
```

这会执行固定版本上游程序的 `--self-test`，不是正常桌宠启动：

- 设置 `QT_QPA_PLATFORM=offscreen`，不显示真实桌面窗口。
- 使用临时 HOME、独立报告目录和不可用的 Codex 命令。
- 用系统 `sandbox-exec` 禁止网络；不执行真实额度查询或聊天任务。
- 验证动作解码、模拟拖拽落地、菜单和模拟对话 UI 等上游离线检查。
- 报告和离屏预览位于 `.local/reports/`；它不是实际桌面截图或真实聊天验收。

如果没有隔离工具，脚本停止，而不是退回真实账号/网络环境运行。

### 可选：逐帧审计与小型 GIF

如果本机 Python 已安装 Pillow，可进一步运行：

```bash
python3 scripts/preview-full-pet.py --audit-all-frames
```

该步骤真正解码每个主动作的每一帧，统计不同画面数量，并输出小型待机/互动 GIF 到
`.local/previews/`。这是上游素材的离线预览，不是原创海报，也不是已经完成桌面验收的录像。
Pillow 仅供这个可选开发工具使用，完整桌宠 App 已自带运行依赖。

## 6. 桌面与功能验收

只在用户明确选择时启动真实开发桌面。新架构已接逐实例启停、任务动画与本机语音播报；原版／静态打包模式未迁，额度卡片只通过合成验收。核对[迁移状态](macOS迁移状态汇报.md)和[真实桌面验收](测试与人工验收.md)，不要把离线解码或 helper 自检当成现有桌面手感或真实服务通过。
