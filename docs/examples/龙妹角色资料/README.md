# 龙妹角色资料示例

这组内容是给首次填写角色资料时参考的中文样例，不是龙妹与用户真实发生过的共同经历。身份由用户掌控；可直接在“角色与记忆”窗口调整。

- `identity.md`：建议的人格、说话方式和边界。默认关闭在线分享。
- `memories/`：仅作为待确认的记忆候选。示例内容是“角色设计约定”，不是对用户生活的事实判断。
- `plans/`：用户可自行决定是否采纳的目标草案，不会自动执行。
- 能力：不放进角色文档。应用会按模型配置、语音模型、桌宠运行时等真实状态动态显示；直播平台仍是计划中。

本机实际资料按实例 ID 保存在 `~/Library/Application Support/AnimeDesktopPets/pets/<petId>/character/`。请通过应用界面保存，避免手工覆盖已有资料。
