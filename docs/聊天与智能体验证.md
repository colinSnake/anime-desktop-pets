# 聊天与智能体验证

此页用于复跑当前「小话间」聊天编辑器、桌宠 Agent 面板和 DSH 文本探针。分别记录浏览器界面、工作区本机服务、可信服务中转候选、独立 DSH 进程探针及两者的合成联调。任何一层都不需要运行 Electron 或使用真实 Key。

## 桌宠 Agent：第一阶段实装预览（合成数据）

当前面板截图和验证脚本在 `.local/pet-agent-stage1-20261120/`（不随仓库分发）。只构建 React 工作区，角色资料与回复由内存夹具提供；页面禁止外部连接，不启动 Electron／Qt。重建与启动：

```bash
node .local/pet-agent-stage1-20261120/build.mjs
node .local/pet-agent-stage1-20261120/serve.mjs
```

在浏览器访问终端打印的回环地址，按「聊天 → ··· → 桌宠 Agent」打开。`?theme=dark&pet=fish` 预览深色大肥鱼，`?pet=copy` 查看同角色分身空资料，`?mode=fail&no-model` 检查读取失败和无在线路由。点 ×、按 Esc 或点击宽窗左侧遮罩均应回焦聊天菜单，点击遮罩不会触发底下的侧栏导航。详情返回总览应还原位置。自动化 `verify.js` 使用 Playwright CLI 的 `run-code --filename=…`，先用本次服务输出的地址打开浏览器会话。数据不落盘；不要换成真实资料、Key 或模型。换机从下节仓库回归入口复跑。

## 复跑：已接入的服务 SDK（macOS，合成模型）

```bash
pnpm install --frozen-lockfile
pnpm exec tsx --test --test-concurrency=1 \
  apps/app-service/test/harness-runtime.test.ts \
  apps/app-service/test/online-chat-dispatch.test.ts \
  apps/desktop/test/workspace-records-chat-acceptance.test.ts
pnpm run check:cross-platform
```

- 常规工作区使用启动命令本身的独立 Node 24（24.9+）加载本仓库锁定的 DeepSeek SDK，CLI 由 SDK 解析。Electron `45.4.1` 的内置 Node `24.22.3` 已在无界面模式实测：原生加载器 `0.1.10` 在 SDK 握手时拒绝该运行时指纹，未进入模型派发。无需 Ape checkout 或用户模型配置来跑下列合成测试。`check:cross-platform` 包含这组验证和构建冒烟，不启动桌面窗口。非 macOS 跳过 SDK／沙箱用例。
- 固定聊天路由向真实 SDK 发送合成正文（也包括 `/` 开头的普通文本），合成模型返回 SDK 启动前不可预知的文字，只有 SDK 完成才交付。无 Worker 或未注入 Runtime 时不能读取厂商 Key 或直连；主动关闭服务时取消挂起传输并等待 Worker；在独立合成宿主被终止后，确认所属 SDK 进程组和本轮目录回收。合成门禁检查文件、额外端口、任意程序执行、工具字段、错误凭证和重放的拒绝。
- `pnpm run dev:desktop` 是实际工作区入口，仅在明确要运行桌面时执行；首次需要真实在线发送时，先在模型管理保存所需服务商连接和默认模型，再明确授权使用。真实 Keychain 授权、在线接口、计费、Electron utility process 生命周期与独立签名包均不在上述测试范围内。

### 复跑本仓库构建产物搬移（macOS）

在已执行冻结安装、且没有正在使用构建输出的工作区中运行：

```bash
pnpm run build:cross-platform
node scripts/probe-pet-agent-relocated.mjs
```

探针暂存本仓库服务的依赖闭包、构建出的 Worker 和当前独立 Node，再移动到含空格的路径。服务使用临时合成资料及固定聊天处理器，Worker 的产品沙箱拒绝读取原 checkout、原 Node 位置和合成服务资料。成功回合验证 `/help` 字面输入、模型仅派发一次和完成回复；故障回合验证授权上下文经服务发送、模型断开后无回复、无补发。两个回合都验证同一请求 ID 被拒绝重放且临时回合目录清空。输出包含依赖和 Node 字节数；探针不生成安装包、不需要 Ape、不开桌面、不调用真实模型。若回收未确认，保留临时目录以供检查。

### 复跑：ad-hoc 签名 `.app` 探针（仅 macOS arm64）

使用有构建产物的隔离工作区。需要仓库锁定版本的本机 arm64 Electron 已解压至依赖包的 `dist/Electron.app`，以及独立 Node 24.9+。探针本身不下载依赖、不启动 Electron：

```bash
pnpm run build:cross-platform
node scripts/probe-pet-agent-packaged.mjs
```

主进程在已打包模式仅选取 `Contents/Helpers/pet-harness-node`，忽略 `PET_HARNESS_NODE`，也不从 PATH 查找；开发态行为不变。探针复制 Electron，在临时 `.app` 内以同样的固定路径放置独立 Node，将服务、Worker 与自包含 pnpm 布局放在真实的 `Contents/Resources/app`（不是 ASAR），不复制本机启动视频或本机封面。探针仅对该副本做 ad-hoc 签名，随后搬移整包、严格验证签名和服务入口解析，再以包内 Node 运行聊天合成夹具。缺失运行时文件仍失败关闭，不回落直连。默认暂存完整闭包，也可以给探针加 `--omit-web-source-maps` 做同一试验；不是安装包裁剪规则。

预期 `adHocSignatureVerified`、`relocated` 为 `true`，`electronLaunched` 为 `false`；`outcomes` 与普通搬移探针一致。成功后删除一次性夹具，回合回收未确认时保留临时目录。此证据不覆盖 Electron 主进程与 utility process 实际启动、真实桌面、Developer ID 签名、公证、安装或真实提供方。当前独立 Node 的最低系统标记为 macOS 13.5，发行前需固定可信的 Node 来源、核对目标系统和架构，并在签名后复验；不把本轮夹具分发给用户。

## 复跑：独立 DSH 文本探针（macOS）

确认使用可信、已安装固定版本依赖的参考项目目录后运行：

```bash
node scripts/probe-pet-agent-sdk.mjs "<可信 Ape checkout>/packages/runtime-deepseek"
```

预期 `syntheticRequests: 3`、`automaticReplay: false`、`networkCanaryHits: 0`、`productionEnabled: false`。`evidence.text` 应是 `completed`，包含有序文本事件；`evidence.stop`、`evidence.crash` 应是 `outcome-unknown`，不自动重发。每轮只应有一个匹配授权的请求，并观察到合成连接关闭、所属进程组退出。关闭日志上传和本机会话持久化后，每轮的 `promptOnDisk`、`replyOnDisk`、`capabilityOnDisk` 都应为 `false`，表示退出后未在回合临时目录扫描到原文标记。任一标记命中即失败。

`node --test scripts/test-pet-agent-sdk-probe.test.mjs` 可在无 Ape、无 DSH 环境单验合成 DTO、修订、回放拒绝和事件边界（也进入 `test:tooling`）。实际探针只访问合成回环服务，不验证完整进程树、宿主崩溃恢复、实际保存路由、真实模型或计费。不要填真实模型地址或 Key；探针不替换已有聊天配置。

## 复跑：DSH 执行聊天文字回合（macOS）

使用与独立探针相同的可信 Ape 目录：

```bash
pnpm exec tsx scripts/probe-pet-agent-sdk.mjs --chat "<可信 Ape checkout>/packages/runtime-deepseek"
```

- 预期 `linkedChat: true`、`syntheticRequests: 5`、`automaticReplay: false`、`productionEnabled: false`。从固定聊天处理器进入；每轮一个通过授权的回环请求、一次校验过的合成模型派发。重交同一个请求 ID 会被拒绝。旧 `--relay` 占位联调不再提供。
- `text` 应有有序的 SDK 文本事件，且 `serviceOutcome: runtime-reply`。握有合成凭证的可信桥返回运行前 SDK 不知道的随机合成回复；处理器仅交付与它匹配的 SDK 最终文字，而不是桥接确认或独立生成的旁路结果。
- `stop`、`crash`、`disconnect`（合成模型断开）和 `timeout`（探针等待 SDK 三秒后关闭）应显示 `outcome-unknown`、`serviceOutcome: no-reply`。停止、崩溃和超时须取消挂起的模型传输；不补发。
- 确认回环连接和所属进程组退出，第二端口零命中。退出后有界扫描应未命中本轮正文、模型回复、回环凭证及其他服务私有标记。不代表宿主崩溃后的完整进程树回收、全盘隔离、隐私或真实提供方通过验收。

不读取用户模型配置，不需要 Key 或真实厂商；不打开桌面。这是历史 Ape 开发夹具，不代表下方常规工作区入口的验收。

## 复跑：可搬移 Runtime 暂存与宿主失联（macOS）

```bash
pnpm exec tsx scripts/probe-pet-agent-sdk.mjs --staged "<可信 Ape checkout>/packages/runtime-deepseek"
```

`--staged` 只读参考项目现有的 pnpm 安装。从固定 DSH、SDK 和 Pi Provider 入口复制依赖闭包及同包许可证，不复制 Ape 源码、配置、账号或会话。暂存包移动到另一目录后才运行；Worker 在沙箱内不能读取原 Ape 项目的清单。原生模块使用本机 Node.js，不将 Node 或 Electron 打进包。不联网安装、不写参考仓库；普通构建不会执行此步骤。

- 预期 `relocated: true`、`syntheticRequests: 6`、`productionEnabled: false`。前五轮与 `--chat` 相同；`stagedPackages`、`stagedPayloadFiles` 与 `stagedPayloadBytes` 只计复制的依赖闭包（不等于压缩或签名后安装包体积）。这版完整闭包较大，不是发布候选。
- 第六轮 `host-loss`：等模型请求已经派发但仍挂起，仅对专属的一次性启动宿主发 `SIGKILL`，**不会向 Worker 组发终止信号**。独立 Provider 仍在运行且不会先关闭连接。Worker 发现父 IPC 断开就取消并关闭 SDK；测试只观察连接和所属进程组，预期 `launcherKilled`、`processGroupExited`、`providerAborted`、`replayRejected` 为 `true`，`serviceOutcome: no-reply`。
- 未确认回收时保留本轮临时目录和暂存包，不按遗留 PID 补杀。验证覆盖这个测试宿主及其实测进程组，不覆盖真实 Electron 主进程／服务崩溃、逃离组的后代、机器重启、签名或安装。第二端口零命中和目录有界扫描也不是全盘隔离证明。

`node --test scripts/test-pet-agent-runtime-stage.test.mjs` 无需 SDK 包，单独验证暂存目录可搬移、只复制可达依赖、相对链接、拒绝出界链接／载荷链接，以及 IPC 预启动／失联门禁。

## 单独安排实机时

当前轮不重启现役 Electron。系统中文输入法、原生窗口焦点、VoiceOver、真实 Keychain／厂商／计费均需独立验收。优先用隔离资料跑中文输入法：候选确认的 Enter 不发送，再按一次才发送；检查中英文切换、长稿滚动、切宠恢复选区和取消等待后的草稿。真实联网或产生费用需另获同意。模型管理的服务商连接列表与聊天选模是两个视图，见 [UI 设计](ui-desgin.md#模型管理同一工作区分清保存与测试)。
