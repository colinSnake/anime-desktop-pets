# Codex 额度气泡（0.6.2）

入口：桌宠右键 → **查看 Codex 额度**。增强版不再创建独立额度/统计窗口；使用桌宠旁的紧凑气泡显示额度进度与重置时间。

## 界面参考

本地参考项目 `codex-pet/bailong-desktop-pet/app/pet.py` 的 `Bubble.quota()`：固定小气泡中按额度周期显示百分比、进度条和可用的重置时间。本项目复用已认可的 `dragon_ui.Bubble` 卡片绘制和气泡定位，只借鉴此额度信息层级，不复制上游源码或图像资源。额度内容不会撑宽气泡，过长文本按气泡现有布局规则处理。

## 数据边界

- 只有用户显式点击菜单或双击桌宠后才查询；使用现有只读 `quota.read_quota()` / `account/rateLimits/read` Codex CLI 流程，不发起提示词或任务。
- 显示 5 小时/每周窗口的剩余额度与重置时间；缺失值显示未知，不猜测或换算成费用。
- 没有后台自动刷新，不发起模型任务或读取对话正文。
- 不显示账号标识或令牌。查询日志仅记录脱敏状态码/耗时，具体行为继承 `quota.py`。
