# Codex 与中转额度气泡（0.7.2）

入口：桌宠右键 → **查看 Codex 额度**，或双击桌宠。使用已认可的紧凑气泡；不打开独立统计窗口。

额度卡片沿用 DeepSeek 桌宠的“额度行 + 使用条 + 重置时间”信息层级，并加入手动刷新与查询时间。官方额度行按剩余额度显示主题色档位（充足/注意/紧张）；TiMi CC 余额以醒目的金额呈现，绝不伪装成百分比。

## 查询来源

- **官方账户**：保留上游只读 Codex CLI `account/rateLimits/read` 流程，显示服务提供的 5 小时/每周订阅窗口、剩余百分比和重置时间。
- **TiMi CC 中转**：读取当前 Codex `config.toml` 的服务地址，匹配 CC Switch 当前 Codex 服务及其已启用的只读 GET `{{baseUrl}}/v1/usage` 模板。仅支持 HTTPS `timicc.com` 根地址、Bearer `{{apiKey}}` 的已知模板；不猜测其它服务端点。
- 显式请求时只读打开 `~/.cc-switch/cc-switch.db`，校验选中服务地址一致，再从配置的环境变量或该服务的 `settings_config.auth.OPENAI_API_KEY` 获取凭据。未修改 Codex/CC Switch 文件、不访问钥匙串、不执行 CC Switch 的 JavaScript。CC Switch 无需保持运行，但其数据库和匹配配置必须存在。
- 中转解析模板约定的 `remaining`、`quota.remaining` 或 `balance`，单位取 `unit`、`quota.unit`，缺省按该 TiMi 模板的 `USD`。显示「中转剩余额度 / TiMi CC · 剩余金额 单位」，不把余额当百分比、不绘制订阅进度条或伪造重置时间。
- 其它中转、未匹配/关闭模板、缺少凭据、401/403、404、网络失败、未知响应格式均给出对应原因，不再统一提示稍后重试。此适配基于本机已配置模板，未宣称 TiMi 对所有账户保证该接口。

## 隐私与运行边界

仅用户点击菜单或双击后查询；不后台刷新、不因任务跟随自动联网、不发送提示词或启动模型任务。
认证仅发送给匹配的 TiMi HTTPS 端点；拒绝重定向，避免凭据被带到其它地址。响应限1MiB。
额度数值只进入当前气泡，不持久化；错误日志仅保存脱敏状态码/阶段/耗时，不保存服务器错误正文、密钥、账号或余额。
任务观察器与额度请求相互独立；额度交互期间暂缓自动姿态切换，关闭气泡后继续跟随。

本轮核对了本机 TiMi 配置与模板匹配、旧接口失败阶段；**没有自动请求真实余额**。真实返回格式、余额及桌面体验由用户主动点击验收。


额度适配器测试使用临时 Codex/CC Switch 配置和模拟 HTTP 响应；覆盖官方回退、配置匹配、禁用/未知模板、认证与重定向拒绝、金额/单位及异常响应。Qt 真实适配器离屏检查余额不会显示成百分比进度条。预览和自动测试不读取真实账号或查询真实额度。
