## 2. 直接可见的稳定特征

| 项目 | 观察 |
| --- | --- |
| 角色类型 | 二次元 Q 版人形龙娘；人类面孔和小身体，不是四足幼龙，也不是龙头兽人 |
| 比例 | 大头、小躯干、短四肢；约 2–2.5 头身是目测范围，不是精确建模比例 |
| 头发 | 近白色/银白长发，淡薰衣草紫阴影；厚刘海、两侧成束的卷发，发尾大波浪；头顶明显卷曲呆毛 |
| 双眼/表情 | 大而圆润的紫罗兰色眼睛、深紫上眼线和亮色高光；很小的鼻口、浅粉脸颊；表情柔软，可闭眼笑 |
| 龙角 | 头顶左右一对白色/象牙色短粗弯角；能看到分节曲线，角尖向上弯，不是鹿角或猫耳 |
| 耳朵 | 两侧露出小尖耳 |
| 装饰 | 画面右侧鬓边（正面图中）有盘花/结绳状发饰和细长垂饰；领口菱形装饰、胸前同风格盘花结饰 |
| 衣服 | 白色层叠荷叶边幻想裙，淡紫内层和阴影；小立领/领结结构、露肩结构与分离式宽大袖子；裙摆前短后长/两侧垂落，整齐而非写实布料堆叠 |
| 鞋 | 白色短靴/小鞋，浅紫描边和菱形等细小装饰 |
| 龙翼 | 一对展开的小型蝙蝠式龙翼，浅紫半透明感翼膜，白色骨架/翼指，深紫轮廓；不是羽翼 |
| 龙尾 | 粗而弯曲的白色鳞片尾，通常绕到画面右下并上翘；淡紫分格鳞纹，尾尖有小簇/鳍状轮廓，随动作可改变朝向 |
| 画风 | 干净柔细的深浅紫线稿、粉彩配色、柔和赛璐璐/插画渐层，局部高光；不是像素风、照片或高反差 3D |
| 背景 | 桌宠用途的透明画布；不需要环境、地面、字幕或绘制的气泡 |

“水彩感”“约 2–2.5 头身”等是外观类比，不代表已经确认制作工艺。抽样中能见到部分边缘残留或浅底，
因此不能把现有透明素材描述成“像素级完美无灰边”。提示词中的干净 alpha 是**新输出要求**。

## 6. 单动作动画扩展提示词

必须先固定角色参考，再每次只生成一种动作；以下是制作目标而非已生成动画。

### 待机（建议 4 秒闭环）

> 使用已确认的同一白龙娘角色设定，完整全身正面轻微三分之四视角，原地站立。4 秒无缝循环，轻柔呼吸、一次自然眨眼，发梢与尾尖极小幅摆动，龙翼轻微舒展但不扇飞。不走动、不说话、不增加道具。相机、焦距、主体大小和画面位置全程固定；双脚的底部中心锚点不漂移。角形、发饰位置、衣裙层次、翼骨数量、尾巴鳞纹和面孔不发生变化。首尾姿态、速度与透明轮廓连续；透明背景，完整保留头发和翼膜的 alpha 边缘，无幻影、变形或地面阴影贴片。

### 招手（建议 4 秒一次性动作）

> 同一角色与相机，一只手抬起轻轻招手两次，眼神看向观众，短暂微笑，再自然回到基准待机姿态。另一只手、双角、双翼和尾巴保持身份一致，底部中心锚点固定，无平移、缩放或镜头运动，不生成对白文字。

### 飞行（分离姿态和运行时位移）

> 同一角色，固定侧身方向，明确起势、稳定飞行姿态与收尾阶段；保持翼膜连接和尾巴拓扑一致，不随意翻转发饰或旋转相机。若由桌宠运行时驱动位移，输出固定画布中的飞行动画，不在素材中再烘焙跨画面移动，避免双重位移。

工程接入仍需逐帧检查透明边界、时长、首尾帧、配准与授权；动作命名、loop、移动时段及朝向应按
[素材包规范](宠物库与素材包.md)显式填写。图像/视频模型是否支持真正透明输出、闭环和指定帧率须在确认服务协议后验证，不能仅靠提示词保证。
