# 桌宠智能体与聊天编辑器

> 2026-11-24：接入 [Pi 统一 Agent 内核](superpowers/specs/2026-11-24-pet-agent-runtime-design.md)，替换旧 DSH 回环执行链；现有角色资料面板、本机记忆提案和完成会话保留。

## 当前可用范围

| 能力 | 状态 |
| --- | --- |
| 桌宠 Agent | 聊天右上角 `··· → 桌宠 Agent` 打开当前实例总览；身份、记忆、目标、能力在同一面板按需深入，不新增 Tab。原有资料、历史、人工审核、逐项授权及手动目标进度沿用固定桥。只有已保存、可审核的候选才出现在总览提醒；点右上角 ×、按 Esc 或点击宽窗左侧遮罩可收起；面板开关不改变桌宠舞台、聊天草稿或在途回复，换实例或目标失效退出旧面板。 |
| 聊天编辑器 | 按 Ape Agent Harness `7be8b9c` 的输入模型参考，独立实现 Lexical 编辑器、语义选区、有界草稿和提交快照。会话内跨页／切换实例保留正文和选区；不存磁盘。撤销历史仅限当前编辑器实例。本机短句只填草稿。`＋ → 预览 Markdown` 只读，不执行 HTML、打开链接或加载外部图片；返回编辑保留正文及选区。保留原 1200 字素发送上限，超限不截断；编辑硬上限为 16,384 UTF-16 单元，额外输入不会无提示地截断草稿。 |
| 聊天内确认记忆 | 显式输入 `记住：…`，提交后生成与当前实例及发言绑定的本机提案；只有点「保存为记忆」才原子写入已确认个人记忆，默认不分享。忽略、切换和关面板均不写入。 |
| Pi Agent Core | 可信本地服务内的固定运行时。普通聊天和已批准的纯文本材料都使用该内核；由现有模型服务持有路由、网络与 Keychain。Apple 芯片 Mac 支持本机 WAV 转写成草稿；直播有独立限额的文字调度，未接平台。 |
| 聊天附件 | 「＋ → 选择或替换附件」：最多 5 个，每个 5 MiB、合计 15 MiB。白名单纯文本每件 20,000、问题加附件合计 60,000 字素；图片和 PDF 只发给有已保存输入声明或匹配官方地址与确切模型 ID 能力规则的 Responses 模型；不根据模型前缀推断兼容网关能力。当前回合发送，原始文件不进入磁盘草稿或 SQLite；用户问题和最终回答仍可保存供查看，该回合不自动重放或重试。 |
| 项目与会话 | 「聊天」侧栏新建实际文件夹并在项目中开新会话，购买或配置模型不是建文件夹的前置。旧已完成会话保留为未分配；第一次安全完成后写入当前项目。独立 Agent 任务弹窗已移除，旧任务记录保留、不会被迁入聊天。 |
| 尚未开放 | `@` 路径引用、任意文件系统访问、后台自启动、自动资料写入、结构化差异审批及应用、Shell、MCP、Skills 和子 Agent。渲染器不获得 SDK、Key、任意 IPC 或目录能力。 |

当前验证入口见[聊天与智能体验证](聊天与智能体验证.md)；旧 DSH 隔离窗口和进程证据仅作为[历史验证记录](实际验证记录.md#2026-11-20隔离-electron-窗口复测停止后重发与在途退出)。

## 从 Ape 借鉴什么

输入框借鉴 `TaskComposer` 与 `editor/runtime` 的编辑器和 UI 分离、语义投影、撤销边界及冻结的提交快照，并按同样的圆角卡片、编辑区／底栏层级和拖拽反馈整理任务输入。不复制工作台会话协议、通用工具审批实现或开发工具选择器；不迁移 Ape 源码、数据、配置或凭证。 2026-11-24 另对照 Ape 远端 `main` 的 `b539c5a`：提交后清空该轮草稿，失败可显式重试或恢复冻结原文，不让异步结果覆盖新草稿。输入法、菜单、纯文本剪贴板和提交门禁分别验收；普通模型选项继续来自现有配置。

Ape 只作为编辑行为和早期进程隔离设计的参考；现产品不调用 Ape/DSH，不复制其源代码、配置、凭证或数据。

### 在聊天中处理本轮材料（2026-11-24）

1. 左侧「项目与会话」支持新建文件夹和项目内会话。系统文件夹选择器只选父目录，不覆盖同名项；不扫描、读取或监控项目文件夹。服务只记录当前桌宠、项目的 ID／名称与会话归属，不保存或发送绝对路径。新业务根下的 SQLite 旧会话自动保留为未分配，原任务数据库不改写。
2. 输入区默认「请求批准」。添加或拖入附件只加入草稿，发送前在聊天内批准；跳过不发送附件。点「完全允许」先收起菜单，再打开独立确认弹窗；取消、Esc 或点击遮罩不改变模式。确认后即使草稿为空也立即更新胶囊，但仅对确认时具备发送条件的本轮附件生效，不预先授权未来附件。切换桌宠／会话、更改草稿／附件／模型、隐藏窗口、取消发送和完成发送都会撤销。主进程持有短期授权；服务核对整个请求摘要，一次有效，30 秒到期；同一实例的新许可替代旧许可。它是可信工作区内的应用层确认，不是系统权限或针对 renderer 被篡改的隔离。不会因此取得 Shell、项目路径或任意读写权。
3. 纯文本附件使用既有列出、读取片段、搜索的固定内存工具。能力明确不支持时不派发；未验证时直接提交用户已批准的本轮问题和固定工具声明，不额外探测。工具请求有效时才回传必要片段，可能计费。图片／PDF 仍要求已配置相应能力，批准后同轮发送；混合附件仍分别处理：图片／PDF 走媒体输入，纯文本仍只经有界只读工具，不随媒体直接发送全文。附件文件不保存、不自动重试或回放；最终回复可能含附件摘录。
4. 人格由可信内置角色设定和用户独立授权的身份资料提供。纯文本工具链不回放历史或附带记忆／知识／目标；普通聊天继续逐项核对资料共享。内置人格不代表额外权限，也不会把用户自定桌宠名称、项目名或路径默认发给模型。

### Pi 文字执行链（macOS 常规入口）

```text
固定聊天入口 → 轮次准入和运行账本 → Pi（约束内工具循环）→ ModelManagement（已保存路由）
聊天回复 ← 终态与当前授权复核 ← 已验证的模型回复
```

- 普通「你是谁？」走选定模型，「查看本机身份」仍是明确的本机查询。普通文字只调用一次模型；没有隐式重试、路由切换或第二套 SDK 凭证。
- 用户选中的纯文本材料是唯一工具数据源。工具参数、来源、大小和轮数有界。模型要求未知工具或尝试传路径不会执行或触发下一次出站。纯文本工具调用的服务内回放保留该协议的原生续接，但不写入账本。
- `~/.adpets/agents/<实例 ID>/agent.json` 保存默认声明，`agent-state.sqlite` 仅记录请求 ID、实例、来源、时间和终态；`chats.sqlite` 继续独立保存合规的已完成聊天。请求结果未确认不会自动重发；不兼容的 Agent 配置不会被覆盖。不迁移旧资料。
- 开发构建把 Pi 打进服务 CommonJS，不引入额外独立 Node 或 DSH Worker；没有将工具或凭证交给 renderer。历史的 DSH 暂存、搬移和独立签名探针已退役，不是 Pi 发布或真实桌面验收证据。

### 语音与直播

当前语音输入是显式选择 WAV → 本机 ASR → 可编辑聊天草稿 → 用户手动发送 → Pi；麦克风和自动回复播报仍待接线。直播链路为获授权的平台适配器 → 限流、去重、过期筛选 → Pi → 气泡／有界语音输出。Pi 负责文字推理，不负责音频设备、平台登录或聊天室回写。合成调度覆盖同宠手动/语音打断直播并等待旧工作清理、不同实例隔离、取消后拒绝迟到输出。直播短期去重和滚动每分钟最多 8 次启动独立于手工输入；真实直播未接线，适配器不得加载私密角色上下文、历史或材料工具。设备、平台授权及计费需另行验收。

## 显式本机记忆提案与后续边界

Agent 不持有角色库文件或通用写命令。只允许提出类型化提案，由应用从当前可信会话绑定实例 ID、证据发言与预期修订，再复核已登记实例、逐项授权、冲突、敏感内容、写入确认和撤销版本。

- **已接入的显式指令：** 仅识别 `记住：`（含半角冒号），以用户填写的单行内容（最多 300 字素、4096 字节）生成本机确认卡。服务复核修订、同实例发言 ID、重复、容量和凭证风险，沿用同一个原子仓库。收到持久确认才显示「已记住」；冲突需重读再明确确认，未知结果只允许读，不重放。撤回确认或删除在「桌宠 Agent → 记忆」使用已有的修订门禁，不提供覆盖后来编辑的快捷撤销。
- **尚不从普通对话推断：** 普通消息、回复、模型输出均不会生成提案，无后台模型审核。记忆命令与提案状态不进入模型历史；新记忆若要在线使用，仍需单独逐条授权。
- **后续身份、知识和目标提案：** 当前尚未接线。若开放，人确认后才可生效，不静默修改身份、引用未知来源或标记完成。应用定义的能力不可由 Agent 配置。

设计及范围见[确认稿](superpowers/specs/2026-11-19-pet-agent-and-composer-design.md)；角色数据主写者仍是当前服务的私有仓库。
