# 桌宠智能体与聊天编辑器

> 2026-11-20：[桌宠 Agent 统一工作台](superpowers/specs/2026-11-20-pet-agent-workspace-design.md)已实装统一面板和显式本机记忆提案，通过合成验证。macOS 常规开发工作区的在线文字路由已接入 DeepSeek 官方 Harness SDK，独立 Node 24 合成验证不需配置模型。自动推断记忆、其他资料提案和独立安装包仍未开放。

## 当前可用范围

| 能力 | 状态 |
| --- | --- |
| 桌宠 Agent | 聊天右上角 `··· → 桌宠 Agent` 打开当前实例总览；身份、记忆、目标、能力在同一面板按需深入，不新增 Tab。原有资料、历史、人工审核、逐项授权及手动目标进度沿用固定桥。只有已保存、可审核的候选才出现在总览提醒；点右上角 ×、按 Esc 或点击宽窗左侧遮罩可收起；面板开关不改变桌宠舞台、聊天草稿或在途回复，换实例或目标失效退出旧面板。 |
| 聊天编辑器 | 按 Ape Agent Harness `7be8b9c` 的输入模型参考，独立实现 Lexical 编辑器、语义选区、有界草稿和提交快照。会话内跨页／切换实例保留正文和选区；不存磁盘。撤销历史仅限当前编辑器实例。本机短句只填草稿。`＋ → 预览 Markdown` 只读，不执行 HTML、打开链接或加载外部图片；返回编辑保留正文及选区。保留原 1200 字素发送上限，超限不截断；编辑硬上限为 16,384 UTF-16 单元，额外输入不会无提示地截断草稿。 |
| 聊天内确认记忆 | 显式输入 `记住：…`，提交后生成与当前实例及发言绑定的本机提案；只有点「保存为记忆」才原子写入已确认个人记忆，默认不分享。忽略、切换和关面板均不写入。 |
| DSH SDK | macOS 服务固定使用 `@deepseek-ai/dsh-sdk-client@0.2.2-rc.5` 执行在线文字回合，经受限回环 Provider 桥取得已保存模型的回复。只有 DSH 完成且复核授权后交付；无 SDK 时不回退直连。本机查询不变，真实桌面与独立安装待验。 |
| 尚未开放 | 结构化引用与文件授权（含附件和 `@` 引用）、工具执行、自动写记忆／身份／目标。渲染器不获得 SDK、Key、任意 IPC 或目录能力。 |

想直接试用或复跑，先看[聊天与智能体验证](聊天与智能体验证.md)，其中区分浏览器夹具、工作区服务验收和独立 SDK 探针。

## 从 Ape 借鉴什么

输入框借鉴 `TaskComposer` 与 `editor/runtime` 的编辑器和 UI 分离、语义投影、撤销边界及冻结的提交快照。不复制工作台会话协议和开发工具选择器；不迁移 Ape 源码、数据、配置或凭证。输入法、菜单、纯文本剪贴板和提交门禁分别验收；普通模型选项继续来自现有配置，未增加通用「思考等级」。

运行时以本机 Ape `c203014` 工作树的 `packages/runtime-deepseek/src/adapter.ts`、`runtime-child.mjs`、`supervisor.ts` 与 `apps/worker/src/provider-bridge.ts` 为参考：Worker 把本轮正文交给 Runtime，Runtime 请求固定回环 Provider，桥持有上游路由和凭证并把回复交回 Runtime。只采用这条执行结构，不移植 Ape 任务系统、工具或审批系统，不复制代码或用户数据。

### Harness 文字执行链（macOS 常规开发入口）

```text
固定聊天入口 → 隔离 DSH（本轮文字） → 回环模型桥 → 已保存路由（验证时注入合成传输）
聊天回复 ← 服务复核实例/授权/路由 ← DSH 完成 ← 有界文本 SSE ← 模型文字
```

- 旧的「核销票据让服务自己跑完聊天、只给 SDK 回执」候选已移除。新链路由可信服务在构造时注入文字 Runtime，走同一固定聊天处理器；常规 `dev:desktop`（含 HMR、Codex 启动变体）从本机启动器取得独立 Node 24 路径，固定服务入口绑定 Worker；没有从界面选择运行时的 IPC。验证夹具只创建临时资料和模拟凭证，无需用户配置模型。
- 子进程接收本轮文字和仅本轮可用的回环凭证；不接收保存的厂商地址、实际模型 ID、Key、原始历史或原始角色资料。桥只接受匹配当前冻结文本的有界请求；SDK 默认系统提示、工作目录提醒及任意工具／日志字段不转发。服务在出站时复核实例与路由修订，按授权使用历史和资料。模型文字经过验证后包装为有界文本 SSE；这是完整文本回送，不是上游 token 流透传。模型回复可能包含其从获授权上下文生成的文字，因此回复也属于受保护数据。
- 不接受仅有上游成功而没有 SDK 完成的回复，也不接受 Runtime 改写或捏造的终态。交给 SDK 和最终交给聊天前均复核授权及路由。按实例限制一个在途回合，最多三个并发、65 秒时限，服务进程内防重标记最多 1,024 个且不驱逐。中止／崩溃／断开／超时没有最终回复，同一 ID 不自动重放，不改走直连补发；不保证跨进程重启防重。

### 进程边界与分发

- Worker 使用 `sdk-minimal` 并关闭内置 DeepSeek 直连、工具入口、日志上传和会话落盘；用 SDK 的字面 `prompt()` 跳过原生命令路由，按回合收件 ID 核验事件与完成状态，`/` 前缀也不执行 DSH 命令。macOS 沙箱将网络出站限制在本轮回环端口、写入限制在临时目录，并限制执行其他二进制及读取账号与应用资料目录。保留必要的 SDK／系统读取权限，不是全盘隔离。取消时撤销 Provider 并关闭父 IPC，Worker 调用 SDK 关闭子进程；先后两次资料／路由检查、Runtime 和已接收的模型调用都在回合管理中追踪，收尾未确认不继续派发。合成宿主强退后，实际 SDK 所属组退场，Worker 清除了本轮临时目录；不视为所有真实 Electron 崩溃时机或逃逸后代的验收。
- SDK 客户端硬依赖同版 DSH CLI。服务只直接声明 SDK 和显式加载的 Pi Provider，并从 SDK 的安装位置解析 CLI；移除重复声明不等于移除 CLI 本体。`sdk-minimal` 是执行配置，不会缩小 pnpm 完整闭包；此前实测约 716 MiB（不含 Node／Electron），不能按缓存清理。构建只复制 Worker 文件，不复制暂存镜像，不依赖 Ape checkout。Electron `45.3.2` 和升级后的 `45.4.1` 均在 Node 模式下被 `node-addon-require-builtin@0.1.10` 拒绝，因此仍使用独立 Node 24。发布前仍需审核并收敛依赖、选择可分发 Node、验证签名安装及真实桌面生命周期。
- 本仓库另有显式[搬移探针](聊天与智能体验证.md#复跑本仓库构建产物搬移macos)：复制服务依赖、独立 Node 和构建出的 Worker，搬移后通过产品 Runtime 执行合成聊天，不再借用 Ape 的依赖或探针 Worker。它不改变常规启动，也不生成可分发的安装包。

### 本机探针（显式运行、仅开发）

在 macOS 和 Node.js 24.9+ 使用可信、已安装依赖的 Ape `packages/runtime-deepseek` 目录（不是仅源码 checkout），从本仓库执行：

```bash
node scripts/probe-pet-agent-sdk.mjs "<可信 Ape checkout>/packages/runtime-deepseek"
```

固定 `@deepseek-ai/dsh-sdk-client`、`@deepseek-ai/dsh` `0.2.2-rc.5`。不安装包、不读真实配置。每个合成回合使用白名单环境和独立临时目录，macOS `sandbox-exec` 将出站限制为一个随机回环端口，写入限制在回合目录；账号 HOME 读取规则保留可信 SDK／运行入口和临时目录例外，不是全文件系统隔离。另用合成文件和第二个回环端口验证拒绝行为。

一次完成文本；两次在请求到达后分别显式停止和强制退出自有 worker，均保留「结果未知」。每轮断言固定路径、一次性凭证及有界文本 DTO：拒绝工具、日志上传字段、路由不匹配和过期修订。显式关闭 `sdk-minimal` 自带的终端与持久 shell 工具等贡献。出站 DTO 和本轮事件没有工具，不代表完整的运行时工具隔离。

**会话存储是独立门槛。** 仅关闭 `session-log-deepseek` 和发出 `store:false`，仍在私有目录观察到合成正文，包括 worker 崩溃前的输入。另关闭本机 `sessions` 持久化后，三种场景均通过，回合目录有界扫描未匹配原文或凭证标记。扫描不证明没有短暂文件、其他编码残留或宿主崩溃后无孤儿。历史 Ape 探针仍须显式运行，不是普通构建路径；新服务的独立 Node 合成 SDK 回归进入 `test:cross-platform`（非 macOS 跳过）。联调复跑用 `pnpm exec tsx scripts/probe-pet-agent-sdk.mjs --chat "<可信 Ape checkout>/packages/runtime-deepseek"`，场景和证据见[验证指南](聊天与智能体验证.md#复跑dsh-执行聊天文字回合macos)。见[实际验证记录](实际验证记录.md#2026-11-20桌宠-agent-第三阶段dsh-文本执行器探针)。

### Runtime 暂存与宿主失联（仅开发）

参考本机 Ape `a55fed9` 中 `runtime-child.mjs` 的父 IPC 失联门禁。Worker 在加载 SDK 前要求有效所有者；断开后关闭输入并通过 SDK 回收自有进程，不再发布终态。可搬移暂存夹具在拒绝读原 Ape 的情况下跑完整合成聊天。另在请求挂起时强制退出一次性启动宿主，只观察连接和所属组退出，不补杀 Worker 组。详情见[暂存复跑](聊天与智能体验证.md#复跑可搬移-runtime-暂存与宿主失联macos)。这不是 Electron 安装包或生产崩溃验收；完整依赖闭包较大，独立安装交付前仍要收敛分发体积、审核依赖并验证真实宿主。

## 显式本机记忆提案与后续边界

Agent 不持有角色库文件或通用写命令。只允许提出类型化提案，由应用从当前可信会话绑定实例 ID、证据发言与预期修订，再复核已登记实例、逐项授权、冲突、敏感内容、写入确认和撤销版本。

- **已接入的显式指令：** 仅识别 `记住：`（含半角冒号），以用户填写的单行内容（最多 300 字素、4096 字节）生成本机确认卡。服务复核修订、同实例发言 ID、重复、容量和凭证风险，沿用同一个原子仓库。收到持久确认才显示「已记住」；冲突需重读再明确确认，未知结果只允许读，不重放。撤回确认或删除在「桌宠 Agent → 记忆」使用已有的修订门禁，不提供覆盖后来编辑的快捷撤销。
- **尚不从普通对话推断：** 普通消息、回复、模型输出均不会生成提案，无后台模型审核。记忆命令与提案状态不进入模型历史；新记忆若要在线使用，仍需单独逐条授权。
- **后续身份、知识和目标提案：** 当前尚未接线。若开放，人确认后才可生效，不静默修改身份、引用未知来源或标记完成。应用定义的能力不可由 Agent 配置。

设计及范围见[确认稿](superpowers/specs/2026-11-19-pet-agent-and-composer-design.md)；角色数据主写者仍是当前服务的私有仓库。
