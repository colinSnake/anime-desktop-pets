# 桌宠自主表达与验收

> 2026-11-19：文中的旧 Swift/AppKit 宿主、控制／安装命令和对应验证只作历史参考。当前功能、开发入口及剩余验收见[迁移状态汇报](macOS迁移状态汇报.md)和[本地开发与使用指南](本地开发与使用指南.md)。

更新日期：2026-11-15。

## 启动与权限前提

本机开发版语音环境和动画素材仍位于源码checkout。若仓库放在“文稿”目录，重新构建的临时签名可能让macOS再次要求“文稿文件夹”权限；请用户在系统提示中手动允许。只按实际需要授权，不需要为此授予完全磁盘访问，不修改TCC数据库，也不以其他启动方法规避提示。

正常启动后等待语音预热和helper恢复，再用`scripts/petctl.sh --status`检查；最初`petVisible=false`不等于启动已经失败。若已出现“命令已发送但结果不确定”，不要自动重放或启动第二控制器；完成系统授权后温和退出本项目宿主，再按正常方式启动。本轮最终包正常启动已得到`ready=true`、`petVisible=true`和互动朗读完成日志；没有代替用户主观听音或测试麦克风。

## 用户怎么用

### 日常 AI 气泡

进入「语音互动」→「回复与互动」，打开 **AI 生成日常陪伴气泡（可能计费）** 后点「保存」。默认关闭，升级不会自动开启。模型管理必须已配置可用服务与 Key；不需要先打开麦克风，也不要求打开语音朗读。

- 当前只替换普通的**空闲问候**；不把任务状态、错误提示、动作专属台词交给 AI 改写，也不编造“任务完成”。
- 第一次仍是本机文案。事件发生时后台预生成一句，下一次同类事件消费缓存；不在旧气泡上迟到替换，因此不会一条气泡读两遍。
- 请求只含 `idle` 这样的粗粒度事件。不发送原台词、任务正文、身份、记忆、反馈或聊天历史；没有工具或后续执行。
- 固定限额：全宠共享10分钟冷却、每天最多12次（UTC自然日）；失败和超时也占次数，重启不清零，不自动重试。缓存一次性消费，30分钟后过期。
- 取消开关并保存后，未使用缓存和旧授权回复不再使用；重新开启也不会复活旧缓存。设置无法读取、授权无法保存、模型不可用或输出不合规时继续本机文案。
- 要朗读，另开 **朗读桌宠互动气泡** 并配齐参考音频/准确转写。AI 开关只负责文案，不等于语音开关；最终显示和朗读使用同一份文本。

### 人格怎样自己适应

进入「身份」，展开 **自动适应 · 可撤销**。本地适应默认开启，不会产生额外模型请求；在线分享独立默认关闭。

直接在聊天中说完整、明确的表达要求，例如：

- `以后请回答简短一点。`
- `请详细一点。`
- `请活泼一点。` / `请稳重一点。`
- `请多给一点建议。` / `请减少主动建议。`

只认保守的完整反馈句，不从引述、否定、玩笑、猜测、助手自评或其他人的偏好推断人格。成功聊天后的反馈保存在独立 `adaptation.json`，记录逐字证据、时间、原因、调整前后值和修订；最近30条可查看。三项维度只有“降低/默认/提高”，不是任意模型指令。

**核心身份**（名字、背景、价值观、关系和安全边界）不会自动改写；**适应层**只影响表达详略、活泼程度和建议主动性。可以关闭、撤销最近调整或重置；重置不会扩大在线分享权限。分享打开后仅传固定表达偏好，不传反馈原话；“简短”以通常不超过3句/120字为指引，不牺牲必要准确性与安全信息，也不承诺模型每次严格遵守。

关闭/撤销在当前进程内立即建立同宠共享拒绝门禁；即使本地保存失败，当前运行也不继续学习或分享，并提示修复。成功保存前不会清除门禁；重新启动仍可能读到未能修改的磁盘设置，需要留意错误提示。不同聊天/语音存储实例使用同一个事务边界，重置、撤销和设置变更会使旧对话反馈失效，避免迟到回复又把旧偏好学回来。

人格适应不是自由运行的自我重写 Agent：不会自行执行计划、改变知识依据、授权新能力或编造共同经历。

## 记忆、知识与适应的分工

| 层 | 写入依据 | 正常处理 | 不会自动做的事 |
| --- | --- | --- | --- |
| 核心身份 | 用户编辑/明确恢复的版本 | 本机保存；独立分享 | 模型自行改名、改价值观 |
| 表达适应 | 成功对话中的完整明确反馈 | 三维有限调整、可撤销 | 从隐含情绪/模型意见推断人格 |
| 普通记忆 | 用户明确记忆命令；或独立开启的AI自动审核 | 逐字证据、高置信低风险自动保存 | 保存凭证、自动放行冲突与敏感信息 |
| 角色知识 | 明确资料、来源/引用/版本/有效期 | 确认后按相关性引用 | 无来源生成设定、绕过过期与冲突 |
| 日常文案 | 粗粒度空闲事件 | 有限生成、下一次消费、离线兜底 | 用气泡宣称执行结果、学习私人事实 |

这些授权互相独立；“使用 AI”不是允许上传所有本地资料的总开关。

## 不计费的整链回归

日常气泡不只检查单个类。新增隔离的跨进程回归，实际连接：Swift生产异步handler → UNIX Socket → Python客户端 → 缓存 → 真实离屏Qt Pet/Bubble → 真实SpeechCueClient → 宿主朗读Socket入口。仅模型生成器是合成假实现；资料和微型WebP均在临时目录，不加载用户角色、记忆、聊天或凭证，也不打开麦克风、合成声音或输出扬声器。

```bash
swift test --package-path apps/companion-macos --scratch-path .build \
  --filter 'PetAIBubbleRoundtripTests|PetAIBubbleProbeSafetyTests|CharacterAdaptationLifecycleTests|CharacterAdaptationProcessTests'
```

- 气泡7项：首次本机兜底、下一次同类事件一次性消费、其他事件不能取走缓存、默认关闭不发请求/不建额度、失败不重试、关→开授权轮换后旧结果丢弃；离屏Qt验证显示与朗读入口文本同文、同序、无双播。
- 探针安全3项：环境白名单阻断调用方任务租约/真实素材/模块注入/凭证继承；大量输出不堵塞Pipe；超时先终止、必要时仅强制回收测试自己创建的探针并确认退出，才清理临时目录。假生成器通过“首次选择已返回”的有界握手而非固定sleep证明非阻塞；真实Qt启动后确认没有任务跟随monitor。
- 人格2项：成功用户反馈保存并跨store/窗口重开，独立分享、撤销/重置与旧分享快照失效；48轮合成反馈后维度有界、历史30条、聊天记录有界，不学习助手回复/隐含情绪，不改核心身份或顺带创建记忆。
- 独立进程人格3项：7阶段验证明确反馈落盘→重启恢复/重复轮次不再写盘→独立分享→撤销分享与学习→再次重启仍关闭→只恢复本地学习→回滚→重置→重启仍不能撤销到重置前；3阶段验证48轮/30条历史重新解码、回滚和重置；2阶段验证损坏资料在新进程内读取/反馈/开启分享均拒绝且保留原字节。每阶段通过同一XCTest可执行文件启动全新进程，父进程等待退出后核对带子PID和阶段名的回执；不复用进程内store/授权注册表。核心身份与另一宠文件逐字节不变，不顺带创建记忆；这证明存储与授权的跨进程闭环，不代表正常产品启动/UI、异常断电恢复、多进程同时写入或长期自然人格质量验收。
- Qt项需要已准备的`.local/pet-build/venv`及固定来源补丁源码；环境缺失时明确标记跳过，不能算通过。纯Python协议项不依赖Qt。离屏样式固定Fusion，不影响真实应用原生样式。
- 探针`scripts/fixtures/pet_ai_bubble_probe.py`是测试内部入口，不作为用户功能命令。朗读回执只证明生产入口收到了文本，不代表实际TTS合成、扬声器听感、真实定时器长周期运行或真人麦克风验收；另见下方真实合成语音结果。

## 合成真实模型验收

本轮已使用 **11/12次**，不再继续执行下面的付费命令；命令仅作复现入口说明，新的验收应重新确认范围和预算，不能清空旧账本。

自动回归 `scripts/test.sh` **不会**发真实模型请求。付费验收必须单独取得批准，本轮总上限12次、失败也计入，全部入口共用同一持久账本。不删除账本或锁文件重新获得额度，不自动重试。Key 只在进程内从既有 Keychain 读取，不输出到命令行或报告。

```bash
# 本轮已批准账本。再次执行仍消耗同一个总上限；不要作为日常回归反复运行。
export PET_ACCEPTANCE_APPROVED_MAX_REQUESTS=12
export PET_ACCEPTANCE_LEDGER="$PWD/.local/autonomy-acceptance-20261115/model-request-ledger.json"
apps/companion-macos/.build/debug/PetCompanion --acceptance-model
# 新版独立表达对照：另两次请求，不重试失败基线
apps/companion-macos/.build/debug/PetCompanion --acceptance-expression
```

`--acceptance-model` 固定3批×6条记忆语料、两组表达对照、一次日常气泡：共8次。记忆报告分别给出严格匹配的 precision/recall、逐字依据有效率、误自动保存比例、风险拦截比例与分母；`actualSaved=0`，自动保存只是隔离语料上的策略模拟，不写用户记忆。少量固定语料结果不能外推成通用准确率。

`--acceptance-expression` 使用新版本的独立合成问题，对照默认表达与实际适应层；报告字符数和文本，不把字符变少当成人格质量或自主意识的评分。

## 合成语音往返

```bash
python3 scripts/accept-pet-speech-roundtrip.py \
  --approved-model-requests 12 \
  --ledger "$PET_ACCEPTANCE_LEDGER" \
  --host-executable "$PWD/apps/companion-macos/.build/debug/PetCompanion" \
  --output-directory "$PWD/.local/autonomy-acceptance-20261115/speech-run-01" \
  --allow-speaker-output \
  --presentation-directory "$HOME/Library/Application Support/AnimeDesktopPets"
```

输出目录必须是新目录。脚本用系统语音生成固定的“二加三”等合成问题/参考音频，真实本地 ASR 识别、**保留原转写**，通过隔离 Coordinator 的生产聊天路由请求模型一次，再把同一回复交给实际气泡呈现和本地 TTS，等待扬声器输出排空及子进程关闭。失败不重试、不替换识别文本“凑通过”。

省略 `--allow-speaker-output` 时仍实际合成，但只静音排空；不得称为扬声器验收。全程不打开物理麦克风；真实录音手感、音色听感、多屏/Space/焦点和长时间资源表现仍需独立验收。当前语音环境仍依赖源码 checkout，不是可独立分发的内置语音环境。

本轮确切结果、失败和未覆盖项以[实际验证记录](实际验证记录.md)为准。
