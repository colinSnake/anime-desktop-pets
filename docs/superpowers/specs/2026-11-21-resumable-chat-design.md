# 按桌宠实例续聊

- 保留小话间与紧凑历史侧栏。列表只显示稳定会话编号、最后完成时间和箭头，不显示正文。详情按原聊天样式预览，点击「继续聊天」才切换到真实会话；上一个聊天的草稿不被替换，也不为切换而取消生成。续聊可返回当前聊天或打开其他会话，不新增 Tab。
- macOS 新业务根的 `chats.sqlite` 存按桌宠实例隔离的会话及完整问答。识别到准确的旧问答结构才原子清除旧表并启用新结构；不迁入旧记录、不手工操作用户本机数据库。未发送草稿仍仅保存在窗口内。
- 打开详情、继续聊天和切模型均不发请求。只有显式发送才将当前问题和本会话有界的普通问答发给所选模型；允许跨已保存模型回放。服务从 SQLite 按实例和会话读取，不接受 renderer 拼接的持久上下文。附带角色授权资料的回合、疑似凭证、本机命令、失败和取消不进入回放；当前问题的既有逐项授权仍由服务重新核对。原轮次重试与换模型后重发原问题沿用逻辑问答 ID；已保存的回复直接恢复，不追加或生成第二次。未找到已保存结果时，才向明确选定的模型发送。清空历史不清窗内草稿，其他会话草稿由聊天选项独立恢复，不复用已清空的会话。
- 列表每页五条，使用边界位置的不可变问答 ID 按实例翻页，详情默认显示最近六个完成问答，旧页使用会话内不可变问答 ID 翻页，单页最多六轮。只保存最新预览、当前页与游标栈；续聊始终使用最新预览，旧页正文不进入实时对话状态。回放至多五个合格问答，继续遵守字数和请求体预算。不新增依赖，不启动真实桌面、不发真实模型请求。
