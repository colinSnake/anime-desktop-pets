# `~/.adpets` 本机业务数据与聊天历史设计

2026-11-20。用户确认分两步：先改 API Key 输入；本规格记录后续的数据根、迁移和持久化边界。宏观设计已在 macOS 路径实现；现有安装必须显式确认迁移，直播功能未接线。操作方式和限制见[本机业务数据与聊天历史](../../本机业务数据与聊天历史.md)。

## 取舍与目录

参考 Ape Agent Harness 本机 `e3b36fb` 的 `ADR-018`（产品数据库与凭证分开）和 `runtime-deepseek`（运行器使用独立 `DSH_HOME`）。本应用没有 Ape 的任务和审批数据库，只借鉴边界：一个产品数据根，保留各模块已有的存储格式。现在把现有配置全部改成 SQLite 会扩大迁移范围；复用 DSH 会话则混淆产品历史与运行日志，并扩大运行器可读范围，两者都不采用。

`~` 指运行应用的用户主目录，不指系统 `/`、Git checkout 或文稿目录。可信主进程解析数据根；服务做路径、所有权与 schema 校验，renderer 不传路径。

| 位置 | 权威资料 |
| --- | --- |
| `~/.adpets/models/` | 现有 schema v2 服务商、模型、默认值和 Keychain 引用。密钥正文不进入目录；沿用现有 macOS Keychain 标识和绑定校验。 |
| `~/.adpets/workspace/` | 现有实例注册表、工作区偏好、逐实例身份／记忆／目标。保留稳定 ID 与修订。 |
| `~/.adpets/chats.sqlite` | 本应用的逐实例、已完成聊天历史；SQLite 及该库的运行伴随文件同属一个库。 |
| `~/.adpets/live/` | 以后才启用的直播平台／房间配置。授权 token、Cookie 等不写配置正文，授权接线另行验收。 |

Electron 缓存、窗口进程资料、视频素材和 DSH 回合临时目录不迁入业务根。DSH 仍只读每回合专属临时工作区，不接触 `~/.adpets`，不因新增历史而开启 DSH 持久会话、上传日志或恢复未完成的请求。私有根目录在 macOS 用 `0700`，持久文件用 `0600`，拒绝越界、符号链接和不可信所有权／权限；其他平台未通过等价权限验证前不启用。聊天数据库是受本机文件权限保护的内容，**不是加密保险库**，不做云同步。

## 现有配置与显式迁移

1. 新安装无旧工作区数据时，使用新根。已有安装继续以 `${appData}/AnimeDesktopPets/cross-platform-dev` 中的本产品数据为唯一写入源，直到用户显式确认迁移；迁移不导入 Swift 宿主、Ape、DSH 或 Codex 数据。如两处都已存在且没有明确选定状态，停止切换并提示核对，不合并、不择新覆盖。
2. 迁移期间禁止原应用业务写入，核对服务已停写且持有源／目标的独占迁移权；不能取得则不迁。只复制已识别的本产品配置与资料，校验 schema、稳定实例 ID、版本、凭证引用与目标文件权限。不会提取或重新写入 Keychain 正文，也不会据引用断言真实授权已通过。当前只有内存聊天，不存在可搬移的产品会话库。
3. 在目标同卷私有暂存目录完成校验后原子发布；只有发布确认后记录选择并从新根重开服务。保留旧目录作为备份，不删除、不双写，不按文件逐项回退。结果不明时只做脱敏核对，写入保持封锁，直到可确认唯一权威根；失败不覆盖源。重开后若已选的新根不可用，报错而不是把它当成空安装或回退到可能过时的旧资料。

## 聊天首版：保存已完成轮次，仅用于回看

- 本地服务是唯一写者。按稳定桌宠实例 ID 隔离，以回合 ID 去重；使用有版本的 SQLite schema，在短事务中原子提交已确认的用户正文和最终助手回复。不开放 renderer 任意追加正文的接口，不用 SDK 的 session ID 作产品主键。自动化验证使用合成资料和临时根。
- 仅持久化成功完成的普通聊天；未发送草稿、取消／失败／结果未知的在途请求、本机资料查询的回答、记忆卡片、推理过程、请求载荷、Key 或模型连接响应原文均不落库。数据库故障区分「回复完成」和「历史写入未确认」，不为修补历史而重发模型请求。
- 分页只读当前有效实例的已完成轮次，保留现有正文大小门禁。重开后历史可回看、可清空，但不是线上上下文；当前窗口对同一路由的有界上下文规则不变。清空要求用户确认，不与在途发送竞争，持久清空成功后才清除对应展示；删除实例后不再允许从产品入口访问其历史，不自动清理用户未授权删除的内容。

## 分步验收

1. **目录与迁移：** 使用临时用户目录验证新建、保留原安装、冲突不覆盖、并发互斥、符号链接与权限拒绝、发布失败有原数据可用、重开不回退。改「打开工作区数据目录」时保持固定无参授权，不暴露读写路径接口。
2. **聊天持久化：** 验证重开和分页、跨实例拒绝、原子写入与去重、已取消和本机资料查询不入库、明确清空、落盘失败、资料损坏不覆盖、旧聊天不出站。再使用有授权的隔离 Electron 窗口验证。不会自动访问真实账号、厂商或 Keychain。
3. **直播：** 单独设计配置保存与授权；仅靠建目录不算直播接入。
