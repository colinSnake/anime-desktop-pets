# 桌宠 Agent：小话间内的统一角色工作台

**状态：第一阶段统一面板和第二阶段聊天内记忆确认已实装。** 第三阶段已在 macOS 使用实际 DSH 执行完整合成文字回合，替换只核销票据的旧探针，详见[实际验证记录](../../实际验证记录.md#2026-11-20桌宠-agentharness-执行合成文字回合)。不重新迁移数据，不增加 DeepSeek Harness 产品依赖或切换正式聊天路由。保留 [11 月 19 日的聊天编辑器与 SDK 探针记录](2026-11-19-pet-agent-and-composer-design.md)。

## 产品决定

**聊天是日常入口，Agent 面板用于查看和管理。** 用户平时直接和桌宠说话；只有想看它记了什么、改了什么或能做什么时，才打开「聊天 → ··· → 桌宠 Agent」，替换现有「角色资料」入口。不新增全局侧栏 Tab，不在桌宠舞台下恢复三个 Tab。独立 Agent 页会把聊天与角色活动分开；四个横向 Tab 则复现原先的分散体验，因此都不选。

### 总览线框（示例数据）

```text
聊天 · 龙妹                                   ···
                                      ┌──────────────────────────────────┐
                                      │ 桌宠 Agent                    × │
                                      │ [龙妹头像] 龙妹      ·  资料仅本机   │
                                      │                                  │
                                      │ 待你确认                         │
                                      │ 「偏好简短回复」        查看  › │
                                      │                                  │
                                      │ 身份      当前设定            › │
                                      │ 记忆      个人记忆 · 角色知识  › │
                                      │ 目标      写完读书笔记 · 1/3   › │
                                      │ 能力      本机查询 · 在线聊天  › │
                                      └──────────────────────────────────┘
```

宽窗右侧面板，窄窗全宽；一屏显示摘要，没有内容就不放解释卡。没有待确认项时隐藏「待你确认」。「资料仅本机」只在没有任何资料获在线授权时显示，不代表在线聊天不可用。点行后在同一面板深入详情，返回保留总览滚动位置；关闭回到聊天，不清输入、不切换舞台、不取消回复。关闭动作为右上角无边框 ×、Esc，或点击宽窗左侧遮罩；点击遮罩不触发背后的导航。面板绑定**打开时的聊天实例**；换实例时先退出旧面板，不把旧编辑草稿或审核按钮指向新实例。只有头像和浅底装饰随角色换色，按钮、状态色和结构一致。龙妹首验，大肥鱼和分身复用。

| 区域 | 看什么 | 谁能更改 |
| --- | --- | --- |
| 身份 | 当前设定、语气、关系；历史收进详情 | 用户可编辑／恢复；Agent 日后可拟修改，不能直接生效 |
| 记忆 | 个人记忆和角色知识；来源与审核在单条详情 | 已确认内容才可召回；推断是候选，不是事实；默认不加入在线上下文 |
| 目标 | 当前目标和下一步，展示 `已完成 / 总步数` | 用户标记进度；Agent 可拟步骤，不自动执行或标完成 |
| 能力 | 当前实例可用的本机查询、在线聊天及权限状态 | 权限由应用与用户决定，不是 Agent 可以自改的资料 |

## 服务与数据边界

- **角色模板 ≠ 桌宠实例 ≠ 聊天回合。** 素材包只提供共用封面、默认角色设定；每个实例以现有不可复用 `petID` 关联身份版本、记忆、目标和授权。复用 `apps/app-service/src/characters/` 的私有库、修订校验与固定桥；首阶段只在 UI 聚合，不复制或批量搬迁记录。
- **先走本机，再考虑在线。** 现有显式本机查询继续独立回答，不进入模型历史；普通在线文字仍通过已保存模型路由。每轮出站前复核实例、模型连接版本和逐项授权，新提案默认本机；撤回授权只影响未来请求，无法撤回已发送给厂商的正文。
- **提案不是写入。** 现从「记住：我偏好简短回复」起步：在龙妹的会话下显示原文、实例和「保存为记忆／忽略」。若后续开放其他提案，身份修改需展示前后差异，目标变更需列具体步骤。应用而非模型绑定当前实例、来源发言 ID、目标条目及预期修订；确认前复核，冲突不合并，结果未知先重读而非重复提交。只有确认写入成功才显示已保存；用现有版本／撤回能力处理回滚。不根据闲聊自动认定事实，不后台调用模型做审核。
- **Harness 不拥有数据。** 未来可在服务侧引入有界的 DSH 适配器，一次仅绑定一个实例／活动回合、一条已保存模型路由；凭证留在可信服务，SDK 只接有界模型中转。默认没有命令行、任意文件、MCP、子 Agent 或后台任务。上游架构会将模型可见输入纳入会话日志，故必须单独证明无持久化正文或可用经验证的临时存储、退出回收以及崩溃残留边界；不满足则不上线。没有确认停止／请求结果时不自动重发、不切旧路由补发，不把候选运行时变成第二个资料写入者。

## 分段与验收

1. **先做统一面板**：复用现有详情、固定桥、聊天与资料。合成测试覆盖龙妹与另一实例、空态／加载失败、键盘开关和回焦、窄窗、打开面板不卡住回复。确认原有身份历史、逐项授权、记忆审核和手动目标进度不丢。不出现旧资料交接入口。
2. **再接可审核提案**：先本机识别显式「记住」语句，无需 SDK 或额外在线请求。验收拒绝无写入、重复确认不重复保存、冲突／未知先重读、跨实例隔离、默认不出站。之后单独评估模型提出的身份、目标或记忆候选。
3. **最后评估 DSH SDK**：沿用隔离回环探针而非直接托管聊天；用合成模型单验事件顺序、同实例并发、取消／退出、崩溃后的结果未知、凭证／网络／日志和工具拒绝，再决定是否接入。保留当前直连路由；不把探针通过记录为生产可用。

## 第二阶段实装：聊天内确认

- **明确触发，不发给模型。** 用户提交「记住：我偏好简短回复」这类显式指令。输入区先标明「本机记忆 · 不发送到模型」；只识别明确命令，不从闲聊推断。明确意图但内容不合要求时就地说明，不回退成在线发送。
- **确认卡紧挨触发消息。** 显示当前实例、拟保存内容和「保存为记忆／忽略」。关面板和换实例均不是确认；候选跟随触发发言所属实例，未保存内容不落盘。「保存为记忆」就是一次明确的人审，不要求去 Agent 再确认一遍；「忽略」不写入。
- **只在确认写入后显示「已记住」。** 提交前复核实例、消息来源、重复和资料修订；一次原子写入，默认无在线授权。冲突或结果未知时先重读，不自动合并／重发。撤销不能覆盖后来人工编辑。暂不处理身份或目标提案、模型推断、后台审核或 SDK。

实装使用「记住：」或半角冒号，正文为不超过 300 个字素和 4096 个 UTF-8 字节的单行非空文本；拒绝疑似凭证。原话去除首尾空白后按「事实／聊天确认」写入，不推断分类。提案随有界聊天记录保留，未确认不落盘、不进入 Agent 的待审核列表。确定冲突可在显式重读后重新确认；结果未知只允许重读核对，读到记录也不等于持久写入确认。没有一键撤销：从 Agent 的「记忆」使用现有版本受控的撤回确认或删除。
