# 桌宠有边界的自主表达与验收

## 已批准的目标

用户批准继续落地记忆提取、语音往返和人格演进，并增加日常 AI 提示气泡。首轮最多 12 次额外真实模型请求（失败/超时计入、不重试），仅发送合成样本，不读历史聊天或私人记忆。此次批准不是默认开启无限后台服务。

## 产品闭环

1. 日常气泡走独立开关，默认关闭。仅发送 idle/interaction/reminder 枚举事件；不发送本地气泡原文、身份、任务、记忆或历史对话。只生成一句不超过 60 字的陪伴文案，不声称任务完成、不提供外部事实、不含工具调用。失败/拒绝/超时继续本地文案；不得阻塞 UI 或在旧情境恢复后插入迟到气泡。
2. AI 气泡每 10 分钟最多一次、每日最多 12 次，失败也消耗额度，预算落盘再请求，重启不清零；禁用时取消待处理请求，回调再次核对授权和情境。模型不配置时只用本地文案。生成文案与朗读同源，沿用互动朗读开关。
3. 人格保持稳定身份与安全边界；适应层只允许表达详略、活泼程度、建议主动性。基于明确用户反馈在本地自动调整，有逐字证据、原因、时间及修订。关闭后不再学习、不注入；可回滚最近调整/重置；适应层分享独立默认关闭。不能从模型自评、引述、否定、提示注入推测偏好，不能修改姓名、背景、价值观或边界。
4. 真实模型验收以固定合成语料统计提取 precision/recall、逐字依据有效率、误自动保存及风险拦截；明确分母与失败。验收入口没有工具、没有重试，先持久预留预算再发送。不要用私人配置以外的资料，也不写用户记忆。
5. 语音用合成音频走真实本地 ASR、真实在线回复和真实 TTS/输出排空，记录阶段耗时与异常。物理麦克风/主观听感仍单列未验收。自动化不代替真实桌面矩阵。

## 实现边界

macOS 13+；沿用 Swift CharacterCore/CharacterMemory/CharacterUI/PetCompanion 和 Python helper。通用功能采用 pet 命名。既有改动保留；未经要求不提交。增强 helper 发布必须固定上游并携带已审核本机 SSRuanTangTi 字体后重建并验签。变更记录同步中英文 README 与实际验证记录。
