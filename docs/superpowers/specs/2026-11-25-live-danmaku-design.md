# 直播管理：弹幕演练

管理页按「舞台输出 → 布景与摆位 → 主播互动」全宽堆叠，沿用项目浅／深主题。主播互动顶部保留三个手动动作，下方为弹幕输入区，保留圆角编辑器、发送箭头与清空，不显示已发送弹幕、回复正文、Enter 提示和字数。只模拟弹幕来源，不模拟回复；开台自动准备好声轨后按普通 Enter 或点发送箭头显式发送，中文输入法确认候选、空白、未就绪或处理中均不提交。只在舞台确认接受后清空草稿；提交失败或未确认保留原文，可手动清空而不发送。回复只在节目画面呈现；未开台时发送不可用，不显示说明；管理页保留处理和失败提示，不显示停止演练按钮。调用模型与可能计费的说明移至本机直播台使用指南，不在输入区常驻。不改变布景选择行为、角色选择或舞台 URL。

只有可信桌面主进程能调用内部路由。每次将一条有界观众输入及固定公开的龙妹主播人设、提交时的布景名称交给现有 Pi Agent 和已保存默认模型。不附带聊天历史、私有角色资料、附件或工具；输入不存盘、不入聊天。生成失败、回复越界或合成失败都不发布，不回退到预设。生成路由只向主进程发一次性短时凭据，合成路由只能用它合成原回复，不接收任意文本。TTS 复用本机音色及排他门禁，不打开播放设备。

同一时刻处理一条；手动动作播放期间不启动新演练。切景不中断处理；手动触发动作、关台或全局暂停可撤销演练，迟到结果不能上台。管理窗口隐藏或离开页面时取消进行中的演练。字幕和音频只在同时就绪后一起短时发布给现有只读节目源；节目浏览器在动作首帧和语音启动均成功后才亮字幕。管理页状态不等于已确认 OBS 播放。真实平台接入、回发与观众数据出站授权另行设计。
