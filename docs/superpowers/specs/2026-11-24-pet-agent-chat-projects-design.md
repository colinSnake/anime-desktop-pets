# 桌宠 Agent：项目、会话和输入区权限

用户已确认：取消独立任务弹窗；聊天侧栏按实际文件夹组织会话；输入区加号右侧用截图布局显示权限菜单，其中 ChatGPT 替换为当前桌宠名称。保留自由聊天及历史；不搬 Ape 的运行时、设置面板或全机权限。

- 项目使用系统选择器选父目录并新建文件夹。仅可信主进程读原生返回路径；服务私有索引保存项目记录，renderer 仅见编号和名称。目录准许创建，不附带读取、递归扫描、联网或修改权限。项目按桌宠实例隔离。现有历史不搬、不清空；新会话先是内存草稿，首次安全完成后进入对应项目。
- 聊天沿用一个编辑器、模型和发送按钮。默认「请求批准」；带材料发送前在消息区确认，允许才送出，跳过按纯文字发送。「完全允许」经菜单内短确认，仅适用于当前草稿、模型及材料，下一轮恢复默认。真实文案保留截图信息层级和布局，不承诺全机访问。材料许可绑定完整回合摘要、短期、一次性；服务在模型调用前拦截缺失或不匹配的许可。
- 纯文本材料复用既有有界只读工具，片段经过用户动作授权才出站；既有图片／PDF 保留模型能力校验及本轮发送范围。不使用 Shell、项目扫描、任意文件读写、外部工具或后台自动执行；材料不进入普通会话回放。已有独立任务记录原样保留。
- 人格来自可信桌宠包预置及已授权的当前角色身份。名字、性格和说话方式沿用身份面板；人格不授予能力。身份、记忆、知识与目标继续逐项授权、按当前实例隔离。新会话不回放旧会话，项目名和路径不进入模型请求。

验收：新建项目 → 新建会话 → 添加合成文本 → 聊天内批准／跳过 → 同一聊天收到结果；另测无授权、跨会话／改材料、重复许可、隐藏窗口、迁移旧历史、浅深主题与窄屏权限气泡。
