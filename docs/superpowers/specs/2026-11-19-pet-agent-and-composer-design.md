# 桌宠智能体与聊天输入框设计

2026-11-19 · 方向已确认；各切片的实现和验收见[实际验证记录](../../实际验证记录.md)。

- **角色资料是低频管理入口，不是三个一级导航页。** 聊天 `··· → 角色资料` 打开当前聊天实例的面板，保留身份、记忆（含知识）、能力与目标的编辑、审核、授权和恢复。绑定聊天对象，不绑定桌宠舞台。关闭返回触发处，不切页、不取消当前聊天。保留固定桥和原数据；无有效实例不可进入。
- **输入体验与执行解耦。** 以 Ape Agent Harness `7be8b9c` 的 `TaskComposer`、`editor/runtime`、`draft` 和键盘策略为机制参考，保留「小话间」样式。先采用独立 Lexical 纯文本编辑器、语义选区、历史与有界提交快照；草稿仍按实例留在本次应用会话内。Markdown 预览已在此底座接入；结构化引用后续扩展，文件必须先有只读授权与发送契约。不移植企业工作台、Skill/MCP/子 Agent 或没有真实模型参数支持的设置。
- **另行验证 DSH 文本回合。** 候选为 Ape 固定的 `@deepseek-ai/dsh-sdk-client` 与 `@deepseek-ai/dsh` `0.2.2-rc.5`；只在服务侧隔离适配，renderer 和领域层不依赖 SDK。保留原多厂商聊天和本机查询，不做自动失败回退。独占可回收运行时，工具、MCP、插件和子 Agent 默认拒绝。先验合成模型、收发事件、取消、进程回收与未知结果不重放；真实联网另需授权。
- **Agent 不直接操作角色库。** 后续可将用户明确给出的低风险偏好作为受限提案保存并提供撤销；推断只进候选，身份、知识、目标完成须确认，能力不授予。服务复核实例、修订、证据、重复/敏感、写入结果及撤销版本。新记录的在线分享关闭；审核不在后台额外发模型请求。此设计不是 Agent 自动写入准入。
