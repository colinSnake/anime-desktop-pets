# 直播换景交互与音频故障定位

**目标：** 不改变节目监听或舞台布局，修复管理页换景闪动，整卡选景、独立图标预览，定位龙妹声轨在本机或 OBS 的失效边界。

- [x] 用延迟换景夹具复现输出区/下方卡片位移，增加布景选中和独立预览、键盘焦点回归。
- [x] 直播页将换景反馈放进固定高度区域，避免清空输出反馈或临时变更其他控件样式；保存确认前保持旧选中。错误仍须明确并支持重读。预览图标在卡内与选景分离，保留预览组件和当前主题。
- [x] 用合成参考音频跑本机语音服务与节目播放器；只读检查 OBS 浏览器源设置。若能复现产品故障，先补失败测试，再做针对性修复；否则明确区分声轨已准备、混音器电平和本机耳机监听，不改 OBS 配置。
- [x] 复测浅深色及窄窗口、原节目 URL 与音频撤销链路，更新中英文 README、使用指南和验证记录。不打开或重启现役 Electron/OBS，不读取参考录音，不推流。
