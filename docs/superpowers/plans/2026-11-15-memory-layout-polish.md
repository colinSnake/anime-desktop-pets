# 记忆工作区布局修正实施方案

**目标：** 以现有桌宠页面为视觉基准，修复个人记忆/角色知识页底部裁切、边距叠加及按钮不统一，移除知识文件导入交互。

**设计依据：** 用户本轮两张截图。问题一为表单固定在外层、只有列表滚动，压缩窗口时列表视口被挤到不足一行；问题二为外壳24pt与页面20pt边距叠加，标题与内容错位；问题三为独立蓝色按钮与桌宠页26pt/11pt小按钮不一致，长说明不能完整换行。

**架构：** 保留AppKit宿主与SwiftUI页面；页面改为单一纵向滚动区域承载概述、资料切换、自动审核、添加表单和记录列表。沿用桌宠页控件尺寸/配色，将公共按钮样式提升至CharacterUI让宿主和记忆页共同复用。不改记忆审核、分享授权、存储格式及既有用户数据。
