# 桌宠 Agent 项目化聊天实施顺序

依据已确认的 `../specs/2026-11-24-pet-agent-chat-projects-design.md`，在当前工作区保留已有未提交改动，不提交或推送。使用 pnpm。

1. 固定材料授权：测试请求未授权、错绑、重复和跳过；`online-chat.ts` 契约增加固定授权调用；服务端短期摘要门禁加入出站流程，复用只读材料工具；既有直接附件验证保留。内置人格与资料授权分离。
2. 单一聊天入口：测试权限选择、内联允许／跳过、发送范围冻结、切换时撤销。移除工作区对独立任务面板的入口，仅保留旧记录；实现截图菜单和名为当前桌宠的标题。
3. 项目会话：为现有 SQLite 增加私有项目与会话归属，测试原历史不动、归属不串、拒绝未知项目。固定 macOS 原生桥创建目录，renderer 只接收标识和名称；复用现有会话控制器和聊天历史读取。
4. 验证：启动本地合成 Web 夹具对照权限菜单，验证项目会话、授权和结果在同屏，运行 `pnpm run check:cross-platform` 与 `git diff --check`，更新 README、设计及实际验证记录。真实桌宠、模型、Keychain 和系统文件选择器不参与自动化。
