# 旧角色资料最小交接实施计划

任务三只交接单个实例的当前身份、记忆和目标；复用已有预检与角色仓库。以空角色资料为前置，不提供覆盖、合并、多实例批处理、旧历史迁移或配置向导。原目录不写不删，仍由用户保管。

- [x] 先测试角色仓库：整批原子导入、只接受空目标和匹配的修订、记忆进入待审核且全部不继承授权、保留目标步骤完成状态、失败无部分记录。撤回只针对当前尚未编辑的导入批次，重启后可见，不倒退修订。
- [x] 接固定认证路由和可信进程传输。主进程把预检出的有界资料存为短时一次性票据，绑定目标实例和修订，预检只返回数量与可操作性；隐藏、重新导航、退出或改选时作废。引用 ID 和路径不从 renderer 进入资料读取。
- [x] 高级页沿用一处折叠区，显示目标、报告及显式确认按钮；删掉旧权限占位。提交结果未确认时只重新读取状态，不自动重试。角色编辑页复用读取流程更新缓存，保留当前草稿。
- [x] 验证新增回归、隔离跨平台全量、项目及差异检查；更新文档。不读取或删除真实资料，不动模型或播放器。
