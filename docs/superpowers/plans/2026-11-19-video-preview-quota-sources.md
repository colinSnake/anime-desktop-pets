# 独立视频桌宠迁移额度来源

目标：恢复旧桌宠右键「查询额度」、双击和卡片刷新。先做独立预览的完整链路；工作区 Qt 保留现有注入边界，冻结 helper 与生成源码保持原样。

1. 先以临时 TOML、SQLite、合成 HTTP 和假 CLI 写失败用例。迁移两条只读来源：官方 `account/rateLimits/read`；匹配当前 CC Switch 使用模板的 TiMi CC HTTPS GET。中转失败不改查官方。限定响应、时限和权限，只返回项目已有的额度结果结构。
2. 先扩展 VM 回归，再接主进程的显式菜单、双击、刷新与关闭。复用 `PetQuota` 的单槽、超时和失效逻辑，取消时回收预览自有查询进程。脚本随临时构建复制，不对 renderer 的媒体协议公开。
3. 在视频窗口内呈现轻量额度卡片：剩余百分比及重置时间，或 TiMi CC 的金额与币种，另有查询时间、固定失败反馈、刷新与关闭。继续按视频 Alpha 判断角色交互；卡片区域只接收自身交互。拖拽、关卡与退出取消查询，关闭后不显示迟到结果；使用主题变量，不发语音。
4. 跑合成额度、预览构建、跨平台与相关可信离屏回归，更新中英文 README、迁移／开发文档与实际验证。真实账号、余额、桌面窗口与已有桌宠均不用于本轮测试。
