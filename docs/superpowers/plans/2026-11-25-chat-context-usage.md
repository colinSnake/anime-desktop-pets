# 聊天上下文 Token 用量实施计划

> 实施按下列步骤逐项验证，不自动提交、启动 Electron 或调用真实模型。

**目标：** 悬停聊天输入框或用键盘聚焦圆环时，显示当前会话、当前模型最近一次成功在线请求的实际输入用量。

**设计：** 沿用聊天模型列表和成功回包，不增加 IPC、轮询、计费请求或数据库字段；用量只留在本次运行的会话窗口内。上下文容量仅来自保存的模型配置，缺失时不推算。样式参考用户截图，以工作区浅／深主题变量呈现。

- [x] 先加契约和合成服务回归：确认仅透传输入用量和已保存容量，材料工具回合采用最终模型请求，恢复历史不含用量。
- [x] 先加会话和 UI 回归：校验桌宠、会话及模型隔离，本机查询／错误／取消／历史恢复不覆盖，新成功且缺统计时清掉旧值；校验有无容量的显示与无用量状态。
- [x] 为契约、服务、会话和输入框实现最小变更。用已有回包更新，悬停和键盘聚焦不发请求，Escape 收起气泡。
- [x] 运行定向及跨平台检查，复核浅／深模式、窄窗与键盘交互；更新聊天验证指南、两份 README 和实际验证记录。
