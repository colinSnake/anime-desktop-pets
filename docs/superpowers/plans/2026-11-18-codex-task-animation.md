# Codex 本机任务状态驱动自有桌宠工作动画

**目标：** 继续 [T01](../../macOS功能迁移清单.md)，把上一段共享读源经服务内租约送给本工作区已确认首帧的自有播放器。沿用 prepared Qt 的工作差分、固定气泡及交互门禁，保留旧宿主与冻结文件。

1. 先为任务采样到自有实例、重复／迟到结果、加入现有任务和停止门禁写红测。菜单仍只看枚举，任务状态不进 HTTP、renderer 或配置。读源重建时开场序号不回退；新实例加入时只跟随当前状态，不补播旧开场。暂停、显式停止读取、探针不再确认和退出撤销。
2. 用已有 guardian／播放器私有版本 3 通道新增严格 `task-animation` 帧，只接受固定枚举、开场序号和短有效期。动画有独立的单个在途确认以及一个可覆盖的最新待发送状态，不抢占显示／行为命令或停宠确认。卡顿或确认缺失时不无限排队；过期工作状态不在播放器重新生效。只由逐实例生命周期调用；高级诊断播放器不接。
3. Qt 侧只在 GUI 线程复用现有姿态/气泡函数，不开启旧任务监听、读 Codex 文件或引入任务身份。重复快照不重开；未知最多保留到最近确认的短有效期，不报告完成；停止读取立即清除任务门禁及自有工作气泡，姿态等交互空闲再回待机。拖拽、松手弹簧、手动气泡、菜单、隐藏和减少动态效果优先。加合成工作素材及离屏实测。
4. 跑任务读源和进程、完整 pnpm 跨平台、可信 Qt Fusion 离屏、项目和空白检查，记录当前结果。未验收真实桌面、真实 Codex 会话或素材，暂不退役旧宿主。
