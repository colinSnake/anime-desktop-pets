# 合成模型验收预算账本实施计划

依据[独立多厂商设计](../specs/2026-11-16-model-management-multi-provider-design.md) §5.1 和 Swift `ModelRequestLedger`。在 `apps/app-service/src/models/acceptance-ledger.ts` 迁移内部预算边界，在新隔离私有目录中固定同一验收路由的 **12 次总预算**，记忆批次、表达、语音和气泡共用。该账本不计算实际 token、费用或日用聊天额度。不改 Swift 账本，不自动读取或重置历史；不得以创建新账本延长既有验收的授权。本批不迁移真实验收 runner，也不接 CLI、HTTP、IPC、页面、日常聊天、发现或连接测试。

1. 先写 `apps/app-service/test/model-acceptance-ledger.test.ts`，以临时目录、合成路由指纹和注入操作锁定接口。检查：无明确 12 次授权不初始化，普通读取和执行不隐式创建；四种固定用途共享计数；固定路由变化时拒绝；不接受任意用途文本；操作失败或取消仍消耗，重开连续编号，第 13 次不调用操作。
2. 沿用 `PrivateDirectory` 的私有权限、ACL、符号链接／硬链接／非普通文件拒绝；增加不创建目录的可选模式。调用方提供一个已存在的私有验收目录；仅显式初始化能建立账本，先持久保存包含随机运行标识和路由指纹的守卫，再原子发布绑定同一标识的 v1 数据。用途只保存固定标签和序号，不保存提示、实际地址、模型正文、凭证或厂商错误。读损坏、缺单边文件或未知版本一律拒绝，不能重设预算。
3. 同一实例排队；同目录跨实例以独占写锁拒绝并发写者，崩溃留下的锁不抢占。写入有界数据到同目录私有临时文件，文件同步、复核读取版本和守卫、原子改名、目录同步；仅确认落盘及释放写锁后执行一次注入操作。写入结果不确定时不发送、不自动重试；若已发布则保留该次用量。新增并发、故障注入、权限、损坏和重开回归。操作在锁外执行。
4. 验证一个四协议共享请求核心的合成出站案例，确认落盘早于注入传输、不会切到默认厂商，且无真实 Keychain 或服务。运行定向、跨平台、可信 Qt 离屏、项目和 diff 检查；更新中英文 README、迁移清单、开发文档、路线图、交接与实测记录。不启动真实桌面，不提交或推送。
