# 直播舞台实施计划（最初三景）

依据《桌边小崽直播台》第 4 节与 2026-11-25 确认的画面：暮色小屋（默认）、雨夜阁楼、云海露台。以提供的分层原稿为构建输入，仅导出原创房间／前景；龙妹取自现有锁定原片，不能烘入布景。仍是一场本地舞台，停台后选景，各场景独立保存位置与缩放。管理页负责控制；隔离预览与 OBS 读取同一只读页面。

1. 写契约、会话、存储及传输回归。导出素材与浏览器舞台；确认两态尺寸、桌沿遮挡、固定安全区及媒体代次。
2. 接可信服务的原子配置与固定 Electron IPC；只允许本机回环、临时地址、有限只读路由；启停与全局暂停和退出协调。工作区加入布景缩略图、滑杆、保存、输出、三动作、模拟一次；保留折叠的平台草稿。
3. 用离屏浏览器验证三景两态；运行范围测试及 `pnpm run check:cross-platform`。更新中英文 README 和实际验证记录。不启动正式桌宠或 OBS、不推流、不提交。
