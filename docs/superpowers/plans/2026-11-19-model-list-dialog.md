# 模型列表与添加弹窗实施计划

以 `ape-agent-harness` 本机模型管理最新改动 `22d0535` 为参考，在离线浏览器重渲染该版本核对，不使用旧截图。此轮调整模型管理入口，独立多厂商设计原稿、schema v2、安全凭证和聊天路由不变。

1. 先写回归：已保存模型按稳定条目 ID 平铺；未保存草稿不进入列表；单条删除使用已保存修订，删除默认时明确替换或清空；保存后测试仅在明确选中且收到保存确认后进行。
2. 实现「第三方模型提供商／自定义模型 API」两个独立草稿、折叠参数、同连接批量新增；编辑、测试及删除在弹窗操作。使用原生对话框管理焦点；沿用现有主题变量和固定桥，不增加 renderer 密钥输入。
3. 跑模型和主题回归、跨平台检查和项目检查；用合成数据离线核对窗口、键盘和窄屏，按实际执行记录。Qt 由独立会话处理。

参数区细化：根据当前参考源码，将常用参数独立成默认折叠的四字段区域，保留鉴权、逐模型能力与双层默认。新增条目聚焦模型 ID；编辑时从「已保存连接」追加同连接条目。叉叉沿用主题的中性焦点状态；只有按下和释放均落在弹窗外的遮罩上且未锁定时才作取消。先用合成数据复现旧交互，再验证窄屏和保存边界。
