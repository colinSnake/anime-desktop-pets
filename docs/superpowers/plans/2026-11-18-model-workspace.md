# 多厂商模型迁移第四段：离线管理页与可信凭证输入

以 `92ba7f5` 及工作区第三段未提交实现为基线，沿用独立设计的连接／模型层级。macOS 新栈只开放本地管理；发现、连接测试、聊天选择与正式发送保持禁用。Windows/Linux 管理页明确不可用。本段不接触真实 Keychain、剪贴板、账号、在线模型或桌面，不提交／推送。

- [x] **可信输入与 IPC。** 先覆盖固定方法与参数、顶层窗口、无权读取 clipboard、过期／取消、当前原生菜单目标与并发。普通保存允许保留或解除凭证引用，IPC 禁止替换正文。特殊保存只提交不含密钥的已验证草稿；主进程保留一个短期操作，原生应用菜单显示绑定的目标 origin，仅用户选择菜单且窗口仍可信时读取剪贴板文本并发起同一次原子保存。剪贴板不是应用的凭证存储，程序不缓存／回显／清空它。导航、退出、取消或超时撤销等待；提交一旦发出，仍以服务回包为准。地址／协议变更不复用已保存的 Key；用户需明确解除或替换。先补失败回归。
- [x] **页面与状态。** 先测试两级折叠、独立草稿与稳定 ID、默认层级、协议兼容项转换、显式删除默认替代、无 Key 保存、跨页及失败保留。React 模型页使用共享工作区设计色与桌宠操作按钮高度；保存／删除／Key 操作均在卡片内说明与确认。加载失败不视为空；发生冲突或提交结果不确定后先刷新，保留旧草稿，显式采用最新版本才重试。预设只在新建时填入，暂无网络操作与模型推荐。
- [x] **验证和文档。** 使用注入剪贴板与服务、离线 UI 渲染、隔离目录和合成凭证，不启动 Electron／Qt 桌面。跑定向、完整跨平台、可信 Fusion/offscreen、项目和空白检查；更新 README、迁移清单、开发指南、路线图与独立本轮验证记录。

独立审查后补充逐连接删除版本、发布不确定后的只读核对与写入封锁。最终证据与未执行范围见[实际验证记录](../../实际验证记录.md)。
