# Electron 管理窗口位置与大小实施计划

**目标：** macOS 工作区在正常退出后恢复本应用管理窗口的普通窗口位置和尺寸；外接屏缺失时让窗口保持可操作。只由 Electron 主进程使用现有隔离 profile。不写桌宠配置，不操作 Codex 或旧宿主，不增加 IPC。

1. 在 `apps/desktop/test/workspace-placement.test.ts` 先写回归：默认中心、负坐标外屏、工作区变化、小屏和标题栏可达性；临时 profile 覆盖私有文件、坏数据、超限、链接及未知版本保护。先确认红测。
2. 在 `apps/desktop/src/workspace-placement.ts` 实现屏幕几何和小型 schema v1 侧车文件。读取有界且失败安全；临时文件与目标同目录，限制权限并原子替换。正常退出仅保存有变动的普通窗口矩形；不可识别文件留原样。
3. 在 `apps/desktop/src/main.ts` 接入启动读取、隐藏窗口重新打开时的不可达修正及正常退出保存。窗口不自动进入全屏或最大化；显式恢复前仅处理应用拥有的同一窗口。非 macOS 暂用现有规则。
4. 用临时目录复测，运行跨平台、项目和受影响的可信 Fusion/offscreen 检查。记录真实多屏、Space、Dock 及窗口管理器行为待验收，不打开真实桌面。同步中英 README、迁移清单、开发文档、路线图与实际验证记录。不提交或推送。
