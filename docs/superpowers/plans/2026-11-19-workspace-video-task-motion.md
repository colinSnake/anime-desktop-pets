# 工作区视频任务动作迁移计划

**目标：** 按[视频迁移验收清单 V08](../../Electron视频播放器迁移验收清单.md)将已授权的任务状态投影接到 Electron 视频窗口，不让任务调度抢占交互。

**边界：** 默认仍保留现有播放器直到功能等价。任务读取仍由既有本机会话授权管理，只有有界状态、序号和时限进入主进程，不向视频 renderer 传任务正文或授权。只迁工作姿态，本机语音、气泡与自主活动另验。

- [x] 在 `apps/desktop/test/video-task-schedule.test.ts` 先验证冷加入／新任务、有效期／未知状态、减少动态效果，以及按住、菜单、任务中真实松手和弹簧保护。
- [x] 在 `apps/desktop/test/workspace-video-lifecycle.test.ts` 先验证私有任务命令、启动代次、伪字段、已停或暂停窗口拒绝及迟到事件。
- [x] 在 `workspace-video-{protocol,client,host}.ts` 接入有界任务投影；同一已有启停代次内的独立命令不改变运行状态，也不影响松手保存。
- [x] 在 `video-preview/task-schedule.ts` 实现单调时钟及工作片段调度；`video-window.ts` 只在当前窗口、首帧和互动门禁满足时选择工作姿态。旧任务观察默认关闭，在显式视频会话中可用。
- [x] 跑定向与全量检查、隔离构建和旧拖拽离屏回归；更新迁移清单和 README，记录未做真实任务、桌面和语音验收。
