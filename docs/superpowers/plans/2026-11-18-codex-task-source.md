# Codex 本机任务读源与显式授权实施计划

**目标：** 让 macOS 新工作区可从原生状态栏单独选择是否读取本机 Codex 生命周期；保持单读源、无正文输出，并先提供真实的读取状态。依据[任务跟随范围](../../Codex任务跟随.md)、[迁移清单](../../macOS功能迁移清单.md)及[租约计划](2026-11-18-codex-task-lease.md)。

1. 为原生选择的服务端状态机和合成目录读源写红测。复用既有 `dragon_tasks.py` 的 Cursor、事件与预算，不改冻结源码。新读源逐级用目录描述符只读打开系统用户目录下固定 `.codex/sessions/YYYY/MM/DD/rollout-*.jsonl`，拒绝链接和非本用户项；重置、替换、截断和积压不得伪造新开场或完成。首轮检查扫描及读取上限。
2. 固定子进程协议须在明确授权、探针确认运行且当前租约有效时才启动或查询。受现有 stdin 监护；输出只含状态、计数和进程序号，服务检查上限、拒绝无效帧、串行且有超时。撤销取消并收尾，尚未收尾不创建第二个 worker。日志与环境不传会话内容或凭证。构建保留原解析器字节。
3. 通过主进程至 utility 的固定布尔命令打开或关闭，服务返回固定状态枚举，无 HTTP/renderer 桥。macOS 原生菜单确认授权范围，默认关闭；暂停、退出、服务失败不可继续显示旧状态。目的与既有纯存在性菜单分别标注；不接桌宠动画或扩大到自定义 `CODEX_HOME`。
4. 用临时目录、合成探针和真实子进程协议验证，不读取真实 Codex 会话。运行跨平台、旧任务解析、可信 Qt 离屏及项目检查，同步双语 README、任务专题、迁移及实际验证文档。保留旧宿主和冻结 helper，不提交或推送。
