# macOS 管理窗口屏幕变化恢复计划

**目标：** 管理窗口打开期间，外接屏断开或工作区变化后，若普通窗口的标题栏已不可达，自动移回当前可见区域。不改变仍可操作的窗口，不抢焦点。

**范围：** 复用 `workspace-placement.ts` 的 DIP 几何和原有保存基线；只处理本应用自己的管理窗口。隐藏、最小化、最大化与全屏窗口不直接移动；通过 Dock／菜单重开、还原、退出全屏或取消最大化时重新确认。继续使用 Electron 主进程事件，不增加 renderer、权限或外部窗口操作。
