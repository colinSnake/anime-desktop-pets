# 聊天内确认记忆 · 第二阶段实施清单

用户已确认[第二阶段交互](../specs/2026-11-20-pet-agent-workspace-design.md)，直接接入，不扩展智能体执行面。

1. 先建立红测：纯本机指令、实例与发言绑定、无确认不写和不发送；固定桥及服务验证单次确认、修订冲突、重复、凭证拒绝与默认不共享。
2. 复用现有记录桥、实例登记队列和原子仓库。新增仅接受实例、修订、发言 ID 和定长正文的固定操作；同实例内以发言 ID 标识新记录。候选仅保留于有界聊天，已确认且持久才显示成功；冲突显式重读，未确认写入只允许查看当前可见状态。
3. 在原聊天轨道放置确认卡和本机发送提示，保留既有选择器、草稿、回复和 Agent 面板；通过 Agent 既有编辑入口复核、撤回或删除。
4. 完成合成浏览器交互和截图、跨平台检查、验证记录与中英文说明。仅交付第二阶段，不打开 Electron、不访问厂商、不读旧资料。
