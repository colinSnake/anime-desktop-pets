# macOS 模型管理：显式连接测试

依据独立多厂商设计第 5、6 节。先交付使用已保存目的地址、协议、认证模式和凭证版本的生成探测。允许在当前连接草稿选用未保存的默认模型与输出兼容项；删除/替换 Key、改地址或协议、全新未保存连接须先保存。暂不增加临时 Key 读取入口或通用用量账本，旧合成验收账本不动。

1. 先用临时 profile、合成 Key、注入 transport 写失败测试：只选择点中的连接、按草稿模型和兼容项发一次有界生成、无聊天内容、无配置提交、限额/拒绝/无正文、缺 Key、版本变化和取消。四协议都用固定合成回复验证。
2. 实现固定测试契约、服务及可信主进程入口：只接连接 ID／版本及允许的模型项，不接受地址、Header、正文或凭证。只从隔离仓库读取选中的版本，第一次等待前固定快照，出站前复核版本，不重试。结果只返回固定状态与匹配标识，不返回厂商文字或原始错误。
3. 在原卡片新增内联计费确认和测试状态；确认前不联网。取消编辑、离页、修改测试输入或相应配置时取消／丢弃结果；单纯折叠保留测试。保存与测试结果独立。
4. 运行定向回归、跨平台、可信 Qt 离屏、项目和 diff 检查，同步 README、迁移、交接、路线图与本轮验证。真实 Keychain、桌面和可能计费的厂商调用留待用户另行授权验收。
