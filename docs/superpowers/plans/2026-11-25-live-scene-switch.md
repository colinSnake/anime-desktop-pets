# 本机直播台：不停台换景

**范围：** 本轮先交付龙妹舞台换景，同次开台的 OBS 地址和预览窗口不变。龙妹节目声轨在下一阶段单独接入，暂不改变静音输出。

1. 先补回归：固定场景 ID；写入失败不换画面；同一监听包含新场景与其已保存摆位；换景不中断/重播动作；停止不允许在途换景重启监听。
2. 在固定桥增加只接受场景 ID 的 `switchScene`。确认保存后更新当前时钟的布景，而不是重建监听；开台时只允许改选中场景，停台时仍显式保存摆位。读回未确认时不显示成功。
3. 节目页先解码新背景与前景，原场景继续显示，两个图层和摆位一起替换；换景与动作代次分离。控制台点名字换景、点图只预览；保留主题和布局。
4. 更新使用指南、README 与验证记录；做回环和离屏验证，不动现用 Electron、OBS 或本机配置。
