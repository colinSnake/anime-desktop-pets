# 桌宠 Agent：由 Harness 执行文字回合

沿用已经确认的新调用链，参照本机 Ape `facf5e2` 的 Worker → Runtime → Provider Bridge，不移植任务系统。替换只核销票据的开发联调；本轮使用合成上游，不开启打包入口或改用户默认路由。

1. 先把旧中转测试改为新职责的服务验收：Runtime 得到冻结的本轮正文，回环桥匹配正文并只允许一次派发，Runtime 取得模型文字并决定何时完成；缺少已验证的终态不能交付。保留隔离、版本变化、取消、迟到与重复请求的回归。
2. 在服务的可信组合入口注入文字 Runtime。服务保留模型路由、凭证和每只宠物的历史／授权资料，复用模型传输和出站授权检查，不允许 Runtime 选择厂商、改写正文或请求工具。生产组合不启用；选择 Runtime 的回合失败不走直连补发。
3. 替换 macOS 开发联调：本轮合成文字通过管道进入隔离 DSH；回环桥只接受绑定请求，并将模型文字编码成受限 SSE。DSH 完成事件与最终文字经服务交付；扰动运行时停止、崩溃、上游断开及超时。保留独立 SDK 探针作为隔离基线。
4. 复跑服务与桥接回归、两个实际 SDK 命令、跨平台检查及文档核对。不启动桌面、不动真实资料、不读用户 Key、不联网或产生费用。
