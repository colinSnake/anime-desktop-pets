# 桌宠 Agent：暂存 Runtime 与宿主失联验收

**目标：** 在不安装、不打开 Electron 的情况下，从可搬移的本机 Runtime 暂存包跑完整合成聊天，并验证启动宿主非正常退出时隔离 Worker 和 SDK 收尾。

**约束：** 延续[文字执行链](2026-11-20-pet-agent-harness-text-turn.md)。只读本机 Ape 的已安装依赖，不复制其应用源码、配置或凭证；不下载、不把暂存包写进默认构建、不切默认路由。复用 `sandbox-exec` 的单回环与临时工作目录边界，不把该探针描述成全文件系统隔离。

1. 给暂存闭包加红测：只复制固定 DSH 入口与可解析依赖；保留相对链接，拒绝逃出可信安装目录、链接和非法输入。给所有者断开加红测：无有效 IPC 不启动，断开立即撤销运行权限。
2. 将隔离 Worker 从宿主脚本拆出。像 Ape 一样在启动前监听可信父进程 IPC；失联后关闭输入和 SDK，拒绝继续发送或输出结果。保留现有 stop/crash 行为。
3. 显式 `--staged`：复制依赖闭包和 Worker，移动到另一目录再跑聊天测试，拒绝读原始 Ape。另用专属一次性宿主启动 Worker；合成 Provider 仍挂起时仅对该宿主发 `SIGKILL`，不向 Worker 组发信号，验证断链、所属组退出、无回复／重放。失败需保留无法确认回收的临时现场。
4. 复跑单测、两个既有探针、暂存／失联探针及完整跨平台检查，更新复跑文档及记录。区分暂存包与 Electron 安装包、实测进程组与任意逃逸后代、合成测试与真实厂商验收。
