# Agent 回复本机播报实施计划

> **For agentic workers:** 使用 superpowers:test-driven-development 与 superpowers:verification-before-completion 逐步执行。

**目标：** Apple 芯片 Mac 聊天可显式勾选本次会话自动播报，不改变文字回合、参考音色、服务商、直播或数据迁移。

**设计：** 语音页启用时独立勾选，默认关闭，不写配置；主进程只为仍有效的新在线纯文字终态短暂登记一条回执。React 在接受回复后仅回传请求 ID，不能传内容；服务读取有界纯文本片段，复用已启用的本机语音与单播放槽。拒绝重放、材料或引用资料回合、疑似凭证或代码链接，忽略旧会话历史与本机指令结果。

- [x] 测试回执过期、只消费一次、启用/撤回、代次、乱序取消、文本边界；实现主进程回执、固定 IPC 和仅回环鉴权的语音命令。
- [x] 测试 UI 只确认已收取的普通终态，切会话/退出聊天撤销。接现有语音页勾选、聊天完成、隐藏/失焦/暂停和麦克风停播门禁。
- [x] 测试合成服务语音播放和取消、不打断无关互动气泡；检查构建桥只接受 ID、没有任意播报接口。全量验证并写明真实音频/在线服务未执行。

本轮定向回归与全量检查通过，见[实际验证记录](../../实际验证记录.md#2026-11-24agent-新回复本机播报)。未打开桌面、麦克风、扬声器或外部账号。真实麦克风仍按上一阶段清单验收；播报人工验收用短的非私密回复，先确认本机音色、用户期望的设备与音量，再单独验兼容性和听感。

已追加本机真实模型的无设备往返和模拟设备尾音验收，见[实际验证记录](../../实际验证记录.md#2026-11-24本机语音模型无设备往返与播报尾音)。物理录音、扬声器听感和系统授权不由此通过。

## 真实验收（未执行）

1. 在用户明确同意的时段，打开新的 Apple 芯片 Mac 工作区，先确认本机 TTS、授权参考音色、可听的安全音量和当前输出设备。未勾选时发一条用户认可的非私密消息：回复可见，不自动朗读。
2. 停止再启用并勾选新回复；发另一条非私密短消息。确认在回复显示后只播一次，核对首声延迟、清晰度和是否与互动气泡争抢。真实在线模型可能计费，只有用户已确认该测试路由和费用才发送；否则使用隔离的合成服务。
3. 确认历史、附件和本机查询不出声，失焦、切会话、隐藏和暂停会停止正在播报的回复。启用麦克风授权后验证按住录音先停回复；失焦再聚焦不能继续旧录音手势。停止播报再启用时复选框默认不选，不补播旧回合。
