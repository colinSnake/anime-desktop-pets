# macOS 工作区状态栏实施计划

依据 [macOS 迁移清单](../../macOS功能迁移清单.md) H02／H03。先迁 Electron 本机状态栏和工作区自身启动观察，不观察或启动外部客户端，不接视频、AX 或旧任务。菜单提供打开工作区、读取本机状态、退出；状态只显示已确认启动阶段和服务刚读回的自有实例摘要，不从请求投递推断成功。标准编辑菜单和模型密钥原生确认保持不变。不修改九页布局。

1. 先在 `apps/desktop/test/workspace-status.test.ts` 写失败测试：本地服务启动→窗口加载→首帧可见，首帧前不能重开；只在状态栏可重开时拦截关窗、隐藏同一窗口，保留服务和草稿；明确退出和渲染进程故障后不再拦截关闭。服务摘要合并重复读取，丢弃退出或窗口失效后的迟到结果，失败不沿用旧数值。
2. 新建 `apps/desktop/src/workspace-status.ts`，用注入窗口／读状态／菜单 port 测试过渡；`workspace-tray.ts` 把它绑定到 Electron macOS `Tray`。`main.ts` 用现有 `ServiceProcess.petRequest('list')`，不新增 HTTP、预加载或 IPC。显式退出先关闭状态栏，再沿用模型取消及服务回收；只有本工作区可重开时拦截关窗，渲染进程或状态栏不可用时保留既有安全退出。关窗隐藏时作废密钥确认和在途模型请求。再用定向回归验证关窗之后到达的可信 IPC：隐藏时阻止新的发送、探测、发现和模型配置修改；只读与取消仍可用，重开后恢复入场。无自动启动桌宠或外部应用。用固定的独立小图标及 @2x 文件随开发构建发布，构建冒烟验证图标与隔离的 preload。
3. 逐项记录已开发、部分接线、未移植及真实验收，并列出移除 `apps/companion-macos` 的门槛。旧构建／预览／Swift 回归仍存在，旧目录、数据、冻结 helper 不动。仅在接替能力、明确范围、安全交接、签名与冷启／退出／回退验收后再删除旧宿主。同步 README、迁移清单、路线图、开发文档和交接。
4. 运行定向测试、pnpm 10.32.0 `check:cross-platform`、可信 Fusion/offscreen 回归、`python3 scripts/check-project.py` 和 diff 检查。仅 Node 注入与合成 Qt；不启动真实 Electron／Qt 桌面，不安装、不申请权限、不访问真实进程、用户数据、Keychain 或模型，不暂存、提交或推送。
