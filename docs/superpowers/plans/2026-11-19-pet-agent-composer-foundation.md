# 桌宠智能体前置：低频角色入口与编辑器

基准：[已确认设计](../specs/2026-11-19-pet-agent-and-composer-design.md)。在当前工作树上增量实现（依赖未提交的「小话间」），不重启 Electron、不提交、不触发真实请求。

1. **角色管理入口**：先以静态 UI 回归锁定侧栏不展示角色页、聊天菜单有角色资料、空态没有入口。更新 `App`、`ChatPage`、`WorkspaceModules`，增加带原生焦点管理与键盘页签的角色资料弹窗，复用现有编辑会话；合成浏览器检查聊天对象与舞台不一致时的实例绑定、关窗回焦及聊天草稿不丢。
2. **Lexical 前置切片**：先锁定结构化草稿、实例隔离、失败保留原快照与按键长按测试。添加固定 Lexical 依赖与独立输入适配器，替换 `ChatComposer` textarea；纯文本导入/粘贴、撤销、语义选区、等待状态、快捷词都复用已有聊天规则。用真实 Chromium 合成桥核对焦点、IME 事件、文本/撤销/提交、窄窗与无网络；`test:tooling` 仍检查首屏预算。
3. **后续独立切片**：在不写现役应用的隔离环境验 DSH 文本协议；生产路由和资料工具需另过进程治理、回收与不重试门槛。Markdown 本机预览与 DSH 独立实现；结构化引用仍独立待做。更新设计、README 与验证记录，分别标注已运行和未执行项。
