# 本机记忆／目标删除与聊天上下文实施计划

**目标：** 先补已保存记忆和目标的显式删除，再让聊天能在本机回答用户明确发起的身份、个人记忆、角色知识和目标进度查询。

**架构：** 复用角色资料注册队列、私有仓库和原子提交。删除严格绑定实例、条目和全局修订，内联展示影响并二次确认；重读和写入使旧确认、检索及历史预览作废。聊天先接有界的只读查询，按所选角色从当前快照过滤并返回必要内容；只有明确的本机查询指令才执行。查询及答复为当前窗口资料，不进入未来的模型历史。正式模型发送、在线分享和真实服务验收保持关闭。

**技术栈：** TypeScript、Fastify、Electron、React；Node 24、pnpm 10.32.0。复用现有角色页双栏和聊天原生输入。

- [x] 删除红测：覆盖鉴权、实例与修订、条目及历史移除、目标步骤、错误未确认、固定传输、内联确认、草稿和迟到响应。再开放 `deleteMemory`／`deleteGoal` 固定路由、桥及页面。
- [x] 删除定向验证通过后推进聊天。先测指令边界、当前角色、审核、过期、凭证、删除后查询、体积、请求取消、对话隔离和不进入模型历史，再接本机上下文构造、固定桥和聊天交互。
- [x] 用合成夹具及临时 profile 运行新增回归、跨平台、相关 Qt 离屏、项目与差异检查；同步 README、迁移文档、路线图、交接及实际验证记录，不启动真实桌面或调用外部服务。
