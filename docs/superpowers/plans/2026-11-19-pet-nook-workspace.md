# 「桌边小窝」我的桌宠页面实施计划

**目标**：在「我的桌宠」用一处角色展示区与紧凑的实例列表替代平铺封面卡片，保留现有控制。

**已确认设计**：角色有自己的颜色，但界面保持统一。龙妹场景使用柔紫；未配置角色用统一的素色和品牌图形。真正的第二角色素材、播放器和数据迁移不在本轮范围。其余八页和全局主题选择不改。

**范围与顺序**

- [x] 在 `apps/workspace-ui/test/compact-pets.test.ts` 和 `presentation.test.ts` 验证单展示区、按实例选中、无额外单实例切换器、未知包不读取龙妹封面、非选中实例故障仍可见及既有操作门禁。运行组件测试观察预期失败。
- [x] `PetPage.tsx` 继续使用 `PetWorkspaceController` 的当前选择和既有读写方法。多实例列表只选中实例；展示区负责启停、设置、分身和删除。保留全局刷新、添加、暂停联动及错误、确认和草稿提示。
- [x] `PetCover.tsx` 只使用已有固定封面地址和本地品牌资源。`pet-nook.css` 限定角色装饰范围，按钮和运行状态复用工作区语义配色；`main.tsx` 加载样式，清理 `style.css` 的废弃卡片规则。
- [x] 执行工作区测试与跨平台检查；用合成数据验收实例切换、浅深色、设置和窄窗，不打开真实 Electron。同步双语 README、新工作区迁移交接与实际验证记录，不提交。
