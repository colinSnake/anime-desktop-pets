# Codex 任务租约迁移实施计划

**目标：** 先迁移 T01 的读取许可及 P04 的暂停／关闭边界，给后续只读任务适配器提供可以合成验证的入口。

**设计：** 由每个 `PetWorkspace` 持有进程内租约。调用者必须显式启用，再以可信进程存在性结果续约；不复用旧磁盘心跳。沿用 2 秒心跳建议和 10 秒有效期，以单调时钟度量，含糊／未检测到即撤销当前读许可。心跳与读取各自只允许一个在途操作；关闭、暂停、过期时取消许可，旧结果或迟到探针不能启动新会话的读取。读取端只接受 `working`／`idle`／`unknown` 及有界计数与开场序号；不把读取错误当作任务结束。

**依据：** [旧任务跟随边界](../../Codex任务跟随.md)、[迁移设计](../specs/2026-11-16-macos-feature-migration-design.md)、[退役清单](../../macOS旧宿主退役清单.md)。

- [x] 在 `apps/app-service/test/codex-task-lease.test.ts` 写红测：默认拒绝、存在性不确定、续约、过期、读／探针串行、撤销后迟到、合成状态校验及失败保持未知。在 `pet-workspace.test.ts` 写暂停、冲突、解除及关闭的集成红测。
- [x] 实现 `apps/app-service/src/codex-task-lease.ts`，可注入时钟、调度和探针／读取。加入 `PetWorkspace` 的暂停立即封闭和关闭边界；解除暂停不重启观察，不增加 revision 或写任务文件。
- [x] 运行定向、完整跨平台及可信离屏回归、项目和 diff 检查；同步任务专题、双语 README、开发文档、清单、路线图与实际验证记录。

本批不连接真实 rollout、固定主进程入口或 Python 任务姿态，不创建用户开关，不改变现有播放器隔离或冻结 helper。后续接入必须通过新的明确授权入口，复用单一有界读源并在自有实例上应用，不读取真实会话做测试。
