# T02：自有桌宠显式额度气泡

目标：先接通自有播放器的额度交互与私有链路，可以用合成官方窗口／余额完整复测。沿用现有气泡、主题和交互优先级，独立于 Codex 任务跟随，不改冻结 helper 或 generated-source。官方账号和中转凭据读取另行迁移；无后端时入口禁用。

- [x] 先写播放器协议、服务和 Qt 离屏行为回归，确认现有实现不能处理显式查询。
- [x] 增加可注入、单查询、限时的服务额度端口。严格校验数字窗口／余额和固定失败状态，不接受透传消息、名称、地址或凭证；不暴露 renderer 或 HTTP 入口。
- [x] 私有播放器协议按原版本和会话隔离承载固定的查询、取消及结果；菜单、双击和卡片刷新共用一个交互入口。隐藏、拖拽、替换或停止废弃交互，迟到结果不得打开气泡。
- [x] 复用 Qt 额度卡片、独立于语音；查询时维护互动门禁，确认后继续任务跟随。没有注入来源时保持禁用，不读取账号、不请求服务。
- [x] 运行新增回归、旧额度适配器测试、跨平台、Qt Fusion/offscreen 和项目检查；同步迁移清单、README、开发说明、路线图和实际记录。

后续：真实官方与 TiMi CC 账户来源、授权及桌面验收单独推进；当前不启用真实查询。
