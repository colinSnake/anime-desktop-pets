# 本机角色知识召回实施计划

**目标：** 在「记忆 → 角色知识」中按关键词查询所选桌宠已确认、未过期的知识，并显示正文及来源／引用／版本。不触发模型、线上分享、聊天或任何写入。

**架构：** 沿用既有资料队列的实例归属检查，读取当前角色快照。迁移旧宿主的排序原则：完整短语优先，中文相邻双字／字母数字词覆盖次之，最后按创建时间及稳定 ID 排序。先过滤候选、过期、凭证样内容和同依据冲突，再取前三条。固定回环 POST 查询不把关键词放进 URL；主进程只接受实例 ID、已读全局修订和有界关键词；成功只返回对应修订的条目 ID。页面把结果映射到同一快照，不留搜索历史。

**技术栈：** Node.js 24／pnpm 10.32.0、TypeScript、Fastify、Electron、React。依据[迁移清单 C04](../../macOS功能迁移清单.md)及 `CharacterMemoryRetriever.swift`、`CharacterMemoryReview.swift`。本段迁移关键词检索与证据边界，旧版对话意图和自然语言答复留给聊天阶段。
