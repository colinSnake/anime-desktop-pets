# 角色知识文件预检与人工加入实施计划

**目标：** 允许用户在 macOS 工作区为所选实例选取单个 `.txt`／`.md` 文件，在原「角色知识」页查看分段、补充来源并核对冲突；点击加入才将整组作为待确认知识保存。

**架构：** 系统选择器是唯一文件入口，固定无参 IPC、可信主框架、单个有界普通文件。主进程对字节和正文预检，返回纯文本段落和固定错误，不传文件名、路径或 Markdown 元数据。React 保留独立的逐实例草稿，使用现有共享表单；服务经固定桥和注册队列用预期修订一次原子保存，预检失败整批不改动。

**技术栈：** Node.js 24／pnpm 10.32.0、Electron、React、Fastify、TypeScript。依据[迁移清单 C04](../../macOS功能迁移清单.md)及旧宿主 `CharacterKnowledgeImport.swift` 的文本分段、来源与大小规则，以及新角色仓库的权限与冲突约束。

- [x] 文件边界：先测试临时 `.txt`／`.md` 的 UTF-8、空行分段、32 KiB／50 段／单段 1,000 字符、同段去重、凭证拒绝、路径类型与关闭后弃用。实现 `apps/desktop/src/knowledge-file.ts` 和固定 `selectKnowledgeFile()`；构建冒烟检查 macOS 预加载桥。
- [x] 原子写：先测试 `memories/import` 只接形状受限的知识批次、必填来源，拦截凭证、过期、当前及批内重复和依据冲突、容量、修订和未注册实例，不产生局部写入；接 `addKnowledgeBatch` 契约、仓库与固定传输。
- [x] 页面：先测试只选文件不保存、草稿与单条新增隔离、依据预检、冲突保留草稿、取消和实例销毁。原页面内联预检和显式提交，保留文本为纯文本，不嵌入 HTML／远程媒体。不自动确认或重放未知结果。
- [x] 跑定向、跨平台、可信 Qt/Fusion/offscreen、项目检查及差异检查；更新中英文 README、开发说明、迁移清单、路线图、交接和本批实测。仅合成文件和临时 profile，不启动真实桌面，不导入旧角色目录或旧授权，不提交或推送。

实际命令、结果与未验收范围见[本批验证](../../实际验证记录.md)。
