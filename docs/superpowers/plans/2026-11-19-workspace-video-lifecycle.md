# 工作区视频播放器：实例生命周期试验

按视频迁移清单 V01、V03 推进。macOS 试验模式由新开发命令显式启用，一次会话只使用一个桌宠后端。Qt 继续默认；启动失败不尝试 Qt。固定本机 WebM 只临时解包，不更改素材、用户配置或冻结 helper。

1. 先用合成服务/窗口端口测试私有 v1 启停：白名单、三槽、首帧、停止未确认、取消启动、崩溃通知、迟到回执及服务退出；把协议接进现有 utility process 消息，不开启 HTTP 或 renderer 入口。
2. 复用已跑通的透明视频窗口模块，但把打包的 HTML/JS/CSS 与临时原片分开。只在首帧确认后可见，并复用服务的逐实例、暂停及删除门禁。试验窗口采用保存尺寸、位置和移动偏好；未完成的运行中偏好、全屏策略、任务、额度和语音不报告为应用成功。真实窗口仍待验收。
3. 增加离线 `pnpm run dev:desktop:video --check`，合成验证可选接线和默认回退，同步迁移清单与本轮记录。测试不启动正式桌面，不读取真实账号/任务，不停止现有桌宠。
