# 语音转写草稿与直播准入续接

承接[已确认的统一 Agent 方案](../specs/2026-11-24-pet-agent-runtime-design.md)。本阶段不接平台账号、麦克风或自动播报，不启动真实桌面或收费调用。

1. 音频输入：聊天 `＋` → 原生单选 1–30 秒 PCM WAV → 固定本机 ASR 子进程经 stdin 收字节 → 有界转写 → 空白聊天草稿。不传原路径，不保存音频，不自动发送；新输入、切会话、窗口隐藏或旧代次不覆盖草稿。缺本机模型明确失败，不下载或切云端。
2. 直播准入：直播源独立短时去重和 TTL，限制每分钟进入模型的轮次；过期记录回收，直播不能填满手工 ID 预算或占用相同 ID。现有抢占/清理边界不变，未接平台生产输入。
3. 先用临时文件、合成子进程和注入时钟写回归，再接固定桥与 UI；验证取消、超时、无自动发送、无正文串线、持续直播、打断/清理；同步 README、专题和实际记录。

## 实施与复核结果

- [x] 固定桥和选择器、15 秒读取／90 秒识别时限、显式取消及空白草稿接线。转写仍按普通文字发送，不开启语音或直播专用回合。
- [x] 直播短期去重、滚动启动额度与手工输入分离；单调计时不受系统墙钟调整影响。
- [x] 本机合成 WAV 实际转写、复核问题回归、完整跨平台检查。见[实际验证记录](../../实际验证记录.md)。
- [ ] 后续：按住说话、设备权限和 Agent 自动播报；选定平台的授权连接、实时输入与输出，另行验证。
