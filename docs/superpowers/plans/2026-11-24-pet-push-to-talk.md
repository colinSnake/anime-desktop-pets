# 聊天按住说话：本机录音与草稿

承接 [WAV 转写草稿](2026-11-24-voice-draft-live-admission.md)。本阶段不更改 Pi、模型路由或直播，不接自动播报。

- Apple 芯片 Mac 的空白输入框提供按住说话（指针及键盘）；辅助技术可显式开始/停止。首次无系统权限时先提示用户点击授权，授权本身不开始录音。
- 隔离 preload 只在观察到语音或授权按钮的可信指针、按键或辅助激活事件时允许相应操作。授权与开设备分开；可信主窗口只在一个短时、一次性录音令牌内可请求默认麦克风，其他 Web 权限保持关闭。捕获和音频转换留在隔离 preload，React 只能开始、停止、取消及得到脱敏状态/转写文字。麦克风、WAV 选择不得同时转写。
- 录音仅在内存处理，有采集和消息长度上限。松手后停止声道，完整 PCM 走原本机 ASR，结果只填原会话的未改动空白草稿；在线发送仍由用户决定。隐藏、失焦、切会话、超时、销毁作废迟到音频和文字。设备打开卡住时先结束界面操作并清理迟到的设备；最多保留两个仍在等待系统结果的开设备请求。
- 先测权限与录音代次、迟到流清理、二进制上限和草稿，再接 Electron/React；合成运行及构建测试不得打开真实麦克风、重启应用、拨平台或发收费请求。

## 真实验收清单（未执行）

在用户同意后启动新版开发工作区；保留当前应用和本机数据。不使用真实在线聊天作为自动化输入。

1. 无本机 ASR 时点击语音按钮，只提示配置，不弹权限。已配置时从未授权状态按住、松手；只有再点「授权麦克风」时才弹系统权限；授权或拒绝都不打开录音。检查拒绝的系统设置引导。
2. 重新按住，说一段 2–5 秒的短句后松开。确认系统麦克风指示灯熄灭，文字仅进入可编辑草稿，没有新增聊天消息；再分别试指针拖出按钮释放、空格、Enter 和辅助技术启停。
3. 分别在打开、录音或转写阶段取消、输入草稿、切会话、失焦和隐藏；检查迟到的音频或文字不被提交或覆盖。试极短录音、超过上限、设备中断、快速重复操作及 WAV 并发，确认可重试及不重复启动 ASR。
4. 实测首次授权、重新聚焦及转写延迟；签名包另确认麦克风用途描述、授权身份和物理录音链路。不执行付费调用来证明录音功能。
