# 服务商连接工作区实施计划

设计输入：[模型管理确认稿](../../ui-desgin.md#模型管理同一工作区分清保存与测试)。沿用 React 组件和固定 `ModelsBridge`，不改 schema、原生凭证桥或聊天选模。

1. 先用合成配置锁定每连接一行、同名连接不合并、模型和草稿不出现在列表、仅统计当前修订测试结果；补全编辑弹窗多模型渲染回归。
2. 将编辑目标改为连接；测试和删除显式选择已保存模型，保留版本门禁、删除默认的替换要求和焦点回退。连接选项保留双层默认及发现。稳定 ID 不依赖服务商名称或模型名。
3. 对齐确认稿的标题、紧凑列表、双列参数和固定底栏；检查 760px 深色及宽窗浅色。用合成桥复验实际 React 交互，不发真实请求、不启动 Electron；同步中英文 README 和验证记录。
