# 龙妹节目声轨

已确认：默认静音、开台时手动启用，独立进入 OBS 浏览器源；只播固定主播台词，不采集设备、桌面或聊天。复用「语音互动」保存的参考 WAV 和逐字稿，不要求启用气泡播报。准备时通过同一个本机 TTS worker 预合成三句，内存只保留本轮的有界 WAV；无需一边直播一边等待推理。

1. 补回归：默认静音、固定台词和有界 PCM 合同、启用／暂停／快停的代次隔离、无声模式、序列化与认证路由。
2. 可信服务复用现役 TTS worker；固定请求，临时文件仅本机私有目录，转交前校验整组 WAV。准备期间和桌宠播报／ASR 互斥。
3. 舞台主进程只在对应动作代次开放媒体字节，停声／关台撤销。渲染器与动作首帧、字幕对齐，超时弃播，换景不重放；本机节目预览静音，OBS 自己混音。控制台显示准备／失败／启用状态。
4. 跑离屏和隔离构建，不启动现役 OBS 或 Electron，不拿私有音色做测试；文档记录真实 OBS 听感待验。
