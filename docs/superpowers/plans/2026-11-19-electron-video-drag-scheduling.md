# Electron 视频显示与拖拽调度实施计划

> 按任务逐段红绿回归；保留当前工作树和 Qt 回退，本轮不提交。

**目标：** 将 Qt 拖拽／松手时序移到独立 Electron 渲染与主进程边界，做成后续可选工作区后端可复用的实现，不用演示短滑行代替。

**架构：** 主进程根据可信光标、工作区和单调时钟运行纯 TypeScript 调度；renderer 仅按固定片段 ID/代次取第一帧及显示，不能定位窗口。按[迁移验收清单](../../Electron视频播放器迁移验收清单.md)明确追踪工作区接线和最终实机门槛。

**约束：** pnpm 10.32.0／Node 24；不修改 Qt 或冻结输入、不自动打开桌面、不读取用户资料、不下载／转码／永久复制角色素材。拖拽调度保留 24 逻辑像素、280 px/s、150 ms 窗口、80 ms 停稳、位移开关、系统减少动态效果及任务优先级。迁移行为与实机观感分开。

- [x] **物理同步。** `video-preview/release-physics.ts` 按 `pet_release_physics.py` 保持原算法和许可。通过合成 Python 基线对比轨迹、碰撞、反弹、上下边界和屏幕尺寸变更。
- [x] **拖拽调度（播放器端，工作区位置接线见下）。** `video-preview/drag-schedule.ts` 区分左键按下、越过 8 px 拖拽阈值、真实移动、松手和取消。保留加权估速、走跑飞迟滞、静止回默认姿态、有效段循环、轨迹独立 240 Hz、反弹朝向与收敛后 2 s 姿态保持。接入单次松手位置端口，反馈或不变偏好不能重置轨迹。
- [x] **原片与显示。** `prepare-pet-video-preview.py`、`playback.ts`、`renderer.ts` 复用固定 WebM 原片，保留双层首帧交接，使用动作代次过滤过期首帧、结束及失败；拖拽及释放显示只循环各自运动段。`main.ts` 使用调度，不再依赖播放成功才推进物理；右键不打断轨迹。
- [x] **自动验证与交接（实机事项仍在迁移清单）。** 合成 renderer/main 测试、Qt 既有回归、`--check` 及跨平台检查。工作区所有权和位置持久化、全局自主／任务等调度、补齐全动作、转场几何及真实合成差异按迁移清单逐项标注，不当成已关闭的等价项。

### 源片与显示补齐

- [x] 把固定归档的 35 个动作及底部锚点／缩放／偏移同步到同一白名单。拖拽和松手只使用同一动作的固定时段；正式动作与姿态循环语义分开。全部原片只在独立会话临时目录内准备。
- [x] 画面、转场 Canvas 和透明命中使用同一坐标变换。同步左飞著作校准曲线、镜像轴及绘制留边；物理与保存坐标仍使用名义尺寸，不按透明边缘放大。
- [x] 运动段循环时保留合法尾帧，等待范围内的解码帧、60 ms 混合，减少动态效果时直接切换；换动作、异常和销毁要能取消。验证冻结过程中动作代次、失败回退及真实解码。

### 工作区松手位置

- [x] 复用工作区的视频窗口生命周期，增加固定私有 `workspace-video-drop`，只由已确认首帧的当前窗口上报真正的拖拽松手。验证坐标、实例和启动代次；旧会话、取消、弹簧物理和拔屏回位不触发保存。服务复用现有位置写入、修订和反馈，不添加工作区 renderer 权限。
