# 角色资料逐项授权与在线聊天上下文实施计划

**目标：** 在现有身份、记忆、目标页独立授权已保存资料，仅供将来的在线文字聊天使用。服务端按最新实例快照、用途、审核、期限、冲突和问题相关性选材。本批只保存授权并构造上下文，不开通发送、选模或供应商网络。

**数据：** 在既有私有角色记录中增设仅当前版本可用的 `chatShare: true`；字段缺失表示关闭。历史和普通草稿不接受授权，旧文件不需要改写。按实例和全局修订原子提交；改写、版本恢复、撤回审核及删除不继承授权。内容未变的保存不撤销。未确认发布在当前服务进程封锁该实例的在线上下文。

**界面：** 延续现有工作区布局和共享内联控件；身份按当前保存版本，记忆、知识和目标按条目。授权前显示用途及字段，默认焦点为取消，可 Esc 或离页取消；撤回单独执行。结果未知时保留草稿并要求重读。页面只调用固定授权操作，不接收组装后的在线上下文。

- [x] 先测跨实例、过期、未审核、未授权冲突、凭证样内容、相关性、字符／字节预算与本机指令隔离，再接服务端上下文。身份只取名称与角色表达所需字段，记忆／知识仅取相关记录，目标仅含相关标题、状态和步骤计数。资料是引用数据，不是模型指令。
- [x] 用合成资料与临时 profile 执行定向、跨平台、可信 Qt 离屏、项目和差异检查；分别记录证据，更新迁移文档。后续接发送时仍须在出站前绑定模型路由、再次核对授权和请求取消；不把本批当成在线交付。
