# 语音互动：本机试听与人工验收

承接已确认的 Agent 回复播报和按住说话方案。本轮只补齐验收入口，不改模型、直播、持久配置或默认授权；不自动启动桌面、打开音频设备、下载模型或发起在线请求。

## 有界设计

- 「语音互动」启用参考音色后，可显式试听一条固定中文短句，不播放逐字稿、聊天历史或页面提供的任意正文，不触发线上模型。
- 试听与互动气泡／聊天回复共用现有单播放槽；忙碌时拒绝，不抢占或排队替换其他来源。独立停止试听不撤销会话播报设置，不打断非试听来源。
- 固定无参 IPC，仅可信、可见且聚焦的 Apple 芯片 Mac 主窗口可启动；麦克风工作或权限提示中不启动。主进程分配递增修订，服务拒绝旧启动及重复回放。失焦、隐藏、最小化、导航、录音及退出撤销试听；停止失败保持保守阻塞。
- 页面提供短小的人工验收步骤，区分本机转写、手动发送和在线可能计费；默认不自动发送、不常开麦克风。
