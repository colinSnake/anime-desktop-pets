# macOS 旧宿主退役清单

2026-11-19 用户明确选择立即退役旧 Swift/AppKit 宿主。仓库中已移除宿主源码与专属入口；系统上的旧安装、登录项和资料不在这次源码变更范围内。以下是原功能对照与**仍待完成的接线或验收**，不再作为删除源码的前置条件。逐项进度见 [macOS 功能迁移清单](macOS功能迁移清单.md)。历史实现可从 `1894f9c` 查阅，例如 `git show 1894f9c:apps/companion-macos/README.md`。

| --- | --- | --- |
| 工作区与宿主 | 九页工作区、主题、标准编辑菜单；macOS 状态栏显示本服务启动与实例状态，可重开同一窗口和显式退出；窗口隐藏时取消在途模型操作并拒绝新操作；会话内可显式启停 Codex 存在性观察；显式打开和本地冷启动视频、跳过／超时／失败清理已接；动画窗可按唯一稳定的可见窗口对齐一次，读不到则保留居中 | 真实菜单、Dock、焦点、长时运行、Codex 检测、冷／热启动与视频音轨；真实窗口对齐、Space／多屏、旧宿主对外部窗口的受控 AX 调整；旧 CLI 的必要命令和退出语义 |
