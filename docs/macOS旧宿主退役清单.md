# macOS 旧宿主退役清单

截至 2026-11-18，新栈可以用于隔离开发验证，暂不能接替旧安装版。用户已明确以迁移完成为前提退役 `apps/companion-macos/`。以下按功能和验收记录判断，不按页面数或测试数判断。完整条目见 [macOS 功能迁移清单](macOS功能迁移清单.md)，当轮证据见 [实际验证记录](实际验证记录.md)。

| 范围 | 新栈已实现 | 退役前尚缺 |
| --- | --- | --- |
| 工作区与宿主 | 九页工作区、主题、标准编辑菜单；macOS 状态栏显示本服务启动与实例状态，可重开同一窗口和显式退出；窗口隐藏时取消在途模型操作并拒绝新操作；会话内可显式启停 Codex 存在性观察；显式打开和本地冷启动视频、跳过／超时／失败清理已接；动画窗可按唯一稳定的可见窗口对齐一次，读不到则保留居中 | 真实菜单、Dock、焦点、长时运行、Codex 检测、冷／热启动与视频音轨；真实窗口对齐、Space／多屏、旧宿主对外部窗口的受控 AX 调整；旧 CLI 的必要命令和退出语义 |
| 桌宠与素材 | 隔离实例登记、克隆、删除、逐实例启停、首帧／停止确认、三槽限制、显示／位置／行为偏好、会话暂停、受限导入 | 首次单宠转多宠、旧实例交接与自动恢复；导入素材实际播放、引用保护和删除；原版／静态选项及真实桌面动作、拖拽、全屏、暂停恢复验收 |
| 角色资料与文字聊天 | 身份、记忆人工审核及历史、知识预检与本机搜索、目标和手动进度；删除、逐项分享授权、选模、文字发送和取消 | 旧角色资料显式交接；表达适应、自动记忆审核及通用本机优先／在线回退；真实会话、授权及撤回验收 |

| 数据、发行与回退 | 新旧 profile 隔离；开发构建和离线检查可运行 | 选定快照的预检、备份、受控导入、冲突和回退演练；独立 macOS 发行包、字体和固定 helper 校验、签名、干净安装／升级／退出以及故障回滚 |

退役步骤：

1. 逐项关闭退役缺口；对于明确决定不再保留的旧功能，单独记录用户确认的范围。功能接入、合成回归、真实桌面验收分别留证。Windows／Linux 播放器继续暂缓，不作为 macOS 退役前置。
2. 用户选择安全时机验收真实 macOS。先证明新旧 profile 隔离及备份可恢复，再确认旧服务停止写入后移交，最后演练回到已验收版本。真实权限、账号、资料和可能计费请求另行确认。
3. 在独立变更中删除旧 Swift/AppKit 宿主与专属构建／预览／控制入口，迁移或替换仍指向旧目录的项目检查、CI 和文档。当前 `scripts/build.sh`、`scripts/preview-character.sh`、`scripts/test.sh`、`scripts/test-multi-pet.sh` 及 `scripts/check-project.py` 仍有依赖；删除前须验证替代入口。继续保留新栈需要的 Python/Qt 播放器和资源、独立 macOS Keychain 助手、Codex 存在性探针与平台适配；不删除旧用户资料、应用安装或备份。
