# 本机直播台使用指南

## 逐项直播资料授权（2026-11-27）

1. 在「直播管理」为龙妹或鲸鱼妹选择已登记的对应桌宠实例。
2. 展开「直播资料授权 → 管理授权」。只有此时才读取当前绑定实例的可授权资料；不展示目标、历史版本、其他实例或未确认／过期记录。疑似凭证资料不参与授权和上下文。
3. 展开某条「查看当前版本正文」，检查内容、资料版本及来源；身份会列出完整字段，记忆／知识会附来源、引用和版本。点击「允许直播使用」后再次确认。每角色当前最多选择 40 项；单次模型上下文仍遵守原有数量及字节上限，不保证每条授权资料都用于每次回答。
4. 点击「撤回直播授权」可单条撤回；开台期间也可管理授权，进行中的舞台操作暂时锁定控件。修改／恢复资料后旧版本授权失效，必须查看新版本并重新授权。
5. 版本冲突、保存未确认或服务不可用时，界面不假定回滚或成功、不自动重试；先点击「重新读取授权」核对实际状态。若主播绑定已由其他操作改变，先重新进入直播管理以读取当前绑定，再打开授权面板。

授权默认关闭，与「在线文字聊天」授权完全独立，不互相继承。更换／解除角色绑定会先清除旧实例和新绑定实例的旧直播授权；清除未确认时不发布新绑定。重新绑定同一实例也不会自动恢复权限。授权不开放任意目录、路径、工具或附件能力。最终模型出站及生成结果／音频发布前都复核当前绑定、授权和角色资料修订；撤权后尚未出站的旧上下文不会继续发送。

授权管理只读写本机资料，不启动舞台、播放音频、调用模型或学习记忆。实际弹幕演练仍是另一个明确动作，获授权内容可能发送给所选模型服务商，并体现在节目回复中。

没有自动自我学习、人格自动改写或 Markdown 导入／导出。真实 Electron／OBS、TTS 听感与实际模型计费尚未验收。


桌边小崽的「直播管理」是**控制台**；本机预览和 OBS 浏览器源使用同一个独立的 **1920 × 1080、16:9** 节目页；只有触发动作或演练后才可能发声。节目页没有管理控件，不录制或镜像桌面。当前入口适用于 macOS Electron 工作区，需使用新本机资料目录 `~/.adpets` 和通过固定版本校验的角色 WebM 素材；龙妹与鲸鱼妹各用独立素材目录，缺原片不会自动下载或跨角色回退。两个角色都能独立配置音色；未配置的角色仍可静音开台和播放手动动作，但不能发送弹幕演练。参见[本地开发与使用指南](本地开发与使用指南.md)。

## 开台、互动、换景

控制台在宽、窄窗口均按「舞台输出 → 布景与摆位 → 主播互动」排列。「布景与摆位」宽窗左侧是布景卡，右侧是横向位置、角色大小、保存与当前状态；窄窗的摆位参数回到布景卡下方。界面不再常驻展示使用说明，保留操作、状态及未就绪、进行中或失败时的提示。

当前正式布景为六套：**暮色小屋、雨夜阁楼、云海露台、蓝天草原、森林篝火、录音棚**。布景及舞台摆位固定保存到 `live/stage-profile.json`，采用 schema v3：当前布景选择在两个角色间共用，每个角色分别保存六套摆位；旧 schema v2 只迁移到龙妹，鲸鱼妹使用安全默认摆位。未知或损坏格式不自动覆盖，也不导入其它旧资料。前三套有桌沿前景；草原、篝火和录音棚依定稿直接落地，不额外添加桌子。

1. 在可安全启动桌边小崽时，从仓库用 `pnpm run dev:desktop` 打开工作区，进入 **直播管理**。工作区仅使用当前已选的本机资料目录；旧 schema v2 布局只迁移到龙妹，其它旧配置不导入。
2. 顶部「直播桌宠」默认是 **龙妹**，与聊天和桌面的选择互不影响；停台时也可选择 **鲸鱼妹** 开启独立舞台。到「布景与摆位」选择 **暮色小屋（默认）**、**雨夜阁楼**、**云海露台**、**蓝天草原**、**森林篝火**或**录音棚**。用「−／＋」逐点调整、直接输入整数百分比，或在数值框内按方向键。横向位置与大小按所选布景约束（通常 25–75%、75–125%；森林因篝火位于右侧，横向上限为 55%）；新三套采用草地、林间空地和录音毯的各自落点。两个角色分别记忆摆位；选择的布景在角色间共用。更改后点 **保存布景**。点**布景卡**选景，只有右上角的**展开图标**打开图片预览；开台时也能看图，不会改变节目。角色位置与动作以「预览舞台」为准。
3. 点 **开启直播台 → 预览舞台**。节目页先显示循环待机。龙妹提供 **打招呼、开心一下、比个心**；鲸鱼妹提供 **打招呼、开心回应、鲸尾回应**。只会加载当前角色的固定素材和动作台词，角色间不共用片段。手动动作和下方的弹幕演练分开。打开舞台不改变桌面桌宠，也不会开始推流。
4. **不停台换景：**节目运行时，点另一套**布景卡**，不用按「保存布景」。保存确认后节目页沿用同一个 URL，加载好新布景的背景和桌沿后一起替换，并使用该布景自己的已保存摆位。等待保存时管理页保留旧选中和布局，节目等待新图就绪时保留旧画面；正在播放的互动不重播。这里切换的是浏览器源**内部的布景**，不是 OBS 的「场景」列表。
5. **调整摆位或切换角色**仍须先关闭舞台。只关预览不关舞台；关工作区窗口也不会停止已开的输出。**关闭直播台**、全局暂停联动或退出应用会终止本机源；下次手动开启会产生新地址。保存只恢复布景和摆位，不恢复上次会话、对白或开台状态。

> 仍在运行旧版本时，请等可以停台再重开桌边小崽；仅刷新页面不会更新旧版桌面桥。升级后首次开台需要在 OBS 更新一次地址，之后同一轮开台期间换景不需要再改。

## 在工作区查看布景图

点布景卡右上角的四角展开按钮，在当前窗口打开 1920 × 1080 的静态布景图。右上角可下载原尺寸 WebP 或关闭；底部「−／百分比／＋」用于缩小、适合窗口和放大。放大后可拖动图片或滚动查看。点蒙层空白处或按 `Esc` 也可关闭；点图片本身不会关。查看、缩放或下载均不会选景，也不会启动、停止或影响 OBS 输出。

云海露台的旧桌面相机已替换为平放的云海明信片。新增三套按确认的 2D 设计分别呈现草甸花径、林间篝火和录音室演播毯；它们保留同一双图层接口，但前景图层透明、不叠桌沿。

## 开启失败时

- 提示「未能准备节目画面」时，可先点 **重试开启**。这是准备失败，不一定是原片缺失。新版从固定归档新建仅当前用户可读写的临时视频文件。如果工作区还在使用旧会话的临时文件，等可以安全退出时，退出后再用 `pnpm run dev:desktop` 手动重开；单独刷新界面不会重新准备素材。不要修改原始归档权限。
- 仍失败时，可在终端运行 `pnpm run dev:desktop --check` 检查本机素材准备，不会启动 Electron；此检查不是实际开台。若提示「状态待确认」，先在控制台按 **重新读取状态** 核对，不要直接清空本机配置。

## OBS 本机预览（不推流）

1. 点 **复制 OBS 地址**，在同一台 Mac 的 OBS 添加「浏览器源」，粘贴地址并设宽 `1920`、高 `1080`，不要点开始推流。地址是临时回环地址，不适合分享，远程设备也无法直接用它。
2. 确认 OBS 预览里先出现待机，再逐个点三个手动动作。保持同一浏览器源，依次点击其他五套布景卡，确认画面换景、不必刷新或改地址，也不重播正在进行的动作。核对角色动作和字幕互不串用，待机不发声、也没有桌面内容；测试节目声轨见下节。关闭直播台后旧地址失效；再开必须更新源地址。
3. 舞台只停止本机画面。需要即时移除 OBS 里的画面或停止录制／推流，仍须由主播在 OBS 操作。

## 为各主播配置音色，让 OBS 收到声音

直播音色按绑定的桌宠实例保存到 `~/.adpets/live/voices/<pet-id>/`。不会从「语音互动」、另一只桌宠或旧资料取样；若要让两个角色用同一音色，必须分别选择。换绑后用新实例自己的配置，删除实例不会改动原始参考文件。

1. 使用已配置本机语音运行时的 **Apple 芯片 Mac**。先停台，在「直播管理 → 直播音色」为当前主播实例选择有权使用的 PCM WAV，再保存对应逐字稿。参考音频需为 1–30 秒且不超过 6 MiB；逐字稿不超过 4 KiB。更换、修改或移除音色前先确认当前绑定，结果未确认时需显式重读。不需要开启气泡播报。需要准备 MLX 运行时时，见[语音互动验证指南](语音互动验证指南.md)。
2. 点 **开启直播台** 后，本机在后台自动合成三句短台词，无需另开声音。画面和换景不等语音先就绪，也不会自动说话。看到 **当前主播声音已就绪** 且 OBS 已经显示舞台后，点一次「打招呼」，再按需测试另外两句。准备期间不与桌宠气泡、试听或转写争用模型。若语音忙、未配置音色或准备失败，节目保持静音；解决原因后关闭再开启直播台即可重试。
3. 在 OBS 浏览器源属性勾选 **通过OBS控制音频**（英文 *Control audio via OBS*），在「音频混音器」核对该浏览器源电平并调整音量；若有电平但耳机没声，到「高级音频设置」把该浏览器源的「音频监听」改为 **监听已启用**（英文 *Monitor and Output*）；不要选「仅监听(输出静音)」，否则不会进节目。不需要额外添加「音频输入采集」或「桌面音频」来采集节目声轨。桌边小崽自带预览故意静音；判断节目是否收音，可做一段本机试录，不用推流。
4. 关台、暂停或退出会同时撤下节目源并取消声音准备或播放。换景不重播台词、不换地址。重新打开／刷新 OBS 浏览器源不补播旧句；若需在 OBS 保留画面但暂时不要声音，可静音该浏览器源。更换参考音色后，下次开台会用新音色准备。

如果当前主播的声音已就绪、点互动有字幕但 OBS 混音器仍没有电平，请先确认该浏览器源是本次开台复制的地址、未静音，然后记录声音就绪状态和混音器现象。节目页会在有限时间内等待音频开始，超时不会补播；媒体失败、拒播或超时会留下固定诊断类别。排查时只需提供错误类别，不要发完整舞台地址或未脱敏的日志。

## 用弹幕演练试一次真实回复

1. 在「模型管理」至少保存一个可用的服务商和模型。演练自动使用第一个已保存服务商的「连接默认模型」，与聊天未手动选模时一致，无需另设全局默认。聊天内换模不影响演练；首个服务商失败时不会自动换用其他服务商。在直播管理开启舞台，并确认当前主播的声音已就绪。保持 OBS 浏览器源打开；想先验证本机结果，可不推流只做 OBS 预览或本机试录。
2. 在 **主播互动 → 弹幕演练** 输入一句测试内容，例如「龙妹，忙了一天好累」。按 **Enter** 或点右下的**发送箭头**才会提交弹幕；中文输入法确认候选不会发送。提交后调用该服务商的连接默认模型，可能计费。输入框内仅保留发送箭头，不再提供清空按钮；舞台确认接受后才清空草稿，未能确认或被拒绝则保留。Pi 使用对应角色的固定人格，并只接收当前已绑定实例中逐项授权且修订仍匹配的身份和已确认、未过期记忆；不会读取其它实例资料、目标、附件或聊天历史。每次演练是独立单轮，不自动保存或学习新记忆。不把附件、参考音频或逐字稿发给模型；请勿输入敏感资料。
3. 管理页不显示已发送弹幕和回复正文，也不展示 Enter 提示、字数和模型计费说明；未开台时只让发送不可用，操作中或失败时给出必要提示。到 OBS 浏览器源或「预览舞台」看回复字幕；节目页播放同一句话用该主播独立音色合成的语音。只有主动开启学习预览时，管理页才临时展示所选一轮正文。内置舞台预览始终静音；声音请在 OBS 核对电平或试录。
4. 没有单独的停止演练按钮。手动触发动作、关台或暂停联动仍可撤销已有演练；离开直播管理或隐藏窗口时，撤销生成中、合成中或已发布的演练字幕和音频；不关停舞台，也不打断独立的手动动作。播放手动动作时暂不启动新演练；已发给服务商的请求仍可能计费。换景不停止演练，回复使用提交时的布景名称。不支持排队或自动重试；模型或语音失败时不播预设回复，也不会只发布半成品。

## 显式学习与审核

1. 一轮弹幕演练成功发布后，可点「从本轮演练提议偏好」。默认不显示回复正文；点开后只预览这条弹幕和这句回复，不调用模型。选中资格短期有效（最多 60 秒），离页、隐藏窗口、取消、关台或新一轮会撤销。
2. 核对后再点「确认生成候选」，这才将所选一轮发给第一个已保存服务商的连接默认模型（可能计费）。不发送其它历史、附件、身份设定、音频或授权列表；源文本不额外存盘。Pi 只能从固定的表达风格（如简短、亲切、先回应感受）选出至多一条偏好；候选由本机固定文案生成，模型自由文本、个人事实、身份、知识和目标不进入候选。不合格、过期或重复的结果不会新增记忆。
3. 在「人工审核」确认或拒绝删除，也可之后到「聊天 → 桌宠 Agent → 记忆」核对待确认项。未审核的候选不会用于回复；确认也不会打开聊天或直播授权，两者均需分别设置。取消在途生成会断开原请求；若已进入写入阶段或取消结果无法确认，先核对记忆列表，不自动重试。
4. 聊天历史详情也能选择一轮已保存的普通纯文字问答，使用相同的预览、确认和审核流程。含材料、工具或角色资料的回合、未完成和未保存回合不符合条件。

当前不接平台账号、真实弹幕或麦克风，也不回发到直播间；手动动作不需要在线模型。真实模型、Electron、OBS 混音和听感尚待验收。本机素材可播放不意味着可公开使用或再分发；公开直播前先核对[第三方来源与素材边界](../THIRD_PARTY_NOTICES.md)及授权。
