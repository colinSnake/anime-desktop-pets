## 闭环判定

当前可称为“用户掌控的资料管理、按需使用、可选 AI 自动审核与手动修订闭环”：明确输入/本地导入、有限本机审核、按桌宠 Markdown 持久化、用户确认/编辑/删除、关键词召回、逐条在线授权、最近10版历史和恢复均有实现及离线测试。**不能称为完整自我演进闭环**：未开启 AI 自动审核时普通对话不会自动提取候选；开启后仅对有界用户原话进行额外审核，低风险自动保存、疑难转待确认。仍没有后台反思、自动归并/遗忘、模型生成的人格更新提案或语义检索。敏感词和冲突检查属于有限启发式，不是可靠事实判定。

因此，现阶段可以验收的是“稳定人格由用户维护 + 记忆/知识由用户控制 + 经授权后用于回答 + 用户修订可恢复”。若产品目标包含逐渐适应用户，后续仍需显式纠正反馈入口、人格变更提案及其采纳/拒绝机制，以及真实模型的记忆提取和纠正评测，再评估后台总结。任何自动改人格、自动执行目标或后台采集均不属于当前能力。

本地可执行的端到端检查：

1. 通过显式记忆命令增加合成偏好，确认本机回答可召回；无关问题不应把该项附加到在线请求。
2. 编辑条目并保存、重启预览，再检查更新后的内容；删除后确认本机回顾与模拟在线上下文都不再包含该项。
3. 默认关闭 AI 自动审核时，记录一次普通用户纠正，系统不自动写入记忆或改变人格。自动审核开启后的有证据记忆写入使用合成 provider/HTTP 测试验证，不在离线窗口伪造联网能力；人格始终不自动改写。
4. 检查记忆/知识/身份各自授权及实际模拟请求载荷；不得用真实 Key 或真实个人资料做自动化测试。

规则/存储的自动化覆盖不等于 UI 易用性或在线效果验收。在线人格一致性、其余中文输入场景、真实服务和语音往返仍需用户在安全时机验收。

因此本机资料维护与规则链路可以开始验收；整套“数字个体”仍是分阶段实现。预填的“知识与擅长边界”是回答约束，不代表已经安装知识库。目标空白由你按实际需要建立，用户记忆空白属于正常初始状态。

## 2026-11-15 本机窗口验收补充

在用户允许重启后，用当前打包宿主的隔离离线窗口执行了实际交互：中文合成文字粘贴与多行输入、普通记忆自动本机保存、重复跳过、已确认内容回顾、敏感样本转待确认、角色知识及来源/引用/版本录入、确认、关闭重开读取。全部资料位于独立临时目录，在线分享保持关闭，没有把验收样本写入真实角色资料。

确认操作曾出现“存储已确认、原位置仍显示待确认”的问题：`LazyVStack` 扁平化两个 `ForEach` 后复用了旧条目。行标识现按状态和记录 ID 区分；回归使用隐藏原生窗口渲染验证，真实窗口也复测确认后无需切页即可更新状态并移除确认按钮。

本机询问知识的“来源/引用/版本/依据”时，优先为证据字段保留回复空间，不让长正文挤掉出处。仅选择通过已确认/过期/冲突/凭证过滤的相关记录，不自动生成来源。普通知识概览仍维持简短摘要。本轮已补做真实窗口问答“琥珀书房的知识来源是什么”，AX 和截图均确认回复同时显示合成设定手册、第3页及验收版 2026-11-15，补齐上一轮因锁屏未完成的出处显示验收。离线 AI 自动审核开关保持隐藏；真实在线模型与自动审核准确率仍未验收。具体命令和结果见[实际验证记录](实际验证记录.md)。

### 自动审核授权补充

开启必须等授权写盘成功后才收集新发言和调度审核。关闭立即取消旧批次并丢弃队列，写盘失败也在当前窗口保持关闭，并提示下次打开可能读到旧授权；需修复路径后重试关闭。快速启停最终按最后一次操作落盘，资料刷新不会恢复本窗口明确撤销的授权；立即关闭工作区也不会丢弃已要求的本地授权保存。上述边界由合成存储及调度测试验证，未使用真实模型额度。

## 打开安全的本机验收窗口

在仓库根目录运行：

```bash
./scripts/preview-character.sh
```

脚本构建当前源码的开发宿主并直接打开真实角色窗口；自动新建临时资料目录并在终端显示路径，不更改 `/Applications` 安装包。预览不启动桌宠 helper、Codex 观察器、麦克风或在线模型，也不检查在线服务配置和钥匙串。窗口顶部显示“离线验收”。关闭窗口即可正常退出；临时资料保留，便于检查重开读取。

脚本每次都创建新目录。验收“重开仍有记忆”时，使用首次输出的同一个目录与可执行文件路径：

```bash
# 将以下两个占位路径替换成脚本刚才输出的值，不要填真实用户资料目录。
PET_DATA_DIR="<首次输出的临时资料目录>" \
PET_RESOURCE_DIR="$PWD/resources" \
"<输出的可执行文件完整路径>" --preview-character-window
```

直接使用 `--preview-character-window` 时必须显式设置 `PET_DATA_DIR`；缺少或为空会在加载用户数据前拒绝。请勿把验收数据填写为真实凭证、病史、身份资料或账号信息。下表均使用虚构样本。

### 修订历史补充

身份页和记忆条目均可展开最近10个本地快照并恢复。身份恢复会形成新身份修订并关闭身份在线分享；记忆恢复会形成新的待确认修订并关闭该条目分享。删除记忆会永久删除应用管理的版本历史。历史加载失败会在对应区域显示错误，不会伪装成空历史。历史记录存储、恢复和上限由自动化覆盖；真实窗口的展开、滚动及恢复操作仍需隔离预览验收。

## 后续真实服务验收

正式服务验收另行使用经构建/字体/签名校验的新版应用。由你在应用里配置服务并决定是否允许身份分享，先检查费用提示，再自行发起在线聊天；不把真实额度、对话或录音作为自动化测试输入。需验证人格的说话方式是否稳定、记忆/知识相关性、失败重试，以及语音识别→回复→朗读→气泡的整条链路。当前离线入口无法证明这些体验通过。
