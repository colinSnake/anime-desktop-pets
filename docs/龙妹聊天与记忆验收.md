## 打开安全的本机验收窗口

在仓库根目录运行：

```bash
./scripts/preview-character.sh
```

脚本构建当前源码的开发宿主并直接打开真实角色窗口；自动新建临时资料目录并在终端显示路径，不更改 `/Applications` 安装包。预览不启动桌宠 helper、Codex 观察器、麦克风或在线模型，也不检查在线服务配置和钥匙串。窗口顶部显示“离线验收”。关闭窗口即可正常退出；临时资料保留，便于检查重开读取。

脚本每次都创建新目录。验收“重开仍有记忆”时，使用首次输出的同一个目录与可执行文件路径：

```bash
# 将以下两个占位路径替换成脚本刚才输出的值，不要填真实用户资料目录。
DRAGON_DATA_DIR="<首次输出的临时资料目录>" \
DRAGON_RESOURCE_DIR="$PWD/resources" \
"<输出的可执行文件完整路径>" --preview-character-window
```

直接使用 `--preview-character-window` 时必须显式设置 `DRAGON_DATA_DIR`；缺少或为空会在加载用户数据前拒绝。请勿把验收数据填写为真实凭证、病史、身份资料或账号信息。下表均使用虚构样本。

## 建议按顺序验收

| 步骤 | 操作 | 预期结果 |
| --- | --- | --- |
| 1 身份 | 检查所有身份字段；将性格末尾加“验收标记”，点保存身份；关闭后用同一目录重开 | 设定完整、修改保留，在线分享开关仍关闭 |
| 2 本机介绍 | 聊天输入“你是谁” | 回答名字、角色定位等；不会发在线请求 |
| 3 普通记忆 | 输入“记住：验收偏好是喜欢安静的书房” | 提示本机已保存；切到记忆页看到已确认条目，在线分享关闭 |
| 4 去重与回顾 | 再发相同记忆，然后问“你记得什么” | 不重复保存，回顾能找到该条；关闭重开后仍可回顾 |
| 5 审核 | 输入“记住：用药验收样本，不是真实资料” | 只进入待审核，确认前回顾不把它当作已知记忆；测试后可删除 |
| 6 凭证拒绝 | 在记忆页新增“密码：synthetic-not-a-secret”并保存 | 显示拒绝原因，输入保留，不产生记忆文件；不要填任何真实凭证 |
| 7 角色知识 | 类型选“知识”，正文填“遇到复杂问题先拆成小步骤”，来源“验收手册”、引用“第2章”、版本“验收v1”；保存后确认 | 问“你知道哪些角色知识”可回顾，未确认或未授权内容不会进入在线上下文 |
| 8 知识冲突 | 同一来源、引用、版本再填“遇到复杂问题直接给完整长答案” | 显示依据冲突；存在已确认冲突条目时，它们不会参与回顾/在线上下文。修改依据或删除不采纳的条目以解决 |
| 9 目标 | 新建“整理验收书房”，写两步“分类”“贴标签”，保存、勾选第一步；聊天问“我们现在推进到哪一步了”及“整理验收书房目标进度”，重开再问 | 显示1/2及下一步“贴标签”，记录保留；暂停/完成按保存状态解释。目标默认本地，逐项授权后只在相关在线问题中附摘要；预览不会发在线请求 |
| 10 在线分支边界 | 输入“帮我写一段新的故事” | 明确提示离线预览不可用，显示失败与重试入口，不发在线请求 |

继续检查本轮新增流程，均在同一隔离目录操作：

| 步骤 | 操作 | 预期结果 |
| --- | --- | --- |
| 11 旧身份补齐 | 将一个身份字段清空，其他字段写“自定义验收”，保存并重开；点“预览龙妹默认设定并补齐空白”，先取消，再打开并“补入表单” | 预览只列空白字段；取消不变。补入后未保存时磁盘原样；显式保存并重开后空白已补，自定义文字、名称和分享设置保持。切换记忆页刷新不丢身份草稿 |
| 12 知识导入 | 记忆页“导入角色知识…”，粘贴两段合成知识（空行隔开）、填来源“验收手册”、引用“§2”、版本“验收v1”，预览后导入 | 显示两条候选及完整依据，均关闭分享；引用带“导入文本第 N 段”区分输入中的位置。未确认前本机回顾不展示；逐条确认后可一起回顾，不互判为同一位置的冲突 |
| 13 去重和校验 | 重复导入相同文本、来源/引用/版本及有效期；另试空来源、单段超1,000字或含“密码：synthetic” | 相同条目跳过，不改已有内容；非法整批拒绝且无半批资料。改变分段或引用视为新依据，需重新核对；不要填真实凭证 |
| 14 修改重新审核 | 对已确认知识改正文、来源、引用、版本或有效期，保存 | 转回待审核且分享关闭；再检查并确认，需要在线使用时重新授权。只改分享开关不撤销已有确认 |
| 15 知识到期 | 设置未来的有效时间，保存、确认后先回顾；时间到后再问同一知识 | 条目仍可管理，过期内容不再参与回答，直接确认提示先更新有效期。自动回归另用合成时间覆盖，不要求等待或改系统时间 |
| 16 陌生目标 | 问“火星计划的目标进度” | 不返回“整理验收书房”等无关目标，不编造进度；查询不改变目标文件 |

导入按空行分段，单次最多32KiB/50段，每段1,000字符；只支持粘贴及所选 UTF-8 `.txt` / `.md` 普通文件。预览中改动任何输入后须再次预览；引用只作文字，不抓取网页。导入批内相同段落去重；带引用时按去重后的顺序编号，重复导入的依据与分段须一致。文件里的分享/确认声明只是正文，不会授予权限。

当前窗口关闭退出验收与表单点击验收需要实际执行后才能记为通过；单元测试不能替代这些交互结果。记录反馈时附步骤编号、输入、期望、实际现象和窗口状态即可，不需要提供密钥。

## 后续真实服务验收

正式服务验收另行使用经构建/字体/签名校验的新版应用。由你在应用里配置服务并决定是否允许身份分享，先检查费用提示，再自行发起在线聊天；不把真实额度、对话或录音作为自动化测试输入。需验证人格的说话方式是否稳定、记忆/知识相关性、失败重试，以及语音识别→回复→朗读→气泡的整条链路。当前离线入口无法证明这些体验通过。
