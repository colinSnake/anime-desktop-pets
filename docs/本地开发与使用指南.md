# 本地开发与使用指南

## 2026-11-24：同步鲸鱼妹全部动画

执行 `node scripts/prepare-local-companion.mjs <dsh-pet-checkout>` 从用户指定、固定版本的源码目录增量准备全部 114 段 WebM（待机＋113 动作）；不执行源项目代码、不下载、不覆盖现有封面、待机及冲突文件，不启动应用。原片保存在 Git 忽略的 `.local/pets/dafeiyu/videos/`，本轮共 57,832,768 字节。`pnpm run dev:desktop --check` 离线报告 `113/113` 表示动作完整，不等同于真实桌面验收。重开开发工作区后，鲸鱼妹右键「动作预览」显示 15 组本机可用动作。

所有源项目动画均可预览，包括移动、额度、工作和睡觉；这些菜单项不启用相应业务，不启动外部模型请求或自动任务。原拖拽悬空与快速松手回弹保持不变。来源及许可见[素材署名](../licenses/local-companion-media.md)，验证边界见[实际验证记录](实际验证记录.md)。

Electron 工作区是当前桌面入口。旧 Swift/AppKit 宿主及其安装、登录项、控制和预览脚本已退役；旧安装与用户资料不由新工作区接管。

## 环境与开发入口

使用 Node.js 24.x、pnpm 10.32.0 和 Python 3.10+；额度查询需要 Python 3.11+。macOS 开发构建使用 Swift 编译独立平台助手，不需旧 SwiftPM 宿主。Windows/Linux 可打开工作区，暂不支持播放器。

```bash
pnpm install --frozen-lockfile
pnpm run check:cross-platform
pnpm run dev:desktop --check  # macOS：校验本机视频素材，不打开窗口
```

明确要打开真实工作区时执行 `pnpm run dev:desktop`；如果还希望打开 Codex 并播放本机启动视频，则用 `pnpm run dev:desktop:codex`。两者均是同一视频播放器；前者不会打开 Codex。这些命令不安装 App 或登录服务。

高级页「打开数据文件夹」只打开已初始化的新工作区目录；配置、实例和合成验证独立于旧宿主。模型凭证按连接存 macOS Keychain，未完成电脑上的真实系统授权和在线验收时，以[实际验证记录](实际验证记录.md)为准。未经授权不导入旧资料、使用真实账号或调用计费服务。

高级页已移除旧角色资料交接入口；应用不会读取、导入、覆盖或删除旧资料。已经保存到新工作区的角色资料仍从「聊天 → ··· → 桌宠 Agent」查看。

## Electron 透明视频桌宠预览

龙妹与大肥鱼的封面和正式使用的视频均在 `.local/pets/` 按角色存放，布局及旧路径归位方法见[本机桌宠素材](管理工作区界面.md#右侧舞台立绘文件)。构建产物与临时会话中的副本不是源素材。

本节介绍独立 macOS 开发预览，与工作区使用同一原片，但不读写工作区配置，不访问 Codex 任务或语音。使用仓库现有 Electron 和 `python3`，额度查询需要 Python 3.11+；不需要 PySide6、Pillow 或 FFmpeg。固定 v0.5.1 归档须已保存在 `.local/pets/longmei/videos/bailong-desktop-pet-v0.5.1-windows-x64-webm.zip`；不自动下载。校验归档哈希后，仅在独立系统临时目录提取 35 段原片（153,885,547 字节），正常退出后回收；松手循环复用原片范围，不生成衍生视频。

```bash
pnpm run dev:pet-video-preview --check  # 只校验、提取并打包到临时目录，不打开 Electron
pnpm run dev:pet-video-preview          # 显式打开一只独立的透明视频桌宠
```

- 待机循环。左键拖动角色按速度切换走／跑／飞的运动段，停稳回默认姿态。轻放应停在松手位置；拖过至少 24 逻辑像素，且松手合速度达到 280 px/s 时才触发二维甩动，窗口物理不等视频首帧。松手只循环对应动作的有效段，碰边反向、收敛后短留姿态再回待机。系统减少动态效果跳过甩动和画面混合。
- 「视频预览 → 试播原始动作（不移动窗口）」按 ID 暴露全部原片。菜单试播运动原片不等同于自主移动。
- 鼠标停在龙妹身上会显示随指针移动的名字气泡，靠边时自动翻到窗口内侧。鼠标离开角色或开始拖拽时气泡隐藏；透明区域继续穿透。
- 在龙妹身上点右键（或 Control 点按）可播放工作动作、回到待机或停止当前预览，也可选择「查询额度」；双击角色也能查询。气泡内可刷新或关闭。查询使用当前 Codex 订阅或匹配的 TiMi CC 中转，不随预览启动执行。见[额度来源与验收](额度气泡说明.md#独立-electron-视频预览)。应用「视频预览」菜单的 `⌘⇧W`、`Esc`、`⌘Q` 仍可用。
- 与常规工作区之间切换，请先退出当前会话。启动脚本不停止其他进程，退出后未保存的窗口草稿不会恢复。
- 独立预览已确认原生窗口显示透明待机；工作区仍需分别实测背景、透明命中、动作切换、多屏、Space、拖拽手感和长期占用。

播放器从独立预览接入工作区的功能基线、素材核对与验收门槛见 [Electron 视频播放器迁移验收清单](Electron视频播放器迁移验收清单.md)。

### 「桌宠」默认视频播放器

先通过现有工作区状态栏「退出桌边小崽」正常退出，再运行 `pnpm run dev:desktop`。本机视频素材可用时，首次空工作区自动登记并启动龙妹；已有工作区按「桌宠 → 设置 → 基本 → 随应用启动」运行。旧配置未设置过该项时，只为首只龙妹补默认值（该实例须启用）；已删除的实例不会自动补回。分身默认不随应用启动。首帧确认后才标为运行，最多三个自有窗口，不接管旧实例。没有本机固定归档时管理页仍打开，龙妹不可播放；不会尝试 Qt 回退。保留设置与资料，不需要重新导入已有实例。

保存的名义尺寸、位置、全屏隐藏、自主活动和桌面移动启动时采用，已保存偏好可以单独应用；设置和会话显隐不提交配置修订。只有有效的拖拽松手位置成功写入时才更新 revision，弹簧后续、轻点、自主位移或拔屏回位不写位置。拖拽甩速依据真实指针轨迹；桌宠贴边后窗口与保存落点仍按屏幕边界裁剪。右键不打断甩动，正在拖拽或甩动时不应用尺寸。任务模式在菜单栏独立授权；已有任务不补播开工帧，任务不抢用户拖拽及甩动。右键「查询额度」和双击启用额度卡片；合格的互动/工作台词可由 Apple 芯片 Mac 已启用的本机语音播报。暂停清除本会话联动和自有桌宠，解除后不自动恢复。

运行 `pnpm run dev:desktop --check` 时还会核验鲸鱼妹的待机、封面与可选动作片段，并按动作名称列出缺失或哈希不符的片段；缺少可选动作不会阻止待机桌宠启动，缺少待机或封面则不能启动鲸鱼妹。

## 本机文件与空间

```bash
python3 scripts/clean-builds.py --caches --keep-prepared --dry-run
```

确认候选再去掉 `--dry-run`；`--keep-prepared` 保护旧会话或历史离屏对照仍在使用的 `generated-source`，新视频会话不依赖它。清理器只选应用自有的受限缓存和闲置 helper 归档，检查正在使用的路径；不会整体清除 `.local/` 或 `.build/`，不会删除素材、Qt/语音环境、用户资料或验证报告。现况与退役范围见[迁移状态汇报](macOS迁移状态汇报.md)。

停止相关 HMR／Vite 开发服务后，项目根 `node_modules/.vite` 与 `apps/workspace-ui/node_modules/` 下的 `.vite`、`.vite-temp` 可以清理。升级 Electron 时，若旧进程仍占用旧版本的二进制，保留该安装目录至正常退出，不为回收磁盘而强停。DSH 的 pnpm 安装闭包是运行依赖，不属于 Vite 缓存。

2026-11-19 的一次性清理另移除了旧完整应用的解包副本及两份旧 helper 构建备份，不是该清理器新增的默认选项。用户确认清除回退文件后，又移除了旧 DMG、helper 基线、旧构建暂存和 `v0.4.1-mac.3` 原版应用下载缓存；原始媒体及来源记录保留。日常工作区不需要这些产物；只有重做历史原版对照时，才用 `python3 scripts/prepare-full-pet.py fetch` 获取固定归档。切到视频并确认无旧进程占用后，可以回收已确认可再生的 `generated-source` 和独立的 PySide6／Shiboken6 组件。若 `PET_PYTHON` 仍指向 `.local/pet-build/venv/bin/python3`，不要整目录删除 `venv`：诊断、只读任务解析和素材包工具仍可按需调用该解释器，WebP 导入校验还需要 Pillow。不要删除视频入口需要的 v0.5.1 WebM ZIP。

本机已对确认哈希相同的 10 段扩展 WebP 用硬链接去重，保留历史素材和审阅输出两套路径。重新生成时用新文件原子替换，不要原地写入共享文件；不要对用户导入的素材包使用此做法。另清理了重复的 4K 实验视频和旧依赖残留，未动语音或超分模型。
