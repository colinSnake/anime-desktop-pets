# 桌边小崽 · 工作区 UI 设计

更新：2026-11-22。本文汇总工作区界面决定和实现边界。业务范围见 [PRD](prd.md)，执行证据见[实际验证记录](实际验证记录.md)。

## 共用设计原则

**角色有自己的颜色，但界面保持统一。** 用 macOS 工作区的清晰层级、紧凑控件和留白做骨架，把卡通感留给真实桌宠立绘、头像、星点和圆环。龙妹用柔紫，大肥鱼用雾蓝；将来增加桌宠，只补角色素材与色阶，不把侧栏、按钮、文字或状态重新染色。未知角色或素材缺失时，用中性占位，不套用龙妹的图或颜色。

侧栏由六个主页面共用同一套图标、宽度、行高和分组间距，只随窗口宽度变化，不随当前页变化。统一浅色、深色与跟随系统。用文字区分运行、停止、失败和未保存，不靠颜色传达状态。窗口原生系统控件保持不变；原型里的窗口框只用于示意。

切换左侧页面时，尚未载入的懒加载内容以轻量骨架占位，面包屑和侧栏保持稳定。骨架沿用中性表面色，窄窗改为单列；状态对辅助技术可读，系统启用减少动态效果时关闭 shimmer。

## 「桌宠」：桌边小窝（已落地）

| 区域 | 已实现的设计 |
| --- | --- |
| 工作区 | 紧凑的紫灰侧栏，带应用标识、线性图标与「桌边小窝」副标。标题右边并排是主题和添加；刷新、暂停联动在内容底部。首页不重复显示面包屑，但保留辅助导航语义。 |
| 角色舞台 | 左侧放角色名、运行状态、短句和明确的启停按钮；右侧放透明立绘、双圆环和星点。设置按需打开，分身与删除留在「更多」。 |
| 桌宠列表 | 多个角色时呈现紧凑头像行，单个可见角色不重复显示切换器。点选只改变舞台，不启动桌宠、不切换聊天对象。失败与未保存状态不因离开该行而消失。 |
| 图片交互 | 龙妹、大肥鱼的舞台封面和头像改用 2× 透明图，不调整布局。舞台封面、头像和占位图禁用浏览器默认的图片拖放；不影响头像行点选，也不改桌面上桌宠窗口的手动拖动。 |
| 大肥鱼 | 有本机素材时可从目录添加，不再只是样稿里的示意角色。添加后保持停止；显式启动才播放独立待机动画。共享启停、拖动位置、尺寸和显隐，不沿用龙妹的任务、额度或专属动作。第三方素材不随仓库分发。 |

已按确认稿比对浅／深主题和 760 × 560 合成窗口；这不是 Electron 实机多屏、Space 或拖动验收。相关历史证据见[样稿对照](../design-qa.md)，两位角色的本机封面与视频统一放在 `.local/pets/`，详见[本机桌宠素材](管理工作区界面.md#右侧舞台立绘文件)和[管理工作区界面](管理工作区界面.md)。

## 聊天页：「小话间」（确认稿已在 React 工作区落地）

新版保留按实例隔离的草稿与本轮消息，以及本机查询和在线发送。改版重点是：**当前在和谁说话、这条消息会不会出本机、长对话好不好读。** 不把「桌宠」的大舞台整块移植过来。

### 页面结构

- **页顶：** 左侧「聊天」及一句副标；右侧依次是当前聊天对象（头像＋名字）、主题和「更多」。多实例可切换，单实例显示静态身份；切换不改变桌宠舞台，也不启动桌宠。「桌宠 Agent」「聊天历史」（本机历史可用时）和「清空本轮聊天」放在更多菜单。身份、记忆、目标、能力不占侧栏；面板绑定打开时的聊天对象，不影响桌宠舞台或在途回复。
- **欢迎区：** 居中的小立绘、双环和轻角色色，与桌边小窝呼应。用「今天想和{角色名}聊点什么？」标明对象。龙妹用柔紫，大肥鱼用雾蓝，其他角色缺少专属封面时使用中性占位；不会把未知角色渲染成龙妹。四个本机查询短句对应已支持的身份、目标、知识和记忆指令；点击只填空白草稿并聚焦，知识和记忆留出关键词，不自动发送、不覆盖手写内容。本机查询不可用时不提供不可执行的快捷入口。
- **对话区：** 有消息后直接显示会话，欢迎立绘与快捷短句不再占空间。角色头像和名字在左，回复用中性正文；用户消息在右，用全局淡紫气泡。时间视觉显示到分钟，提示及辅助名保留秒；「本机资料」有文字标注，不只用颜色区分。消息和输入框对齐到同一列（最大 680 px），常规窗口只滚动消息区和超长输入正文。
- **输入区：** 底部常驻。输入框上方说明当前草稿的去向，右下保持选模和发送／停止等待。识别到本机指令时显示「本机查询」，不要求先选模型；非本机文字在可发送时显示「在线文字」并提示可能计费。没有模型时解释如何配置，而不是挡住本机查询。默认两行，常规窗口最多约七行，超出在 Lexical 编辑区内滚动。参考 Ape Agent Harness 的机制，按实例保留会话草稿与选区；纯文本粘贴、撤销、中文输入法防误发、Enter 发送、Shift+Enter 换行仍可用。`＋ → 预览 Markdown` 不改草稿或发送，不加载外部图像或链接。极矮视口限制输入框高度，并允许聊天内容区垂直滚动以到达操作，不裁掉发送按钮。

### 状态与边界

| 状态 | 界面表现 |
| --- | --- |
| 没有桌宠 | 中性图标与「去桌宠」入口，不展示一个似乎可发送的输入框。 |
| 未配置模型 | 在线发送禁用；本机资料可用时仍显示其短句、说明及查询动作。 |
| 等待／停止 | 对话末尾显示状态，原发送位置切换为「停止等待」。对在线请求不承诺服务商已停止处理。 |
| 失败 | 输入框上方显示原因及现有「重试／恢复输入」，不自动重发、不覆盖新草稿；路由变化时提示重新选模。 |
| 清空本轮 | 弹窗确认，清除当前窗口对话并重新开始；保留已保存的历史、未发草稿及角色资料。Esc 取消并返回触发处。 |

小话间不增加附件、语音、联网搜索或角色联动。在线发送明确展示所选模型、服务商及计费提示。新业务根下的会话续聊只携带本会话近期可回放的普通问答，本轮角色资料仍按逐项授权核对；本机查询与回答不进入模型历史。

### 聊天历史

「聊天 → ··· → 聊天历史」复用桌宠 Agent 的侧面板：宽窗右侧 468 px，600 px 及以下全宽。沿用浅／深主题、线条分隔和圆角列表；面板标题下标明当前桌宠，不另开 Tab，不用角色色重染控件。右上角 × 无边框、无底色；Esc 和宽窗左侧遮罩也可关闭并回焦菜单。遮罩不触发底下的界面，跨过面板边缘的拖拽不算点击。

每页最多五个会话，用固定排序边界翻页。每条为紧凑单行按钮：左侧聊天图标，中间「会话 01」等稳定编号，右侧最后完成时间和右箭头，不显示正文。点击整行或按 Enter／空格进入主区域的详情预览，沿用聊天头像、气泡与日期，默认显示最近六个完成问答；存在旧消息时，底部在续聊动作上方显示「更早消息／较新消息」和页状态，沿用聊天控件样式，每页仍至多六轮。加载失败保留现页并允许重试；「返回历史」或 Esc 恢复会话列表的分页、滚动和行焦点。

详情底部的「继续聊天」从任意回看页切换到同一会话最新状态的聊天输入页，并提示发送时近期可回放的普通问答会交给所选模型。只有用户发送才联网；模型选项可随时更换，回复仍追加到同一条会话。正在等待回复时禁用续聊切换，既不打断回复，也不替换原会话的草稿。「··· → 返回当前聊天」可回到先前的聊天。

分页与「清空历史…」留在底部；清空在原处二次确认，Esc 先取消确认。只清当前实例的已保存会话，不丢当前显示的消息、草稿或角色资料。其他会话的未发草稿从「聊天 → ··· → 恢复草稿 · 会话编号」返回输入页；菜单不显示草稿正文。已清空的问答不会继续发给模型。切模后显式重发同一未确认问题，若本机已保存回复，通过输入区状态说明已恢复、未调用模型。见[本机业务数据与聊天历史](本机业务数据与聊天历史.md)。

## 模型管理：同一工作区，分清保存与测试

**列表按服务商连接展示，模型参数收进弹窗。** 参考 Ape Agent Harness 的 `ModelSettings.tsx`、`ModelProfileFields.tsx` 与 `ModelSettings.module.css`：列表优先显示服务商名称，表单使用紧凑双列栅格，模型参数按需展开。React 工作区继续沿用「小话间」的浅／深底色、侧栏和圆角，品牌色只用在小图标上；不移植 Ape 的明文 Key 输入或额外模型字段。

| 画面 | 设计决定 |
| --- | --- |
| 服务商列表 | 同一连接无论配置几个模型都只显示一行。主标识显示服务商／自定义模型 API 名称，名称后留约 10 px 再放 9 px 状态点，点击区域为 28 × 28 px；行尾只有「编辑」「删除」两个文字按钮。不显示模型名、模型 ID、数量或协议。同一服务商品牌的不同连接仍按稳定连接 ID 分开，允许通过自定义连接名区分，不按品牌合并。状态点只反映当前保存版本的连接默认模型：成功绿、失败红、未测试黄，不汇总其他模型，也不代表同连接所有模型可用。主动作是「添加配置」，空态也从此进入。 |
| 模型列表空态 | 仅成功读到空列表时显示，以浅紫光晕、叠层图标和两颗星点呼应工作区；简述第三方模型提供商、自定义模型 API 和聊天选模，居中只放一个「添加配置」主入口。加载、读取错误和不可用状态不使用该卡片。 |
| 添加配置 | 「第三方模型提供商／自定义模型 API」保留独立草稿和各自的批量模型。首行左侧为厂商，右侧为接口协议；接口地址与 Key 状态各独占一行。Key 区只显示绑定状态和系统菜单入口，不显示或收集密钥正文。窗头与底栏固定，仅中间表单滚动。 |
| 编辑与参数 | 编辑打开所选连接，而不是单个模型。默认折叠「模型参数」并显示组数；展开后一个模型一组：第一行「模型 ID／配置名称」，第二行「上下文窗口／最大输出 Token」。容量支持 `K`／`M`，可留空。共用一套地址和凭证，可在同连接新增模型并聚焦新 ID；已保存的模型只能经独立删除确认。聊天选模仍显示模型名称。 |
| 连接选项与发现 | 将连接默认模型和全局默认分开；连接级改动应说明影响同连接模型。只对已保存且版本有效的连接发起发现，地址、协议或鉴权变更须先保存；发现候选不自动提交，也不标为生成测试通过。 |
| 测试与删除 | 单击状态点直接发送一次短测试，不打开弹窗；悬停提示测试结果、脱敏失败信息及可能计费，键盘可触发，状态文字可被辅助技术读取。测试中增加环形提示并阻止重复发送；缺 Key、未保存草稿或过期修订继续阻止测试。点击「删除」打开确认弹窗；有多个模型时先选定目标。删除非最后一项时保留连接；删最后一项时明确随之移除连接。若影响连接默认或全局默认，先处理替代；全局默认连接被移除时也可明确清空全局默认。 |

**保存、发现、测试仍是三个动作。模型连接测试参考 Ape Agent Harness 本机提交 `1598d68`：非 DeepSeek 官方地址的 OpenAI Responses 流式测试最长 60 秒、最多 256 个输出 Token，收到完整 `response.completed` 即校验固定回复；兼容网关可返回完整 JSON。DeepSeek 官方地址保留现有非流式探测。失败提示只显示固定错误类别，点击失败状态点可显式重测同一保存版本的默认模型，不自动重试。** 普通保存不联网。「保存后测试」默认不勾选，接口地址无效时禁用，明确标注请求次数与计费可能；仅在写入已确认后对已授权的保存版本执行，保存和测试结果分开报告。API Key 用可直接输入或粘贴的密码框，已绑定只显示状态，留空保留原凭证；切换地址或协议要求新 Key 或明确解除。仅固定保存动作提交新 Key，持久值仍在 Keychain。保留 schema v2、多厂商路由、双层默认和 DSH 接线。

列表和弹窗已接入 React 工作区。只有主动点击状态点才从列表发起短测试；打开或刷新列表不会测试。[实际验证记录](实际验证记录.md)分别记录合成浏览器检查与真实桌面、Keychain、厂商验收边界。

## 语音互动与直播管理（按确认稿实装）

两页沿用工作区的侧栏、标题、浅／深主题、按钮和状态表达。紫色龙妹、雾蓝大肥鱼只占状态横幅里的插画区，不绑定操作范围；整页功能不按插画角色分流。

| 页面 | 设计决定 |
| --- | --- |
| 语音互动 | 首屏先显示气泡播报状态。参考音色设置按「参考音频 → 音频逐字稿」排布，宽窗双栏、窄窗上下堆叠。音频显示是否已选择，不显示文件路径；逐字稿实时显示 UTF-8 字节数，上限 4096 字节，说明内容对应参考音频而不是待播报正文。两项就绪才可启用；已启用、准备中、播报中、失败或状态未确认时，突出「停止气泡播报」而不是再次启用。仅本次会话、本机生效，没有麦克风、试听或在线播报入口。 |
| 直播管理 | 首屏直说「平台尚未接入」。房间草稿可在 B 站／抖音之间切换，各自保留内容，草稿状态与连接状态分开。支持清空当前平台草稿；跨页保留，工作区重载或关闭后清空，不提供保存或连接按钮。平台授权、连接直播间、收发弹幕放在只读能力卡，窄窗排到草稿下方。 |

本机确认稿：`.local/design-speech-live-20261119/site/index.html`。已复刻到 React 工作区，保留正式的六项导航、系统窗口栏和「跟随系统／深色／浅色」切换；不搬入原型的预览工具条、示例数据或模拟窗口栏。参考音频选择、清除及播报启停沿用现有本机语音桥；直播仍只有内存草稿。两页封面沿用固定资源协议，禁止默认拖动，缺图有占位。

对照与验证见[实际验证记录](实际验证记录.md)和[设计验收](../design-qa.md)。语音设置在 490 px 及以下堆叠；直播两卡在 560 px 及以下堆叠。

## 高级：本机工作区（按确认稿实装）

「高级」左侧图标换为 Lucide `Settings2`，六项导航的结构和尺寸保持原样。右侧复用语音互动、直播管理的页头和系统／深色／浅色三态外观按钮。用带产品标识的淡紫资料夹延续双环、星点与卡通风格，不选某只桌宠作为系统功能代言。默认只显示工作区数据主操作和一项折叠的运行诊断。

| 区域 | 设计决定 |
| --- | --- |
| 工作区数据 | 首屏唯一主按钮「打开数据文件夹」，复用只打开本应用数据目录的现有操作，不显示路径。宿主未连接时禁用并说明原因。 |
| 运行诊断 | 默认折叠；展开只显示应用服务、当前平台和 Python 桥接的状态，操作区保留「刷新状态」及「运行 Python 诊断」。刷新不运行探针，失败才显示原因。窄窗诊断卡纵向排列。诊断不验证桌宠播放或联动。 |

## 桌宠 Agent（第一阶段实装）

「聊天 → ··· → 桌宠 Agent」打开同一实例的总览：身份显示当前保存的名称，记忆按个人记忆和角色知识显示数量，目标显示已保存的目标与步骤进度，能力列出实际可用的本机查询及在线文字聊天。四行点入原有详情，不新增侧栏或角色 Tab；保留记忆详情内原有的个人记忆与角色知识切换。候选确实可审核时才显示「待你确认」；只有资料读全且无逐项在线授权时才显示「资料仅本机」，未连接、加载、读取失败与空态分开。

宽窗右侧、600 px 及以下全宽。角色色仅用于头像及总览顶部装饰，控件、焦点和状态色沿用小话间。详情用「返回总览」恢复原行焦点和滚动位置；右上角为无边框、无底色的 ×，保留键盘焦点标记。点 ×、按 Esc 或点击宽窗左侧遮罩均可收起并回焦聊天菜单；底下的侧栏和页面不接收这次点击，拖拽跨过面板边缘不收起。换实例、删除或目标失效都会退出旧面板，不清聊天输入、不切舞台、不取消在途回复。

### 聊天内确认记忆（第二阶段实装）

欢迎页「记住一件事」只预填指令。写 `记住：…` 时，输入区显示「本机记忆 · 不发送到模型」；有效提交在发言正下方放一张沿用浅／深主题的卡，显示实例和原文。「保存为记忆」与「忽略」都不跳转、不增加 Tab。卡片区分等待、已记住、忽略、冲突和未确认；写入未确认时仅提供重读。确认保存的条目从现有 Agent 记忆详情查看。见[浅色宽窗与深色窄窗合成截图](实际验证记录.md#2026-11-20桌宠-agent-第二阶段聊天内确认记忆)。
