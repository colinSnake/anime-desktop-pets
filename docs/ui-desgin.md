# 桌边小崽 · 工作区 UI 设计

更新：2026-11-23。本文汇总工作区界面决定和实现边界。业务范围见 [PRD](prd.md)，执行证据见[实际验证记录](实际验证记录.md)。

## 共用设计原则

**角色有自己的颜色，但界面保持统一。** 用 macOS 工作区的清晰层级、紧凑控件和留白做骨架，把卡通感留给真实桌宠立绘、头像、星点和圆环。龙妹用柔紫，大肥鱼用雾蓝；将来增加桌宠，只补角色素材与色阶，不把侧栏、按钮、文字或状态重新染色。未知角色或素材缺失时，用中性占位，不套用龙妹的图或颜色。

侧栏由六个主页面共用同一套图标、宽度、行高和分组间距，只随窗口宽度变化，不随当前页变化。统一浅色、深色与跟随系统。用文字区分运行、停止、失败和未保存，不靠颜色传达状态。窗口原生系统控件保持不变；原型里的窗口框只用于示意。

切换左侧页面时，尚未载入的懒加载内容以轻量骨架占位，面包屑和侧栏保持稳定。骨架沿用中性表面色，窄窗改为单列；状态对辅助技术可读，系统启用减少动态效果时关闭 shimmer。

**输入焦点：**文本输入框与 `textarea` 聚焦时取消外圈，改用控件边框颜色提示焦点；聊天编辑区也只突出外框边线，不额外绘制阴影环。按钮、链接、复选框／单选框和其他非文本交互控件保留键盘焦点提示。

## 「桌宠」：桌边小窝（已落地）

| 区域 | 已实现的设计 |
| --- | --- |
| 工作区 | 紧凑的紫灰侧栏，带应用标识、线性图标与「桌边小窝」副标。标题右边并排是主题和添加；刷新、暂停联动在内容底部。首页不重复显示面包屑，但保留辅助导航语义。 |
| 角色舞台 | 左侧放角色名、运行状态、短句和明确的启停按钮；右侧放透明立绘、双圆环和星点。设置按需打开，分身与删除留在「更多」。 |
| 桌宠列表 | 多个角色时呈现紧凑头像行，单个可见角色不重复显示切换器。点选只改变舞台，不启动桌宠、不切换聊天对象。失败与未保存状态不因离开该行而消失。 |
| 图片交互 | 龙妹、大肥鱼的舞台封面和头像改用 2× 透明图，不调整布局。舞台封面、头像和占位图禁用浏览器默认的图片拖放；不影响头像行点选，也不改桌面上桌宠窗口的手动拖动。 |
| 大肥鱼 | 有本机素材时可从目录添加，不再只是样稿里的示意角色。添加后保持停止；显式启动才播放独立待机动画。共享启停、拖动位置、尺寸和显隐，不沿用龙妹的任务、额度或专属动作。第三方素材不随仓库分发。 |

已按确认稿比对浅／深主题和 760 × 560 合成窗口；这不是 Electron 实机多屏、Space 或拖动验收。相关历史证据见[样稿对照](../design-qa.md)，两位角色的本机封面与视频统一放在 `.local/pets/`，详见[本机桌宠素材](管理工作区界面.md#右侧舞台立绘文件)和[管理工作区界面](管理工作区界面.md)。

## 工作区弹窗统一关闭

- 应用内弹窗统一在右上角放无边框、无底色的 × 图标，保留可读名称和键盘焦点。点 × 或弹窗外空白处关闭，Esc 保留原有取消语义；拖拽跨过边缘不关闭，模态遮罩不把点击传给底下的页面。关闭不等于保存、删除、清空或授权；对写入反馈有锁定要求的弹窗保留锁定，已存设置和窗口内桌宠设置草稿不变。macOS 系统对话框及原生文件选择器保持系统样式。
- 「桌宠设置」最大高度 520 px（不足时再受视口限制并保留上下空白），标题和保存栏固定，正文滚动。分组及运行时应用流程不变。「桌宠 Agent」和「聊天历史」宽窗靠右 468 px，600 px 及以下左侧仍留 24 px 遮罩可用于关闭。

## 聊天页：「小话间」（确认稿已在 React 工作区落地）

新版保留按实例隔离的草稿与本轮消息，以及本机查询和在线发送。改版重点是：**当前在和谁说话、这条消息会不会出本机、长对话好不好读。** 不把「桌宠」的大舞台整块移植过来。

### 页面结构

- **页顶：** 左侧「聊天」及一句副标；右侧依次是当前聊天对象（头像＋名字）、主题和「更多」。多实例可切换，单实例显示静态身份；切换不改变桌宠舞台，也不启动桌宠。「桌宠 Agent」「聊天历史」（本机历史可用时）和「清空本轮聊天」放在更多菜单。身份、记忆、目标、能力不占侧栏；面板绑定打开时的聊天对象，不影响桌宠舞台或在途回复。
- **欢迎区：** 居中的小立绘、双环和轻角色色，与桌边小窝呼应。用「今天想和{角色名}聊点什么？」标明对象。龙妹用柔紫，大肥鱼用雾蓝，其他角色缺少专属封面时使用中性占位；不会把未知角色渲染成龙妹。四个本机查询短句对应已支持的身份、目标、知识和记忆指令；点击只填空白草稿并聚焦，知识和记忆留出关键词，不自动发送、不覆盖手写内容。本机查询不可用时不提供不可执行的快捷入口。
- **对话区：** 有消息后直接显示会话，欢迎立绘与快捷短句不再占空间。角色头像和名字在左，回复用中性正文；用户消息在右，用全局淡紫气泡。时间视觉显示到分钟，提示及辅助名保留秒；「本机资料」有文字标注，不只用颜色区分。消息和输入框对齐到同一列（最大 680 px），常规窗口只滚动消息区和超长输入正文。
- **输入区：** 底部常驻。普通在线聊天不显示常驻发送说明，底栏左侧为添加内容、语音按钮和「请求批准」，右侧为细环、选模和发送／停止等待。整排控件下移 5 px（顶部／底部内边距由 0／8 px 调整为 5／3 px），输入框外框和编辑区保持原位。识别到本机指令时显示「本机查询」，不要求先选模型。没有模型时解释如何配置，而不是挡住本机查询。正文预留两到三行高度，长草稿超过高度上限后在 Lexical 编辑区内滚动。参考 Ape Agent Harness 的机制，按实例保留会话草稿与选区；提交时冻结本轮内容并清空原草稿，不覆盖后续输入。纯文本粘贴、撤销、中文输入法防误发、Enter 发送、Shift+Enter 换行仍可用。`＋ → 预览 Markdown` 不改草稿或发送，不加载外部图像或链接。极矮视口限制输入框高度，并允许聊天内容区垂直滚动以到达操作，不裁掉发送按钮。

### 状态与边界

| 状态 | 界面表现 |
| --- | --- |
| 没有桌宠 | 中性图标与「去桌宠」入口，不展示一个似乎可发送的输入框。 |
| 未配置模型 | 在线发送禁用；本机资料可用时仍显示其短句、说明及查询动作。 |
| 等待／停止 | 对话末尾显示状态，原发送位置切换为「停止等待」。对在线请求不承诺服务商已停止处理。 |
| 失败 | 输入框上方显示原因及「重试／恢复输入」。交给在线桥后失败仍保持输入框为空，可手动恢复原文与选区；不会自动重发或覆盖新草稿。路由变化时提示重新选模。 |
| 清空本轮 | 弹窗确认，清除当前窗口对话并重新开始；保留已保存的历史、未发草稿及角色资料。点 ×、外侧遮罩或按 Esc 取消并返回触发处。 |

小话间支持当前回合的有界附件，不增加在线语音或联网搜索。输入框按用户截图采用一体式圆角卡片，底栏与正文同色、无分隔线。模型触发器显示模型名和下箭头，长名省略；悬停提示和选择列表显示完整模型名，不拼接服务商。开发模式热更新保留旧的聊天状态时，仍兼容旧的「模型名 · 服务商」在线显示格式，无需丢弃草稿。选模仍按已保存的连接和模型路由区分，服务商信息保留在模型管理。参照 Ape Agent Harness 的 `ExecutionControls`，模型和「请求批准」平时为透明底，悬停显示圆角胶囊，选模展开时保留胶囊底色，不挤动其它控件。发送用圆形上箭头，等待时换为停止按钮。「请求批准」打开锚定输入区的双选项气泡，不另启任务弹窗；「完全允许」只作用于本轮明确选择的材料。细环不表示用量，普通聊天目前没有可显示的 Token 用量。底栏不显示快捷键文案，原有按键行为不变。移除普通聊天的常驻计费说明，不改变可能计费的行为；本机指令、无可用模型、失败及附件审批提示保留。新业务根下的会话续聊只携带本会话近期可回放的普通问答，本轮角色资料仍按逐项授权核对；本机查询与回答不进入模型历史。

模型选择按截图分两步：点击当前模型先开思考深度气泡，默认「高」；顶部显示当前等级，中间模型名与右箭头，底部为可键盘／拖动调整的离散滑杆。等级与模型名／箭头包在同一个圆角视觉分组，悬停任意一行或键盘焦点进入模型按钮时统一显示背景；移出且组内无焦点时恢复透明，模型按钮不单独显色。滑杆留在分组外，点击行为仍只绑定模型行。滑杆已填充的轨道和滑块描边使用项目亮紫色 `--brand-violet`，未填充轨道仍为中性色；思考等级文字使用随主题切换的紫色文字 token `--accent-text`。点击模型名行后，第一个气泡关闭并切换为按服务商分组的模型列表，两者不会叠放；模型项只显示模型名，当前项以勾选标识。Escape 关闭并回焦触发器，模型列表打开时焦点移到当前模型。推理能力只对已审核的服务商地址、协议和模型身份开放；不支持的模型直接打开模型列表，不显示虚假的思考滑杆。等级按当前连接路由保存在桌宠会话中，并随发送请求冻结，重试保持原等级；不改已保存模型配置。模型管理的「模型参数」组中，每个模型下增加「思考深度」选项，初始显示「高」，切换后随该模型配置保存；未知能力保持不可选。

### 项目会话与权限气泡

聊天侧栏「项目与会话」保留未分配会话；标题行的 `＋` 新建项目文件夹，项目行 `＋` 新建独立会话，展开的项目显示有界会话列表。主区域标注当前项目。建立项目只在系统选择的位置创建目录，不读取文件。旧「Agent 任务」弹窗和菜单入口撤下，保留「桌宠 Agent」身份资料面板。

输入区加号右侧为权限胶囊。菜单沿用用户截图的 324 px 圆角浮层：灰色「应如何批准 {桌宠名} 操作？」、右侧下划线「了解更多」，两行带图标、说明与选中勾，说明为 11 px，标题保持 13 px。「请求批准」沿用中性色；「完全允许」的标题、说明和图标（含选中勾）始终用主题暖色，输入区选中后的权限文案用同一颜色。默认「请求批准」，点击发送后在同一聊天内显示附件审批卡；跳过不发送附件。点击「完全允许」时收起菜单，不在菜单追加确认或提示行。独立确认弹窗参考 Ape Agent Harness：520 px 居中面板、警告标题、三行图标范围卡、风险提示和右对齐的「取消／确认」。文案只说明本轮已选附件及未授予的终端和网络权限。确认后即刻更新胶囊，取消、Esc 或点击遮罩不改变状态；关闭回焦到胶囊。浅／深主题适配，长名字可换行，窄窗限制宽高并允许内部滚动。

### 聊天历史

「聊天 → ··· → 聊天历史」复用桌宠 Agent 的侧面板：宽窗右侧 468 px，600 px 及以下左侧保留 24 px 遮罩。沿用浅／深主题、线条分隔和圆角列表；面板标题下标明当前桌宠，不另开 Tab，不用角色色重染控件。右上角 × 无边框、无底色；Esc 和左侧遮罩也可关闭并回焦菜单。遮罩不触发底下的界面，跨过面板边缘的拖拽不算点击。

每页最多五个会话，用固定排序边界翻页。每条为紧凑单行按钮：左侧聊天图标，中间「会话 01」等稳定编号，右侧最后完成时间和右箭头，不显示正文。点击整行或按 Enter／空格进入主区域的详情预览，沿用聊天头像、气泡与日期，默认显示最近六个完成问答；存在旧消息时，底部在续聊动作上方显示「更早消息／较新消息」和页状态，沿用聊天控件样式，每页仍至多六轮。加载失败保留现页并允许重试；「返回历史」或 Esc 恢复会话列表的分页、滚动和行焦点。

详情底部的「继续聊天」从任意回看页切换到同一会话最新状态的聊天输入页，并提示发送时近期可回放的普通问答会交给所选模型。只有用户发送才联网；模型选项可随时更换，回复仍追加到同一条会话。正在等待回复时禁用续聊切换，既不打断回复，也不替换原会话的草稿。「··· → 返回当前聊天」可回到先前的聊天。

分页与「清空历史…」留在底部；清空在原处二次确认，Esc 先取消确认。只清当前实例的已保存会话，不丢当前显示的消息、草稿或角色资料。其他会话的未发草稿从「聊天 → ··· → 恢复草稿 · 会话编号」返回输入页；菜单不显示草稿正文。已清空的问答不会继续发给模型。切模后显式重发同一未确认问题，若本机已保存回复，通过输入区状态说明已恢复、未调用模型。见[本机业务数据与聊天历史](本机业务数据与聊天历史.md)。

## 模型管理：同一工作区，分清保存与测试

页头直接显示「模型管理」，不再显示上方的「工作区 › 设置」。标题下方以次级色显示「聊天和弹幕演练默认使用首个已保存的服务商。」

**列表按服务商连接展示，模型参数收进弹窗。** 参考 Ape Agent Harness 的 `ModelSettings.tsx`、`ModelProfileFields.tsx` 与 `ModelSettings.module.css`：列表优先显示服务商名称，表单使用紧凑双列栅格，模型参数按需展开。React 工作区继续沿用「小话间」的浅／深底色、侧栏和圆角，品牌色只用在小图标上；不移植 Ape 的明文 Key 输入或额外模型字段。

| 画面 | 设计决定 |
| --- | --- |
| 服务商列表 | 同一连接无论配置几个模型都只显示一行。主标识显示服务商／自定义模型 API 名称，名称后留约 10 px 再放 9 px 状态点，点击区域为 28 × 28 px；行尾只有「编辑」「删除」两个文字按钮。不显示模型名、模型 ID、数量或协议。同一服务商品牌的不同连接仍按稳定连接 ID 分开，允许通过自定义连接名区分，不按品牌合并。状态点只反映当前保存版本的连接默认模型：成功绿、失败红、未测试黄，不汇总其他模型，也不代表同连接所有模型可用。「添加配置」主按钮固定在「已配置的服务商」标题行最右侧。 |
| 模型列表空态 | 仅成功读到空列表时显示，以浅紫光晕、叠层图标和两颗星点呼应工作区；只保留空态标题，不重复展示说明文案或第二个添加入口。添加操作统一由标题行最右侧的「添加配置」按钮进入。加载、读取错误和不可用状态不使用该卡片。 |
| 添加配置 | 「第三方模型提供商／自定义模型 API」保留独立草稿和各自的批量模型。首行左侧为服务商，右侧为接口协议；接口地址与选填的 API Key 各独占一行。密码框不回显已绑定的密钥。窗头与底栏固定，仅中间表单滚动。 |
| 编辑与参数 | 编辑打开所选连接，而不是单个模型。默认折叠「模型参数」并显示组数；展开后一个模型一组：第一行「模型 ID／配置名称」，另显示可选的「上下文窗口」。容量支持 `K`／`M`，可留空。有支持规则的模型显示「思考深度」，默认「高」；不展示工具能力、输入类型或输出 Token 字段选择，普通保存保留同一路由已有设置；改地址、协议或模型 ID 后不沿用旧路由的能力。共用一套地址和凭证，可在同连接新增模型并聚焦新 ID；已保存的模型只能经独立删除确认。聊天选模仍显示模型名称。 |
| 连接默认与发现 | 有多个模型时可设置连接自己的默认模型。聊天未主动换模时和弹幕演练统一使用首个已保存服务商的连接默认，不显示全局默认控件。只对已保存且版本有效的连接发起发现，地址、协议或凭证变更须先保存；发现候选不自动提交，也不标为生成测试通过。 |
| 测试与删除 | 单击状态点直接发送一次短测试，不打开弹窗；悬停提示测试结果、脱敏失败信息及可能计费，键盘可触发，状态文字可被辅助技术读取。测试中增加环形提示并阻止重复发送；未保存草稿或过期修订继续阻止测试；未绑定 Key 不阻塞测试。点击「删除」打开确认弹窗；有多个模型时先选定目标。删除非最后一项时保留连接；删最后一项时明确随之移除连接。删除非最后一项且影响连接默认时先选同连接的替代模型；删除整个连接不要求手动指定全局替代。 |

**保存、发现、测试仍是三个动作。模型连接测试参考 Ape Agent Harness 本机提交 `1598d68`：非 DeepSeek 官方地址的 OpenAI Responses 流式测试最长 60 秒、最多 256 个输出 Token，收到完整 `response.completed` 即校验固定回复；兼容网关可返回完整 JSON。DeepSeek 官方地址保留现有非流式探测。失败提示只显示固定错误类别；本机凭证不可用或其他未确认结果在列表上方显示原因，不改写已确认状态点。点击失败状态点可显式重测同一保存版本的默认模型，不自动重试。** 普通保存不联网。「保存后测试」默认不勾选，接口地址无效时禁用，明确标注请求次数与计费可能；仅在写入已确认后对已授权的保存版本执行；已授权的连接默认模型排在首位，首个未成功结果终止本批，不追加授权范围外的模型。保存和测试结果分开报告。API Key 用可直接输入或粘贴的密码框，已绑定只显示状态，留空保留原凭证；切换地址或协议要求新 Key 或明确解除。本地校验失败保留新 Key 并提示字段；仅在实际提交固定保存动作时清空密码框，持久值仍在 Keychain。保留 schema v2、多厂商路由、双层默认和 DSH 接线。

列表每次进入模型管理页都会自动读取已保存配置，不再提供列表刷新图标；自动读取只同步本机配置，不触发模型连接测试。已有草稿会保留，若保存版本发生变化则按原有冲突保护要求重新核对。只有主动点击状态点才从列表发起短测试。[实际验证记录](实际验证记录.md)分别记录合成浏览器检查与真实桌面、Keychain、厂商验收边界。

### 直播管理 · 紧凑科技控制台（2026-11-26 更新）

保持工作区原有主题色板，以细线分组、等宽参数、区块序号和紧凑间距做出控制台感；静态设计稿的冷蓝色与面包屑不采用。页头和各区不放重复的常驻使用说明或英文标签，状态、操作受限原因和失败恢复提示按需显示。侧栏、窗口框架与 16:9 节目画面不变。宽窗和窄窗均全宽堆叠：舞台输出 → 布景与摆位 → 主播互动。

- **直播桌宠放在页标题右侧。** 复用聊天的头像、名称和原生下拉控件，独立于聊天与桌面选择。默认龙妹；选鲸鱼妹明确显示「暂不支持直播」，不展示或调用龙妹的舞台操作。开台准备、运行中或状态待确认时锁定切换。
- **舞台输出置顶。** 集中显示本机状态、1920 × 1080、16:9、节目声轨状态及 OBS 浏览器源；主按钮按状态切换「开启直播台／准备中／关闭直播台／重试开启／重新读取状态」。预览和复制地址只有开台后可用。成功开台后在支持环境后台准备龙妹声音，不显示独立声音开关。输出规格显示声轨准备或就绪；缺少配置、忙碌或失败在输出区提示。准备不影响换景和画面，也不自动发声；桌边小崽预览不输出声音。失败提示紧挨输出操作；素材准备失败不等于原片缺失，开启本机画面源不等于推流。
- **只留六个正式布景缩略图。** 删除大幅「布景示意」及重复展示。选中保留描边与对勾，卡片空间充足时附状态文字。主内容宽度至少 680 px 时，左列显示布景卡，右列集中横向位置、角色大小、保存与状态；位置和大小使用百分比数值框，两侧「−／＋」逐点微调，可直接输入或用方向键。窄窗参数回到布景卡下方，不挤压缩略图。停台时可编辑摆位并显式保存，每套独立记住摆位；没有常驻已保存提示。点卡片内容停台时改草稿，开台时保存并换景；右上角四角展开按钮独立打开只读预览。等待确认期间保留旧选中态，换景提示不占用舞台输出区域；OBS 地址不变，摆位和角色切换保持锁定。
- **主播互动采用精简弹幕输入区。** 打招呼、开心一下、比个心放在一排；演练保留圆角编辑区、清空草稿和发送箭头，不显示已发送弹幕、回复正文、Enter 提示或字数。回复只在节目画面显示；管理端不显示未开台提示或停止按钮，只按需显示处理、失败及不支持提示。普通 Enter 提交，输入法确认候选不提交；空白、未就绪或处理中不可发。仅舞台确认接受后清草稿，未确认或被拒绝时保留。关台、暂停或手动动作仍可撤销演练；模型与计费说明仅保留在使用指南，失败不回退到预设；沿用原有浅／深主题，不连接真实平台。

初版设计稿保留在本机 `.local/design-live-control-20261125/`；双列布景、精简输入区的离屏截图分别见 `output/playwright/live-scene-columns-20261126/` 与 `output/playwright/live-compact-20261126/`。合成浏览器与原生验收边界见[实际验证记录](实际验证记录.md)和[设计验收](../design-qa.md)。

### 通用图片预览蒙层

## 桌宠 Agent（第一阶段实装）
