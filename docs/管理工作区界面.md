# 桌边小崽管理工作区

更新：2026-11-10。

## 界面结构

模型管理、直播语音、角色与记忆由同一个可调整大小的「桌边小崽」窗口承载。窗口采用深色品牌侧栏、图标加文字的一级导航，以及右侧明亮内容区；状态栏原有三个入口保留，但分别打开同一窗口并选择对应页面。互动气泡语音快捷开关仍留在状态栏，实例管理也不并入本工作区。

模型和语音表单保留 AppKit 控件及既有存储、Keychain、麦克风、参考音频和回调逻辑；角色页复用 CharacterUI 工作区及其本地聊天、身份和记忆安全门禁。窗口关闭时取消录音并取消当前语音聊天轮次，重新打开时复用已创建的模块控制器。

当前主要入口为 `CompanionWorkspaceWindow`。视觉使用原生窗口与 SF Symbols，不更改动画桌宠、Qt 菜单或气泡样式。

## 离线预览

`scripts/preview-character.sh` 仍使用临时数据目录打开工作区。模型页的保存、Keychain 删除和连接测试均禁用；语音页的麦克风、演示和设置保存均禁用；角色聊天保留离线能力，需在线回答的问题会拒绝执行。预览不启动桌宠 helper、不访问在线模型。

## 验收边界

Swift 全量测试只验证可编译性及已有业务回归，不等同于窗口视觉验收。需在用户明确要求时启动 `scripts/preview-character.sh`，检查标准与窄窗口、三页切换、角色子页、滚动、键盘焦点、关闭时录音清理及深浅系统外观。状态栏真实入口和正常配置写入需另行人工验收。
