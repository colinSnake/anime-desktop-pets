# 海报设计说明：月白龙姬 · 紫雾工作室

更新日期：2026-10-30。
**当前仅为设计说明，图片服务尚未接入，未生成原创海报，也未应用首页背景。**

## 1. 设计目标

与现有启动视频和白色/淡紫桌宠保持色彩与氛围协调，但不直接复刻第三方角色、服装或姿势。
作品首先是安静的编码工作区背景，而不是广告、软件截图或高亮展示墙。

## 2. 画面规格

- 横向 16:9，目标母版 3840×2160，最终以服务实际支持的尺寸为准。
- **原创**银发龙娘，淡紫眼睛、精致弯角、半透明龙翼、月白与淡紫服装。
- 人物位于最右侧约 25–30%，朝画面内侧看。
- 中央约 55–60%、左侧栏与下方输入区保持安静、低细节、低对比。
- 场景为午夜梅紫工作室，微弱月晕、柔和紫雾、稀疏晶线与少量冰蓝高光。
- 不出现文字、商标、水印、虚构应用 UI、霓虹代码雨或杂乱装饰。
- 代码、差异、终端与弹窗保持不透明、清晰可读；插画主要用于首页背景。

## 6. 模型服务交接

模型名严格使用用户指定的 `gpt-image-2.5`，不能擅自替换，
也不能由名称推断其为官方可用模型。用户后续提供 base URL 与本地密钥来源。
实施前确认：

1. 生成/编辑端点路径，以及实际支持的请求字段。
2. 尺寸、质量、参考图能力与返回格式，包括 base64、URL 或流式响应。
3. TLS 与认证要求，诊断时不打印密钥或 Authorization 头。
4. 费用、限额与第一次付费请求的明确同意。

密钥仅放被忽略的本地 `.env` 或系统钥匙串，不进入 Git、图片元数据或示例配置。
配置占位见 `config/image-provider.example.json`，当前禁用。
条件不完整前不实现猜测接口，也不发送请求。
