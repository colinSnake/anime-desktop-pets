# 语音互动验证指南

适用：2026-11-25 的源码开发工作区、Apple 芯片 Mac。当前保留两条本机能力：桌宠互动气泡播报与固定短句试听；按住说话只生成可编辑草稿，需手动发送。普通聊天回复仅显示文字，不自动朗读；这不是常开麦克风或全双工通话，也不代表直播设备／平台已接入。

## 先准备

1. 如正在运行旧开发工作区，用本项目菜单的「退出」正常退出后重开；只点窗口关闭是隐藏，不能加载新的主进程／preload。不要退出官方 Codex、强停进程或删除数据。
2. 在仓库根目录手动运行：

   ```sh
   pnpm run dev:desktop:static
   ```

   此命令打开本项目 Electron 工作区，并按已保存偏好启动桌宠，不启动官方 Codex。本文的自动检查未运行此命令或操作真实音频设备。
3. 降低系统音量，建议戴耳机，避免扬声器回授；本机关卡无需发送在线消息。
4. 本机需要已有 `.local/voice-runtime/venv/bin/python`、ASR `Qwen3-ASR-0.6B-8bit` 和 TTS `Qwen3-TTS-12Hz-0.6B-Base-8bit` 权重。目录存在不等于模型加载或设备已验收；缺失时查看[语音运行时](../apps/speech-runtime/README.md)，不要默认下载或触发在线替代。

## 第一关：只测本机试听

1. 打开「语音互动」，点「选择参考音频」。要求 PCM WAV，1–30 秒、最多 6 MiB；8–48 kHz、单／双声道、16／24-bit。使用本人或已授权的声音，不使用不明来源素材。
2. 本机已有的可莉音频 `.local/voice-runtime/results/klee-voice-reference.wav` 可直接用于本次测试（约 17.93 秒、24 kHz、单声道、PCM16）。原生文件选择器可按 `⌘⇧G`，输入该文件的本机完整路径后选择。文件仅保留在本机，不随项目分发；其他环境请使用你有权使用的参考音频。
3. 在「音频逐字稿」填写与参考音频一致的原话。本机可莉样本的转写草稿在 `.local/voice-verification-20261124/klee-transcript.txt`，由本机 ASR 转写并校正角色名，请以原音为准。之前的系统合成参考已删除，不再使用。
4. 点击「启用气泡播报」。
5. 在「设置参考音色」底部点击「停止播报」左侧的「试听一句」，并保持工作区聚焦。预期只听到一次固定短句：

   > 你好，我是桌边小崽。这是本机语音试听，不会发送在线请求。

6. 点「试听一句」后，同一个按钮会变为「停止播放」。在准备或播放中再点它，只取消本次试听，不关闭气泡播报。停止确认或自然结束后会恢复「试听一句」，不必重新启用。失焦、最小化、隐藏、离开语音页或开始录音均取消试听，不应迟到重播。

试听不打开麦克风、不调用服务商、不自动播放逐字稿。与桌宠气泡共用单一播放槽，其他声音忙碌时拒绝试听，不抢播。首次加载可能较慢，不能把按钮已受理当作实际发声。

### 验证重启恢复

首次使用新版时，旧进程里仅存内存的音色不会自动迁入。重新选择一次 WAV；选择成功会把音频副本保存在 `~/.adpets/speech/`。填写逐字稿后暂停输入约 0.4 秒，文字会自动保存，不需要先启用。然后分别验证两种重启状态：

- **未启用时退出：**在启用前正常退出并重开。应看到参考音频与逐字稿已加载，状态仍是「未启用」；不会自动预载／朗读。
- **启用后退出：**点击「启用气泡播报」，确认状态「已启用」后正常退出并重开。应恢复为「已启用」，并预载本机 TTS。「模型准备中」变为「模型已就绪」以 worker 确认为准，并不代表扬声器已经播放。启动本身不发声、不打开音频输出设备；此时触发一条有效气泡，它会等待同一 worker 就绪，不需要再点一次。隐藏、拖动、停宠或暂停仍会取消旧句。点「停止播报」并再次重启后，应回到「未启用」，但保留音频与逐字稿。

若提示「逐字稿尚未保存」，最新有效稿在当前窗口内保留待重试；离页时会尝试保存，回到语音页会重试。退出前确认错误消失，未成功写入的文字不保证在重启后恢复。

替换成不同音频会先清除旧的服务端逐字稿，语音页会把当前输入重新保存为新参考音频的逐字稿；「移除」只删除应用保存的副本和逐字稿，不删除原件。旧格式资料若没有启用标记，一律按未启用恢复。

## 加测：桌宠气泡与朗读同步

1. 保持气泡播报启用且龙妹可见，单击龙妹触发带台词的动作；也可等待定时问候。不要用「试听一句」代替，试听按钮不会显示桌宠气泡。
2. 确认气泡从准备到整句读完都还在，动作结束或回到待机不应让它提前消失；声音结束后气泡至少再停留约 0.7 秒，同时保留原本的最短阅读时间。
3. 再触发一次，朗读中主动隐藏或拖动龙妹。气泡应移除，本句取消；重新显示不应续播旧句。「停止播报」后，普通文字气泡仍按原时长收起。
4. 如需比时延，分别记下「刚启用就触发」和「模型已加载、90 秒内再次触发」从气泡出现到实际听见首音的时间。预加载不播放，空闲回收后首句会再次冷启；离线首块 PCM 测量不等同于扬声器首音。

## 第二关：只测按住说话

1. 打开「聊天」，确认输入框为空且没有附件；先不要发送在线消息。
2. 按住麦克风；若首次提示需要权限，单独点「授权麦克风」，在 macOS 系统提示中选择允许。**授权本身不开始录音**。
3. 重新按住麦克风，说 2–5 秒非私密测试句，例如「你好，这是本机语音转写测试」，然后松开。
4. 若气泡播报已启用，系统会先确认停止 TTS，再打开麦克风；录音与转写期间不会同时加载 TTS 和 ASR。转写完成后，只有工作区仍可见且没全局暂停时才异步预载 TTS，保存的启用偏好不变。停止未确认时不会打开麦克风。
5. 预期松开后麦克风指示结束，转写结果只进入当前会话的可编辑草稿，**不自动发送、不生成模型回复**。可手动修改或删除。录音最多 30 秒，少于 1 秒可能被拒绝。
6. 再测试按住时按 `Escape` 及切换到其他应用。预期停止录音、不填入取消的结果；迟到的设备打开／识别结果不能覆盖新输入。
7. 若录音被取消或窗口隐藏，预期清理本次 ASR 工作，并且不在隐藏窗口预热 TTS。建议仍使用耳机，减少桌宠气泡或环境声音被麦克风收录。

若改用「＋ → 语音转文字（本机）」选择 WAV，只有在文件被选中并通过格式校验后才会暂停气泡 TTS；取消选择或 WAV 无效不应卸载已预热的 TTS。有效音频开始本机转写前，必须先确认 TTS worker 已关闭；转写结束后仅在工作区可见、未全局暂停且播报仍启用时预载，不改变保存的启用偏好。

录音 PCM 仅在本机受限转写链中使用，不向模型发送音频，不写录音文件。若用户之后手动发送，转写出的**文字**会按所选模型和本轮授权出站。

## 普通聊天回复

普通聊天回复仅显示文字，不自动朗读。需要语音验证时，请按上面的步骤单独测试本机试听或桌宠互动气泡；在线聊天仍须由用户手动发送，可能产生服务商费用。

## 不符合预期时

| 现象 | 先检查 |
| --- | --- |
| 没有「试听一句」或麦克风入口 | 是否在 Apple 芯片 Mac 的最新 Electron 工作区；主进程改动必须正常退出后重开，网页夹具不提供真实设备桥。 |
| 显示「退出后重开应用，再试听」 | 开发页热更新了，但仍连接旧主进程或旧服务。退出本项目应用后重新运行 `pnpm run dev:desktop:static`，只关窗不会更新主进程。 |
| 试听灰色 | 先选择有效 WAV、填准确逐字稿并启用；其他播报／录音忙碌、运行时不可用或状态未确认时不允许试听。 |
| 显示「已启用 · 模型预载失败」 | 本机模型未启动成功或 30 秒内未报告就绪，不是音色被清空。保持语音页聚焦，可点一次「试听一句」重试；仍失败再核对本机运行时。 |
| 一直准备或没有声音 | 保持窗口聚焦，核对系统输出设备和音量；记录等待时长及页面状态，不要连续重试。模型首次加载和真实听感尚未验收。 |
| 状态未确认或停止失败后无法重试 | 用「停止播报」确认取消全部播放，之后重新启用再试听；不要删除配置／Keychain／模型，不用强停外部进程恢复。 |
| 麦克风被拒绝 | 在 macOS「系统设置 → 隐私与安全性 → 麦克风」检查启动本工作区的应用权限，再按页面提示操作。系统权限主体以实际系统提示为准。 |
| 有草稿但没有回复 | 这是预期：必须核对草稿并手动发送；如果手动发送也失败，先单独检查保存的模型路由，不要将模型故障误判为 ASR 故障。 |
| 桌宠气泡没有朗读 | 确认已启用气泡播报、窗口与桌宠仍可见，运行时和输出设备可用；普通聊天回复不自动朗读。 |

反馈时提供：失败关卡、按钮／状态文字、识别是否出现、是否发声、停止是否生效、持续时间和脱敏错误。不提供 API Key、私密音频或个人对话。

## 证据边界

- 自动化覆盖固定短句、受限 IPC、鉴权／严格路由、忙碌互斥、气泡／试听来源隔离、试听修订乱序、停止失败门禁、界面按钮与模拟浏览器流程。
- 已用本机可莉样本通过正式 WAV 格式检查、离线 ASR 转写和一次真实本机 TTS 合成；合成 PCM 只在内存中计数，未保存或播放，不代表听感或设备已验收。
- 真实麦克风、扬声器、系统权限、首音延迟、尾音、连续多轮及安装包仍需按以上步骤人工验收。没有自动调用服务商或执行付费请求。
- 实际命令及结果见[实际验证记录](实际验证记录.md)；实现范围见[本机试听计划](superpowers/plans/2026-11-24-local-speech-preview.md)。
