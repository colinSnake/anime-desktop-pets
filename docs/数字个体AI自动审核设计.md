# 数字个体 AI 自动审核设计

更新日期：2026-11-15。

## 目标

让桌宠在用户明确开启后，自动从当前临时聊天中发现有证据的个人记忆，并按低风险自动确认、高风险转人工的规则处理，减少用户逐条审核普通内容的负担。系统不保存完整聊天，不允许模型直接执行文件写入，也不自动改写角色人格核心字段或无来源的角色知识。

## 用户控制和数据范围

- 自动审核默认关闭；仅在角色资料页由用户显式开启。
- 开启前清楚说明：每累计3条尚未处理的用户发言，应用最多发送最近6条用户发言给当前配置的 OpenAI-compatible 模型做额外审核；这是独立于聊天回复的附加请求，可能产生费用。助手回复、既有记忆、身份、API Key 和能力上下文不发送给审核请求。
- 聊天发言只保留在现有窗口内存中。自动审核只在窗口运行期间处理尚未审核的发言；退出或关闭窗口会丢弃未提交批次，不后台恢复或追踪。
- 任意时刻可关闭自动审核。关闭后不再发新审核请求；正在进行的请求允许取消，迟到结果丢弃。
- 授权采用保守关闭策略：开启必须先保存成功，保存期间不收集待审核发言、不发审核请求；保存失败保持关闭。关闭立即取消并清空当前批次，保存失败也不在本窗口恢复授权，同时明确提示关闭设置未保存、下次打开窗口可能仍读到旧授权，需修复后重试关闭。此处不承诺磁盘写入失败后仍能改变下次启动的配置。
- 快速启停的设置写入串行执行，过期的保存结果不得更新当前开关或状态；最后一次操作决定最终保存值。资料刷新不覆盖本窗口已明确作出的开关选择。设置授权代际与聊天审核批次代际分开管理，清空聊天不撤销或覆盖开关保存。已经要求的本地设置保存会执行到完成，不因关闭工作区而在任务尚未开始时丢弃；完成或失败后释放模型，不将这一生命周期延长套用到在线审核请求。
- 离线预览不提供开启入口，也绝不发送网络请求。

## AI 输出与审核分级

模型只可返回 `fact`、`preference`、`episode` 三类建议。每条只包含来源用户发言 ID、逐字证据和置信分；资料正文直接采用原话，不采用模型改写文本。每批最多6条，单条发言最多1,200字符；仅整条用户发言可自动保存，局部引用进入人工队列。不接受 `knowledge` 或身份字段输出。

宿主逐条执行确定性校验：引用必须指向本批用户发言且为其原文连续子串；格式、大小、类型和置信分必须有效；内容及来源通过现有凭证检测。凭证类直接拒绝保存。完全重复项静默跳过。符合现有低风险自动确认策略且置信分不低于0.90的候选可自动确认并写入本机，在线分享始终关闭。低置信、敏感、过期、冲突或来源不足的候选进入待确认列表，并说明原因。

自动审核不是事实判定器。人格核心（姓名、角色、背景、性格、价值观、动机、关系、知识范围和边界）永不由模型自动更新；没有可核验来源的角色知识也不自动导入。普通聊天产生的性格/语气建议可作为带原话证据的个人偏好记忆自动审核，不覆盖人格字段。

## 处理时机与故障

- 仅在一条聊天答复正常完成后检查待处理发言；达到3条才启动一批，不阻塞答复呈现。
- 同一有效审核批次不并发启动第二批；处理期间新增发言进入下一批。待审核队列只保留窗口 transcript 中最近最多6条用户发言，已被 transcript 裁剪的发言 ID 一并移除，不持久化积压队列。关闭或清空后旧请求可能仍由服务商处理，但宿主取消其任务并使批次代际失效，迟到回调不会释放或改写新批次状态。
- 缺少配置/凭证、网络失败或模型输出无效时不保存本批建议，并释放当前请求名额；不立即重新调度，也没有计时轮询，仅在后续新的成功答复后重试。提供器主动取消同样释放名额、等待后续答复，不永久卡住。
- 清空聊天同步使旧批次失效、取消任务并丢弃未处理发言；已保存记忆与开关授权保留，新聊天重新累计3条。关闭自动审核也同步失效和丢弃未处理批次。
- 单条建议的最新记忆读取、重复/冲突判定和写入在存储 actor 的同一个同步操作内执行，操作开始及写入前检查任务取消；清空/关闭发生在等待存储期间时，排队的旧建议不会继续落库，并发建议也不能基于同一份旧快照各自重复插入。最终刷新记忆列表后再次检查取消和批次代际，防止迟到结果更新界面。
- 多条建议逐条保存，不承诺跨文件或整批事务；已进入同步写入的操作不能撤回，清空聊天不删除已保存记忆。本地存储中途失败时不删除已写记录，重试仍执行既有重复/冲突门禁。
- 提案和批次检查均为内存状态；不增加聊天历史或审核请求正文日志。

## 验收

- 合成 HTTP 测试断言审核请求只带批次中的用户发言和短提示，不包含助手文本、身份、既有记忆或凭证；断言关闭开关和离线预览时请求数为0。
- 领域测试覆盖阈值、逐字证据、无效 turn ID、无效类别/置信分、凭证拒绝、重复跳过、冲突/敏感人工队列，以及自动保存默认关闭分享。
- 合成真实存储/actor 屏障测试覆盖开启等待落盘、开启/关闭保存失败、失败后刷新不得恢复旧授权、修复后重试、快速启停、立即关闭工作区时仍完成撤销授权保存并释放模型，以及重新打开读取最后设置。已有调度测试显式等待开启授权保存完成后再累计发言。
- 界面状态覆盖关闭、启用说明、自动完成、待人工处理、失败与关闭后取消；离屏测试中离线预览无自动审核开关。
- 不连接真实服务、不加载真实记忆、不读取真实 Key，不以自动测试替代真实在线和 UI 人工验收。

## 关联：表达适应与真实评测

普通记忆自动审核不等于人格自我改写。新增独立的有限表达适应层只从完整明确反馈调整三项表达维度，有历史/回滚/重置和独立分享；日常AI气泡仅接收粗粒度事件，不能读取审核批次、记忆或任务。固定18条合成语料的真实模型验收和指标分母见[桌宠自主表达与验收](桌宠自主表达与验收.md)，本轮实际结果见验证记录；前述“自动化不联网”指离线回归，不包括明确批准后单独执行的付费合成验收。
