# 桌边小崽：菜单功能与交互边界

更新：2026-11-10。目标是少入口、准确语义、明确确认，不以占位菜单展示规划。
项目名仍为 Anime Desktop Pets；按用户进一步要求，构建包名与系统显示名统一为「桌边小崽」。Bundle ID、内部可执行名与配置/数据路径保持兼容。

## 1. 两个菜单，各负其责

| 位置 | 保留的职责 | 不承担的职责 |
| --- | --- | --- |
| 宿主状态栏 | 单宠显示/隐藏或多实例启动/停止；实例与尺寸管理；联动暂停；高级配置；退出宿主 | 不重复罗列全部动作，不提供模型聊天、海报/主题占位，不为打开客户端再造入口 |
| 动画桌宠右键/自身托盘 | 本只显隐、尺寸、全屏让位、自主活动、动作预览、显式额度查询、退出本只 | 不安装宿主、不改官方客户端、不自动查询额度、不创建另一个角色 |
| 静态降级右键 | 隐藏；通过宿主状态栏恢复 | 不称为完整动画，不提供重复的“结束本次”入口 |

已认可的 Qt 卡片菜单圆角、行高、按文字定宽、键盘导航和气泡样式保持不变；本次调整信息层级，而不是换皮。

## 2. 状态栏逐项契约

- **显示/隐藏桌宠**：单只外部桌宠走 Qt 窗口级控制，不把后台代理应用的 macOS 隐藏调用成功与否当作窗口隐藏。隐藏后暂停动画 tick，恢复不激活客户端、不改尺寸。
- **启动/停止全部桌宠**：仅存在有效多实例配置时显示；实质是按现有名额恢复启用实例，或停止所有运行实例，不是假装隐藏窗口。默认最多同时运行3只，包含原宠；实例清单最多登记32只。三只实机采样中 helper CPU 均值约55%（单核100%口径）、RSS中位数约901MiB且峰值约1129MiB，因此3只作为保守默认上限合理；这不是对所有机器的性能保证。
- **实例管理**：按 helper 最近确认的状态列出实例；helper 握手期间明确显示“正在读取桌宠实例状态”，不把清单快照伪装成实时状态。子菜单提供单只启停、尺寸与删除已停止分身；删除需确认，只移除定义，不删除素材或独立状态目录。
- **状态文案与命名**：原宠显示“龙妹 · 运行中”，分身显示“龙妹·分身”等名称；状态不再附加“下次启动恢复”。自动恢复策略不变。历史 `white-dragon` 等内部 ID 仅为兼容配置/协议保留，不作为角色展示名。
- **桌宠管理**：位于“实例管理”子菜单。使用宿主原生窗口扫描项目默认目录、已导入包和用户选择的本地目录，支持 `.petpack` 或含有效 `manifest.json` 的展开目录；⌘/⇧ 多选、全选，一次最多添加16只。后台完整校验后批量登记，已有包引用不重复添加，新实例保持停止。普通 `.app` 或散图目录不作为兼容桌宠。首次添加也沿用确认后的单宠安全交接，但不额外创建未选择的分身。
- **创建与恢复**：“创建小分身”复制同包引用、不复制动画媒体，新实例登记为停止且默认不随宿主启动自动恢复。用户单只启动后才加入下次自动恢复；单只停止会关闭该实例的自动恢复。手动“启动全部”仍会启动全部已启用实例。暂停时不得从实例入口绕过宿主门禁。
- **首次创建**：仅默认增强版龙妹且当前单宠确由本宿主控制时，在状态栏显示“创建龙妹分身”。用户确认后，宿主先请求原 helper 退出并异步确认进程结束，再启动唯一的多宠控制器；取消不改状态。新清单只在明确缺失时创建，原宠白名单偏好保留，分身独立偏好并保持停止。原版、静态降级、无归属或退出结果不确定时不提供/不继续切换，不会强启第二个控制器；启动/清单结果不确定时，退出并重开宿主可根据磁盘状态恢复，不要重复提交创建。
- **素材库入口已移除（2026-11-05）**：按用户决定，宿主不再提供“打开宠物素材库”，构建不再附带 `DragonPetLibrary.app`。素材包解析、引用保护和开发 CLI 保留以兼容多宠运行时；不删除已有素材或实例数据。
- **暂停/恢复联动**：仅在 launch/watch 模式提供；暂停会隐藏/停止展示并停止任务跟随授权。恢复不补播已有进程动画。暂停状态的主操作为“恢复陪伴”，不留下无效的“显示”。
- **管理工作区入口**：模型管理、直播语音、角色与记忆三项状态栏入口打开同一个「桌边小崽」可调整大小窗口，并定位到对应页面；侧栏导航承载三个模块，实例管理不并入。交互气泡语音快捷开关仍留在状态栏。窗口样式和验收边界见[管理工作区界面](管理工作区界面.md)。
- **互动气泡语音开关**：位于“模型管理”之后、“直播语音”之前，作为状态栏顶层可勾选项显示“互动气泡语音：已开启/已关闭”。它控制 `speakInteractiveBubbles`：任何实际显示的气泡均进入本机朗读；状态栏菜单或管理窗口交互期间等待交互结束，期间的新气泡覆盖旧气泡，默认只朗读最后一条。TTS cue 送出后，气泡按文本长度估算 3–30 秒的朗读显示时长，并保留最大时长兜底；无气泡的动作不朗读；主动生成的语音回复不由此开关控制，且不重复朗读。开启前必须具备有效参考音频书签、路径和准确转写；切换只保存本地偏好，不启动语音运行时、不联网。设置不可用时显示禁用项，写入失败则保留原状态并提示错误。
- **高级**：打开数据文件夹与窗口同步设置；数据文件夹保存用户配置、实例清单、已导入素材包（含包内动画素材）、搜索目录、实例偏好/状态和诊断/运行数据，不含内置龙妹动画素材。当前目录名为 `AnimeDesktopPets`；旧目录会安全迁移并保留兼容符号链接。窗口同步未授权时显示，点击后打开系统设置，不自动请求权限。
- **待机问候**：仅内置龙妹在可见、无任务且无用户交互时低频显示龙妹问候气泡；其它宠物包不套用龙妹专属文案。不读取或引用 Codex 内容，用户开启减少动态效果或关闭自主活动时不自动弹出。
- **退出桌边小崽**：退出宿主并清理其拥有的桌宠。对本宿主启动、且支持窗口协议的增强 helper 正常请求退出；宿主还把自己的 PID 传给 helper，异常退出或超时退出时由 helper 自己回收，避免变成孤儿进程。不退出/重启 Codex，也不关闭既有独立 helper。旧 helper 不支持协议时不强杀，反馈能力不足。

状态栏菜单打开时刷新；运行错误以限长状态文案显示。异步命令返回后更新状态，不能用“请求已投递”声称动画/窗口已经完成动作。

## 3. 动画桌宠做减法

- 三组“互动/工作/待机差分动画”收进 **动作预览**；保留原动作内容、选中态和手动触发，不再占三个顶层入口。
- 没有可用工作动作时隐藏该组，不展示“预留6个位置”。
- 自主活动开关与手动表演仍分离；关闭自动调度不等于禁用手动预览。减少动态效果与任务/拖拽优先规则不变。
- 额度查询是已实现的显式能力，保留；不为本轮菜单测试访问真实额度。不扩展任务读取范围。

## 4. 窗口控制与扩展边界

增强单宠 helper 的 `dragon_visibility.py` 提供独立于多宠协议的窄窗口契约：`show / hide / status / quit`。
仅宿主启动且声明 `windowControlProtocol=1` 的 helper 启用；端点为用户临时目录内按 UID/PID 命名的 Unix socket。
服务端权限0600、最多8连接、单请求256字节、1秒空闲超时、校验目标PID；未知指令/空连接不触发显示。
客户端在后台串行队列执行，未发送的过时意图可以取消，已经发送的未知结果不重放。退出时先排空队列，以AppKit模态运行循环可执行的回调确认退出；不在GUI线程等待socket，不读取正文/窗口标题；多宠仍用原有类型化控制器，不互相替代。

后续新入口必须同时具备实际实现、错误反馈、权限/线程/退出约束及回归；不为“将来可能有用”加入顶层菜单。
跨角色扩展走素材包/实例契约，不把龙妹专用动作或客户端假设写进通用菜单。
