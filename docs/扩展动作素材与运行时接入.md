# 扩展动作素材与运行时接入（2026-10-31）

## 当前松手规则（2026-11-02／dragon.30）

达到24px位移和最近150ms合速度280px/s的明确甩动，每次等概率随机奔跑追羽毛或飞行，朝向跟随松手；两种均只循环有效运动段，直到弹簧落到当前屏幕可用区底部并收敛才回默认待机。不会每次上下反弹重新抽选，也不会播放疲惫／停止收尾。轻放不弹且原地默认待机；普通自主／手动移动仍播放完整动作。姿态循环沿用同一播放器时钟，独立物理计时及既有共享资源预算不变。下文按日期／版本记录的内容为历史接入过程；本轮证据见[实际验证记录](实际验证记录.md)。

## 回待机与尺寸连续性（dragon.30）

- 跑步／飞行弹跳真正落底收敛后，仍直接回默认待机，但回切采用280ms eased预乘alpha渐变，不插入疲惫、停止或落地素材。原先160ms过短，现保留源姿态直到待机首帧就绪再计时；其它非拖拽过渡仍160ms。
- 用户设定的50%／100%／150%显示尺寸、解码尺寸和原有`renderScale`／`renderOffset`校准在拖拽前后保持。旧通用`pose_bridge`按透明包围盒临时缩放（限0.9–1.1），会把尾巴、展翅、羽毛的外框差异也当作角色尺寸；拖拽／自主移动相关切换不再使用此临时缩放，只按固定校准混合。自然侧身／抬腿／展翅的轮廓仍不同，不强行改变素材比例。
- 60ms回环／镜像接缝、独立50%随机、甩动力度与落底轨迹不变；再次拖拽从当前可见合成画面开始，不回旧原帧。减少动态效果优先，不强制280ms渐变。
- 不改写原35动作、派生WebP、源清单或用户偏好；不新增定时器、整段解码或缓存预算。真实桌面流畅度仍需人工验收。

## 松手专项优化（dragon.29）

- 每次明确甩动独立50%抽选一种动作，允许“跑、跑、飞”；轻放不抽选、不弹跳。不增加随机／只跑／只飞偏好，也不在同一轨迹里反复换动作。
- 四个左右跑／飞片段生成松手专用短循环，原35动作与清单不改写。按身体及羽毛的黑底合成RGB差选较近首尾，再预乘alpha重采样至384px（当前最大显示尺寸），以无损WebP编码；这是派生缓存，不是原创补帧，也不是相对720px源图完全无损。普通自主／手动移动继续用完整原片。
- 回环／撞墙转向用60ms局部混合，不重新播放160ms入场，不暂停姿态时钟；物理时钟仍独立于WebP。转向只镜像GUI绘制，不换文件，水平速度绝对值小于60px/s保持上一朝向以防抖。
- 合速度从280至1200px/s连续映射力度，初始目标升高约运动区高度8%至75%（受小屏保护），回弹系数约0.46至0.66；竖直方向仍尊重松手趋势。轻甩无需触顶，重甩更高／更久，最终都落当前可用区底部。
- 非正常长轨迹在8秒后用1.2秒smoothstep落底兜底，避免12秒从半空硬写地面；兜底中地面改变则从当前位置重新平滑收敛。任务／再次拖拽／隐藏等主动中断仍保留当前位置。
- 派生目录`dragon-release/`及catalog记录源描述、源／派生SHA-256、帧区间、时长及接缝评分；生成脚本进入构建指纹，摘要进入`DRAGON_PATCH.json`。运行时只在描述匹配、安全相对路径、存在文件和合法时长时使用；缺失或损坏则安全回退原片，不在GUI线程校验整段媒体哈希。
- 共享48MiB QImage、8MiB QPixmap、最多8帧预取和单解码闸门不变。派生媒体约19.3MiB，内容缓存与本机素材输出优先硬链接；缓存无效时原片兼容路径不承诺同样的等帧改善。真实Cocoa桌面和长期资源仍待验收。

| idle04 | 贴贴枕头 | 待机 |

原版 App 与上游源码保持只读；增强 App 已重建为 build 9 / `dragon.6`。菜单与气泡样式不变，
只在待机菜单和自主活动子菜单增加动作入口。自主待机轮转覆盖完整待机与互动动作池；工作差分仅保留任务和手动入口，不进入日常池；走/跑/飞移动仍是独立分支。动作切换桥接按透明边界稳定可见尺寸，过渡结束回到目标原始姿态。
已运行进程不会热更新，本轮不自动重启桌宠或启动真实桌面预览。

## 可复现入口

压缩包放在被 Git 忽略的 `.local/animation-sources/`，无需手动解压。
在项目根目录执行：

```bash
.local/pet-build/venv/bin/python scripts/prepare-extra-animations.py
.local/pet-build/venv/bin/python scripts/test-extra-animations.py
```

需要 Pillow（已有构建虚拟环境）及带 `libvpx-vp9` 解码器的 FFmpeg / FFprobe。
不安装新依赖、不调用图片服务、不播放真实桌面窗口。
脚本固定检查本轮压缩包的大小与 SHA-256；这是本机输入身份检查，不冒称已核验发布者签名。
逐文件读取 ZIP 时同时检查 CRC，并拒绝路径越界、超大帧缓冲和不同内容的现有源文件。

输出目录：`.local/animation-sources/jingh12312-v0.5.1-extra/`。

- `*.webm`：保留原始 10 段视频。
- `source-manifest.json`：完整上游清单，含渲染锚点、缩放、位移段和朝向。
- `webp/*.webp`：720 × 720、透明、多帧、无损转换的审阅版。
- `extension-manifest.json`：只含 10 个新增动作，路径指向本地转换后的 WebP，供构建合并。
- `conversion-audit.json`：帧数、时长、尺寸、透明度、散列及可见像素/时序一致性记录。
- `player-compatibility.json`：现有 Qt 解码器对每段首/中/尾帧的读取检查。
- `previews/*.gif`：缩小并降帧的深色底预览，非播放器实际效果或透明源素材。
- `previews/idle-contact-sheet.png`、`movement-contact-sheet.png`：每段首帧、约 1/3、约 2/3、尾帧联系图。

转换强制使用 `libvpx-vp9`，避免默认 VP9 解码忽略独立 alpha 通道；保留原视频逐帧时间戳，
不强行套用恒定 42ms。无损 WebP 重新逐帧解码，与源视频按可见 RGB、alpha 和时间轴比较。
编码器允许合并完全相同的相邻画面，但合并后的画面与持续时间必须完全相同。
质量参数只控制无损压缩努力，不启用有损颜色压缩；生成产物通常比源 VP9 大。

## 可复现构建接入

```bash
python3 scripts/build-pet-runtime.py build
./scripts/build.sh
./scripts/test.sh
./scripts/dragonctl.sh --check
```

`scripts/extra-animation-overlay.py` 先检查 10 个 ID、源包身份、WebP 散列、审计结果与运动时段，
再将原始输出复制到脚本持有的 `.local/pet-build/generated-source/outputs/`，只在私有副本新增 `dragon-extra/` 和合并清单；最终运行素材仍单独保留于 `.local/pet-build/source/outputs/`。
原始素材不再用可写 symlink 共享；原版 App、原版清单和固定源码哈希保持不变。
随包保留 `outputs/DRAGON_EXTRA_SOURCE.json`、10 段素材散列及上游随包说明；元数据标识 `dragon.6` / build 9。
Swift 和 Python 检查同时支持完整原版 25 动作与完整增强 35 动作，拒绝不完整扩展；不静默降级为 PNG。

### 运行方式

- **待机差分动画**：默认待机、待机02，以及翻绘本、贴贴枕头、玩掌机、贴尾巴。
- **自主活动 → 走路 / 跑步 / 飞行**：6 个方向明确的手动预览入口。菜单/弹窗渲染模块没有改样式。
- 定时静默调度为 12–24 秒；普通动作使用洗牌队列轮转完整待机/互动/可用工作池，避免纯随机长期漏播。位移分支使用新移动素材。
- 默认待机仍以 4:1 偏好优先，但新增待机也会参与自主调度；真实任务保持交互优先，不会打断任务动作。
- `ClipMotion` 按播放器首帧就绪后的时钟运行；只在 `moveStartMs` 到 `moveStopMs` 移动，起步和收尾位置固定。
- 自主待机位移按可用屏幕尺寸扩展：走路目标为屏宽18%（至少160、最多420逻辑像素），跑步27%（至少240、最多520），飞行34%（至少300、最多640）；飞行上浮约屏高22%（至少112、最多280）。可用距离不足时按边界裁剪，顶部空间不足时降低弧高。
  手动移动与自主调度共用此范围，结束保持新位置；不循环起步、不倒放、不突然回原点。
- 任务、隐藏、菜单、拖拽、聊天、关闭位移及系统减少动态效果仍可阻止或中断移动；中断保留当前位置。
  没有其他窗口识别或物理平台；自动活动不会读取桌面内容、发起聊天/额度、发声或弹台词。
- 手动预览移动可在关闭定时活动时使用，但仍尊重位移开关、任务与减少动态效果；用户可打断普通非任务动画。

### 松手衔接与验收边界

松手经确认改为方向飞行/快速横甩跑步，进入运动前 200ms，使用已呈现画面约 160ms 预乘 alpha 混合；动作自然收尾后再混合回待机。飞行上浮与最多 96px 惯性仍受屏幕边界约束。
显示按 WebP ANMF 逐帧时长选择索引、按清单总时长对齐；呈现时钟在冷加载/混合/缺帧期间暂停，位移读取同一时钟。卡顿单步最多 50ms、等待超过 5 秒或解码错误回退待机。再次按下/任务等最新指令打断并捕获当时混合画面，不排队播放旧动作。
这些是短姿态混合，不是骨骼插值或新生成帧；过渡中可能看到轻微重影。
真实桌面、多屏/Space、焦点、长期 CPU/RSS 和连续切换手感仍待人工验收。
本轮没有重启或强制结束任何既有桌宠/Codex 进程，也没有安装登录项。
