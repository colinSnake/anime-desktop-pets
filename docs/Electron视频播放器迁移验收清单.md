# Electron 视频播放器迁移验收清单

更新日期：2026-11-19。范围是 macOS 普通 Electron 工作区从 Qt worker 切至 Electron 原生窗口及 `<video>`；不是所有旧宿主功能的迁移承诺。源代码切换、现役进程交接、磁盘回收和真实桌面是不同验收项。Windows/Linux 播放器仍不开放，其他旧功能见 [macOS 功能迁移清单](macOS功能迁移清单.md)。

## 素材基线：35 个动作都能找到源片

对照本机 prepared Qt 的 `素材清单.json` 与固定 v0.5.1 WebM 归档中的清单。归档大小及 SHA-256 与现有预览固定值一致；按组核对非空动作 ID、顺序、文件存在性及 WebM 一一对应关系。逐段临时提取并核过 CRC、VP9 流和首帧 Alpha，**35/35** 为 720×720、Alpha 实际值覆盖 0–255。原视频共 **153,885,547 字节（约 146.8 MiB）**，不是最终安装包大小或实际省盘量。

| 动作组 | 必须纳入的 ID | 数量 |
| --- | --- | ---: |
| 待机 | `idle`、`idle2`、`idle03`、`idle04`、`idle05`、`idle06` | 6 |
| 互动差分 | `01`、`04`、`05`、`08`、`09`、`13`、`14`、`17`、`18`、`20`、`21`、`22`、`24`、`25`、`26` | 15 |
| 拖拽／落地／额度 | `drag`、`landing`、`quota` | 3 |
| 工作 | `work01`、`work02`、`work03`、`work04`、`work05`（清单第六槽为空，不算缺片） | 5 |
| 位移 | `move01left`、`move01right`、`move02`、`move02left`、`move03left`、`move03right` | 6 |

- 独立预览的固定白名单和试播菜单覆盖 35 段；原片合计 153,885,547 字节，只在会话临时目录准备退出回收。首帧透明不代表全片透明边缘、触发条件及运动节奏等价。
- Qt prepared 还有四条**另外生成**的松手循环（`move02`、`move02left`、`move03left`、`move03right`）；不计入原 35 段。视频后端复用四段原片范围，已有接缝和转向混合、独立物理时钟的自动化证据，仍需实机手感对照。主要证据见[扩展动作与运行时接入](扩展动作素材与运行时接入.md)及[增强构建记录](桌宠增强与性能构建.md)。

## 本机大肥鱼（可选）

[显式准备素材](管理工作区界面.md#macos-本机使用大肥鱼)后，固定版本的大肥鱼与龙妹分别校验资源。启动命令只带已登记包的标识与版本，不传路径；主进程从固定角色会话解析资源。大肥鱼的协议域只允许自己的待机 WebM、固定播放器界面与同源的已核验本机界面字体，不提供龙妹动作或台词文件。三个运行槽、首帧、停止、暂停和显隐门禁共用。大肥鱼默认不登记、不自启；添加后显式启动。待机、拖拽和原生窗口的实机验收与离线合成测试分开记录。

## 旧 macOS 右键菜单与气泡对照

工作区已按 `d15e783` 补齐右键菜单：临时隐藏、五档尺寸、全屏让位、两个行为开关、手动表演、六方向移动及三组单次动作预览。应用与合并保存由当前实例和启动代次约束，失败及回退状态在工作区反馈。保留额度查询和停宠。自动化覆盖私有边界、提交失败、拖拽与任务门禁；原生菜单手感和多屏未执行。详见[菜单交互](菜单功能与交互边界.md#现役-electron-工作区桌宠右键2026-11-19)。

普通对白和现有任务短句对齐旧卡片的 12 px 圆角、浅深色、居中和柔和阴影。龙妹与大肥鱼的悬停名字气泡，以及龙妹的对白、任务短句、额度卡片文字和播放失败提示，共用核验过的本机 `SSRuanTangTi`，不可用时回退至圆润系统字体。字体仅暂存至私有会话目录，暂存独立于龙妹归档校验；仅有大肥鱼素材时也可使用。额度卡片的刷新和关闭图标及原生菜单保留系统字体。从源码正常启动会重新构建样式；只重开旧构建中的窗口不会更新。布局与字体路由各有离线检查，不代表 Electron 混合透明窗的实机视觉验收。不迁旧聊天模式、任务结果卡片或在线气泡。

## 实机交接与剩余工作

1. `pnpm run dev:desktop --check` 仅核对并临时提取固定原片。使用旧工作区状态栏的「退出桌边小崽」收尾，确认 Qt worker 退出，再运行 `pnpm run dev:desktop`，确认默认龙妹无需手动点击即可出现。可在「设置 → 基本」关闭「随应用启动」后重开核对，并确认手动停止或解除暂停不触发重新启动。想要同时打开 Codex 才用 `pnpm run dev:desktop:codex`。
2. 覆盖三实例、独立关闭、暂停及重启、连续甩动、跨屏／Space、透明区命中、焦点和全屏策略。按需显式体验任务、账户额度和本机语音，另记耗时、长期占用和听感。
3. 现役进程仍占用的 `venv`、`generated-source` 及旧 `dist` 不能提前清理。退出后须确认不再被其他进程使用，区分专用 Qt 环境、历史基线素材、Python/Pillow 素材校验和独立语音运行时。不得删除原始 WebM 归档、唯一素材或用户数据。

运行证据见[实际验证记录](实际验证记录.md)。
