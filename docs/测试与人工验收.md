# 测试与人工验收

实际执行证据见[实际验证记录](实际验证记录.md)；旧宿主测试不再属于当前入口，过去的结果继续作为历史记录保留。

## 自动检查

```bash
pnpm run check:cross-platform
python3 scripts/check-project.py
pnpm run dev:desktop --check  # macOS，有固定本机 WebM 归档时
```

`check:cross-platform` 不启动 Electron 或 Qt。固定原片检查不启动窗口。旧 `scripts/test.sh` 及 Fusion/offscreen Qt 对照只用于历史辅助工具，不是 Electron 运行或构建前置。自动检查仅用合成账号与任务输入。缺少环境导致的跳过单列，不能计通过。不要把真实账号、聊天、任务、麦克风或模型服务用作自动化输入。

聊天界面、角色资料和 DSH 的定向离线复跑见[聊天与智能体验证](聊天与智能体验证.md)，不需要运行 Electron 或 Qt。

## 真实桌面验收

不依赖播放器的身份、记忆、目标、模型和聊天链路可先跑[当前工作区合成验收](龙妹聊天与记忆验收.md#当前-electron-工作区验收2026-11-19)。其重启验证的是回环服务和私有资料持久化，桌面页面交互另行验收。

用户选择安全时机，按[本地开发与使用指南](本地开发与使用指南.md)显式启动。分别记录冷／热启动、焦点和窗口恢复、播放视频和音轨、Dock／状态栏、屏幕和 Space、拖拽与全屏、暂挂及多宠停止确认、退出清理和长期占用。遇到原生崩溃首先阅读本轮诊断报告，避免反复触发。

资料备份、恢复、Keychain、真实厂商和计费、语音听感及签名／安装各自保有独立验收结论。源代码退役和离屏回归通过都不能替代这些证据。Windows/Linux 播放器保持阻塞。
