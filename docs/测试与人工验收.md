# 测试与人工验收

测试通过必须注明范围。自动测试不能证明真实桌面的声音、焦点、多屏或主题效果正确。
已实际执行的结果见 [实际验证记录.md](实际验证记录.md)，需求依据见 [PRD](prd.md)。

构建增强版前需要按 [桌宠增强与性能](桌宠增强与性能构建.md) 准备专用 Python 3.12 环境与辅助应用。
`./scripts/test.sh` 在环境齐备时运行 79 项离屏增强层测试和 9 项真实白龙适配器测试；
多实例计划/启动队列另由 `swift test --package-path apps/companion-macos` 与 `scripts/test-multi-pet.sh` 覆盖。
基准为实际 WebP 的离屏取帧与进程 RSS，不等于 Cocoa 实机验收。

## 1. 自动检查（不改变 Codex）

在项目根目录运行：

```bash
# 新环境先显式获取完整桌宠；此步访问网络，但不运行桌宠。
python3 scripts/prepare-full-pet.py fetch
./scripts/build.sh
./scripts/test.sh
./scripts/dragonctl.sh --check
```

各入口职责如下：

| 入口 | 覆盖范围 | 不覆盖 |
| --- | --- | --- |
| `swift test --package-path apps/companion-macos` | 配置验证、淡出时间、按进程生命周期、隐藏/结束、过期回调、下次启动重置、播放看门狗、消息类型 | 真实 AppKit 窗口与焦点 |
| `python3 scripts/test-full-pet.py` | 固定来源、哈希、归档路径、符号链接、完整清单、离线自检参数的模拟测试 | 不下载或执行上游应用 |
| `python3 scripts/check-project.py` | Shell 语法、安全默认值、模板无密钥、本地媒体哈希、海报占位状态 | 模型或主题真正可用 |
| `python3 scripts/test-control.py` | 构建后的实际二进制，在临时目录以隔离服务模式验证 Socket | Codex 启动观察与桌面窗口 |
| `python3 scripts/test-pet-build-inputs.py` | 增强 helper 源码指纹新鲜度检测 | 冻结二进制行为本身；需要结合冻结归档检查 |
| `scripts/test-real-pet-adapter.py` | 实际补丁 Pet 类、真实工厂/控制器、合成小动画、两实例偏好/尺寸/首帧/停止 | macOS Cocoa、真实显示器、真实素材长时间运行 |
| `./scripts/dragonctl.sh --check` | AVFoundation 元数据、媒体时序、资源与客户端发现 | 实际声音与视觉交接 |
| `codesign --verify --strict "build/Dragon Codex Companion.app"` | 本地 ad-hoc 签名完整性 | Developer ID、公证与公开发行资格 |

`./scripts/test.sh` 先运行 Swift 和两组 Python 离线检查；仅在构建二进制已存在时执行 Socket 测试。
首次完整检查应先构建。Socket 测试使用临时数据目录，不注册 Codex 观察器、不显示窗口、
不安装登录项、不发模型请求，覆盖权限、类型化命令、畸形/超大消息、单实例和退出清理。

小分身命令和 Qt lifecycle 使用合成窗口；`test-real-pet-adapter.py` 则在 offscreen 环境实例化
当前固定来源的真实补丁 `Pet`，素材是测试临时目录中的微型合成 WebP。冻结 helper 还应检查
`DRAGON_PATCH.json` 输入指纹，并确认 PyInstaller PYZ 内含当前 `clone_pet` 协议模块。

**禁止把正常 `--launch` 或 `--watch` 放进自动测试**，以免激活当前用户客户端。

## 2. 手动预览方法

在项目根目录运行一个模式：

```bash
./scripts/dragonctl.sh --preview-animation
```

该命令持续占用前台；视频结束后伴侣仍在运行。用菜单栏退出，
或在另一个终端标签页进入项目根目录后执行 `./scripts/dragonctl.sh --quit`。
等实例退出，再运行 `./scripts/dragonctl.sh --preview-pet`。
不要把两个预览模式连续粘贴到同一个终端并期待第一个自动返回。

预览不启动或激活 Codex，但会显示伴侣窗口，必须由用户主动运行。

| A01 | 仅预览动画 | 声音、画面填充、无意外全屏接管、跳过快捷键、淡出、无残留遮罩 |
| A02 | 仅预览完整桌宠 | 真实待机/点击/拖拽/落地、不抢焦点、分类菜单、隐藏/唤回与位置恢复 |

| A07 | 动画中隐藏或结束桌宠 | 动画结束后仍尊重手动意图；客户端退出清理原生桌宠 |
| A08 | 隔离配置下媒体损坏或时序异常 | 可安全失败，不留下永久覆盖层 |
| A09 | 多屏、缩放、断屏、全屏、Space 切换 | 位置合理、全屏让位、无窗口丢失或错误遮挡 |
| A10 | 完整外部桌宠生命周期 | 复用既有实例、启动中隐藏、伴侣退出隐藏自有实例而保留独立实例、不强制终止任务 |
| A11 | 海报与主题准备完成后 | 首页、代码、差异、终端、弹窗、窄窗口可读性，实际截图、降级与恢复 |
| A12 | 用户同意后安装 | 登录启动、冲突拒绝、卸载边界，不改官方 Codex |
| A13 | 自主活动 | 12–24 秒随机动作、四种移动、菜单打开/鼠标接近/任务时不抢占、暂停开关持久化 |
| A14 | 松手弹跳 | 快/慢拖动、左右惯性、三次衰减、再次按住停止、屏幕四边及断屏、减少动态效果不位移 |
| A15 | 宠物管理与小分身 | 创建同包小分身、克隆初始停止、单只/全部显示隐藏、尺寸与位置互不影响、重启后清单保留 |
| A16 | 多实例资源与窗口 | 同一素材包不复制媒体、多个窗口共享只读素材、单只停止不影响其他实例、超出运行上限的错误反馈；重启按剩余名额恢复 |
| A17 | 启动/停止竞态 | helper socket尚未就绪时的逐只启停、克隆、隐藏意图排队；启动中停用不应稍后被自动恢复 |
| A18 | 多屏与 Space 下的多宠 | 每只位置保持在屏内、全屏让位一致、切换 Space 不丢失、管理菜单不重复创建 helper |
| A19 | 素材库与停止态切换 | 导入不启动；选择精确版本、停止实例后切换、重新启动载入；运行态切换拒绝；包括停止实例在内的引用阻止删除；错误保持原引用 |
| A20 | 长时运行资源 | 分别观察单只与3只的空闲、连续切换、隐藏/恢复、停止/重启；记录时长和 CPU/RSS/线程变化，不能把56MiB像素缓存称为总内存上限 |

冷启动验收需要用户主动选择时机，不能中断当前对话来自动完成。
主题场景依赖真实海报与兼容性确认，不得提前执行应用或重启。

MP1c 的自动覆盖范围已包括 A15/A16 的模型、IPC、持久化和合成 offscreen 窗口；A15/A16 的真实桌面部分以及 A17
仍待用户手工验收。自动测试通过不等于已经完成多屏、Space、焦点或长期 CPU/内存验收。

### 白龙全流程验收顺序

先完成白龙，再复刻其它角色。每一步都记录构建身份、实际结果与问题；未执行保留“待验收”。

1. **离线门禁**：固定上游/扩展来源与哈希、增强源码回归、真实适配器回归、冻结输入指纹、签名和 `--check`。使用当前构建，不沿用历史通过记录。
2. **用户选择安全时机后的独立预览**：A01-A03、A13-A14；检查已认可菜单/气泡、35动作与拖放手感。
3. **Codex 生命周期**：A04-A08、A10、A17；冷启动必须由用户主动操作，不能自动退出已有任务或重启 Codex。
4. **多屏与管理**：A09、A15-A16、A18-A19；真实导入/切换先用合成小包，不复制白龙媒体或冒充第二角色。
5. **资源与安装**：A20 分别记录单只/3只至少30分钟，再安排更长观察；安装/登录项/卸载 A12 另需用户明确确认，保留用户配置和数据。

海报/主题 A11 等素材及服务参数就绪后另行验收。只读任务状态仍是独立待办，不把额度或模拟任务当作接入完成。
上述顺序是验收计划，不是本轮已经执行的结果。每项按以下字段填入验证记录：

```text
日期、macOS/架构、显示器/缩放、宿主/helper版本及输入指纹：
验收编号、触发步骤、预期结果：
实际结果（通过/失败/未执行）、问题复现：
时长、CPU/RSS/线程记录（如适用）：
退出/恢复结果与仍未覆盖的边界：
```

## 4. 完整桌宠的离线播放自检

```bash
python3 scripts/prepare-full-pet.py check
python3 scripts/prepare-full-pet.py self-test
```

第二条运行上游固定版本的 `--self-test`，设置临时 HOME、独立 `BAILONG_DATA_DIR`、
`QT_QPA_PLATFORM=offscreen` 和不可用的 Codex 命令，并用系统沙盒禁止网络。
不启用 `--quota-only`（会访问额度接口），也不显示真实桌面窗口；`--chat-only` 是旧构建选项，当前已移除。
报告保存在被忽略的 `.local/reports/`。它能验证动作解码和模拟交互，不能替代真实桌面验收。

## 5. Monorepo 迁移后的额外回归

- 根目录构建、测试和控制命令保持有效，说明文档与实际入口一致。
- Swift 本地包依赖解析正确，资源从新位置被打包且没有泄露来源绝对路径。
- 配置与用户数据位置不因源码目录迁移而变化。
- 安装/卸载与隔离 Socket 测试继续通过；按变更影响补做人工矩阵。

## 6. 记录规范

记录日期、系统、架构、版本、执行命令、结果与未覆盖项；失败应写复现步骤和清理方式。
不得把上游维护者在别的系统上的测试当成本项目结果。
不保存账号、聊天正文、令牌、密钥或未经脱敏的输出。
完整动作由上游辅助应用提供；现有 Codex 实时任务跟随和首页主题仍保持待完成。
