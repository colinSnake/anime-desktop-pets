# 白龙桌宠本地增强层

这里仅保存针对固定上游源码的补丁、逐文件哈希与接入说明。
播放、文本布局、菜单和自主活动业务源码已迁到 `apps/pet-runtime/bailong/`（路径均相对仓库根目录）。
第三方源码、角色素材与编译结果只放在被忽略的 `.local/`；不修改原始下载目录或官方 Codex。

构建与验证流程见 `docs/桌宠增强与性能构建.md`（仓库根目录）。上游版权和素材授权声明保持原样。

`apps/pet-runtime/bailong/dragon_behavior.py` 负责低频动作决策、可中断轨迹和拖拽松手动量，复用播放器 tick；不读取 Codex 数据。

0.6.11 / `dragon.22`：拖拽释放需同时达到 24px 位移和 280px/s 合速度才触发弹跳/抛掷；普通轻拖停在放手位置。拖动姿态判断限制为每 50ms 一次，降低高频鼠标事件下的重复计算。

`dragon.23`：日常待机轮询显式合并全部互动差分、待机差分和素材存在的工作差分；完整轮转通过独立分类回归验证。

`dragon.24`：按用户要求将工作差分移出日常静默轮询；轮询完整覆盖全部互动与待机差分。工作差分的任务播放和手动菜单入口、移动分支及调度时间均不变。

0.5.0 / `dragon.4`：6 个走/跑/飞 ClipMotion 与素材运动段同步，保留现有卡片样式。构建脚本通过
`scripts/extra-animation-overlay.py` 校验并合并 10 个扩展动作，不修改原始素材或 App。

0.5.1 / `dragon.5`：新增 `apps/pet-runtime/bailong/dragon_playback.py`，松手使用方向飞行/快甩跑步，按运动前 200ms 进入；
约 160ms 当前姿态短混合，读取 WebP 非均匀帧时长，位移与已呈现时间同步，缺帧冻结且不积压。
不是生成补帧；界面样式不改，25 动作兼容清单保留旧弹跳路径。

0.6.2 / `dragon.8`（历史阶段）：按用户要求删除桌宠自有对话/历史 UI 与独立用量窗口；不清理既有用户文件。
右键「查看 Codex 额度」在菜单关闭后请求原有只读额度接口，结果显示在桌宠旁宽度不超过 284px 的 `dragon_ui.Bubble`。
信息层级参考本地 `codex-pet/bailong-desktop-pet`，不修改已认可菜单和气泡绘制，不开启自动刷新。
0.6.0/0.6.1 是历史构建记录，不代表当前 UI；隐私边界见 `docs/额度气泡说明.md`。
