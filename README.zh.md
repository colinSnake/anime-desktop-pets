
`dev:desktop` 默认启用 Vite 热更新，原 `dev:desktop:hmr` 入口仍是等价别名。保存 `apps/workspace-ui` 中的 React 或 CSS 文件，无需重启 Electron、桌宠或本地服务。兼容的 React 更新会保留状态；如退回工作区页面重载，未保存草稿可能清空。需要检查无热更新的静态界面时用 `dev:desktop:static`。主进程、preload、服务、Vite 配置和桌宠视频窗口的改动仍需重启。`dev:desktop --check` 仍是离线检查，不启动 Electron 或 Vite。生产构建按需加载聊天、模型管理及其余非首屏页面和样式。

先通过状态栏正常退出在用工作区，再执行新入口。可播放素材已就绪时，首次工作区打开即启动一只龙妹；已有工作区按保存的设置启动，未设置过的工作区会只为首只龙妹补一次默认值（该实例须启用）。可在「桌宠 → 设置 → 基本」关闭「随应用启动」。新分身默认关闭，最多同时运行三只。启动脚本只使用 `.local/pets/longmei/videos/` 中已核验的 `bailong-desktop-pet-v0.5.1-windows-x64-webm.zip`；不自动下载、不回退 Qt。缺素材可打开工作区但龙妹不可播放；导入的素材包仍只登记。Windows/Linux 可打开管理工作区，暂不支持播放。

`PET_PYTHON` 可为本地服务助手选择普通 Python。当前输出是 checkout 开发构建，不是安装包。播放器不需要 PySide6 或 Pillow。若 `PET_PYTHON` 仍指向旧项目虚拟环境，只能单独清理 Qt 包；保留 Python 和素材包导入所需的 Pillow。请保留原片归档、本机封面及语音环境。
