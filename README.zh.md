# Anime Desktop Pets

[English](README.md) | [简体中文](README.zh.md)

面向 macOS 的动漫风格桌宠项目。当前角色是 Codex 龙妹；Claude、DeepSeek、Grok 角色仍属规划，尚未接入。
桌边小崽应用与 Codex 并行运行，不修改官方应用包或 `app.asar`。本项目不是 OpenAI 产品，也不是官方插件。

应用界面称呼为 **「桌边小崽」**，配文 **「让喜欢的角色，陪在桌边。」**。项目展示名为 Anime Desktop Pets；
构建产物与 macOS 显示名统一为 **「桌边小崽.app」／「桌边小崽」**；Bundle ID、内部可执行名、配置标识和数据路径保持兼容。

## 当前状态

本项目是本地开发原型，提供 **35个角色动作**与多宠管理。已移除素材库窗口、菜单入口及其独立辅助应用；素材包工具仅保留为开发底座。
完整动画由独立 helper 提供，Swift 原生 PNG 后端仅为有限降级方案。增强版已接入本机 Codex 任务生命周期跟随与工作差分；真实桌面联动、
焦点、多屏和长期资源表现仍待人工验收。详见[路线图](docs/roadmap.md)与[实际验证记录](docs/实际验证记录.md)。
桌边小崽现由一个可调整大小的工作区承载：透明标题栏与工具栏共享主题底色，工具栏下方带细边界；下方采用左右分区，侧栏固定为200pt并按“梦境区”（桌宠、聊天、身份、记忆、能力）、“工作区”（模型管理、语音互动、直播管理）、“系统区”（高级）顺序排列。浅色模式下原生窗口底色、工具栏、添加弹窗和全部管理页面画布均明确为纯白，侧栏为浅灰；深色使用统一暗色画布，设置卡片、角色内容块和输入区以共享语义色区分层次。我的桌宠卡片采用柔和灰色封面区、与画布同色的操作区及细描边。整体以黑白灰为主，只在侧栏选中项使用紫色渐变。工具栏左侧先显示放大的 Logo，再显示“桌边小崽”，右侧主题图标略缩小；系统外观使用半圆条纹图标。右侧各页标题下不显示二级描述。桌宠控制页右上角显示服务连接状态，桌宠总开关与暂停联动使用左文案、最右侧小号黑色 Switch。实例管理在页面内展开紧凑卡片，名称和状态位于封面两角；原实例卡片提供启停与创建分身，分身卡片提供启停与删除实例，删除前须先停止并确认。最多同时运行3只（含原宠），实例登记上限为32只；添加桌宠以工作区附属 sheet 打开，按钮具备左右内边距并适配浅/深色文字和表面。模型页提供当前已实现的服务商、Base URL、模型名与 API Key 配置，圆角输入控件有明确高度；已保存 Key 仅在实际请求时读取，页面打开不触发认证输入。语音互动和直播管理使用独立页面。直播管理展示接入状态与本地房间配置，并明确平台连接、弹幕接收和互动发送尚未实现，保存配置不会连接直播间。目标页签已移除，现有本地目标资料与聊天引用保留。主题图标循环切换跟随系统、深色和浅色主题。分身可从已有启用桌宠实例创建并继承来源配置，实例仍可独立启停。正常使用 `--launch` 或 `--watch` 启动时默认不弹出管理窗口，避免遮挡启动动画和 Codex；菜单栏左键打开工作区，右键菜单仅保留“退出”。`--preview-character-window` 使用 `/tmp` 下独立构建和临时数据离线预览，并提供不读取或导入真实素材的合成小宠列表；模型网络/钥匙串、麦克风和桌宠启停操作均禁用。已检查页面导航、主题、搜索多选、加载禁用状态和弹窗 X 关闭；真实素材导入、sheet 外点击、Finder/文件面板及安装版交互仍需验收。详见[管理工作区界面](docs/管理工作区界面.md)及[验证记录](docs/实际验证记录.md)。角色资料仍按实例保存为本地 Markdown；龙妹新资料预填完整人格设定并默认关闭在线分享，已有身份不会被覆盖。退出清理已加入超时保护和宿主 PID 所有权保护。

添加桌宠弹窗的主操作简化为“添加”；移除“全选”按钮，“选择素材目录”“刷新”“查看目录”和“添加”统一为固定26pt纯文字按钮，搜索框同为26pt，使用12pt字体与固定自然行高居中，保证占位文字、输入文字和光标在焦点切换时对齐；普通按钮与搜索框使用适配浅/深色的1pt清晰描边，桌宠页“添加桌宠”同步复用此样式。移除按钮左侧图标、候选名称左侧图标及标题说明副标题。候选使用固定160pt宽的自适应封面卡片网格，版本号/内置标识与动作数分别位于封面左上、右上角，名称在封面下方居中，点击封面选择；扫描后后台串行抽取默认动画首帧或读取现成封面，目录和 `.petpack` 均支持，卡片内仅保留底部“查看目录”。封面加载/失败不阻塞选择和添加，搜索、多选、导入和目录操作行为不变。 卡片内容先裁切，再固定向内预留2pt描边空间，封面、角标和按钮不占用边框区域；选中描边为2pt、未选中为1pt，网格四周另留2pt滚动间距。原生隐藏窗口回归检查浅深色、三种窗口宽度、单卡/多卡及滚动后的四边连续性。

工作区主窗口外壳、桌宠页、添加桌宠 sheet、模型、语音/直播、高级设置及角色聊天/身份/记忆/能力均由 SwiftUI 呈现。AppKit 只保留应用/状态栏与原生窗口所有权、现有控制器 hosting bridge、系统文件面板、Finder、麦克风/辅助功能及独立启动动画/桌宠运行时窗口；领域状态和副作用仍由对应控制器与 Coordinator 管理。自动化测试和离线构建通过，但真实窗口浅深主题、弹窗关闭/导入、焦点与 Finder/文件面板行为尚未实机验收。边界见[管理工作区界面](docs/管理工作区界面.md)，验证记录见[实际验证记录](docs/实际验证记录.md)。


本机聊天与资料管理可通过 `./scripts/preview-character.sh` 隔离验收，按[龙妹聊天与记忆验收](docs/龙妹聊天与记忆验收.md)检查；在线人格、语音端到端和正式安装包仍待验收。
开机动画已在本机超分至 4K；原片备份与处理报告保存在私有目录。超分工具实测峰值驻留内存约 915 MB；流程和边界见[4K 超分说明](docs/开机动画4K超分.md)。目前没有独立超分 macOS 应用。

## 环境要求

- Apple Silicon Mac，macOS 13 或更新版本；目前以本机 arm64 构建为验证对象。
- Xcode Command Line Tools（Swift 5.9 或更新版本）及用于构建/测试脚本的 Python 3。
- 如需 Codex 联动，需安装 Codex 桌面应用。
- 全新检出需自行准备有权使用的本地媒体和桌宠素材；这些私有资源不随 Git 仓库分发。

## 构建与检查

在仓库根目录执行。先按[本地开发指南](docs/本地开发与使用指南.md)导入媒体，
再按[桌宠构建说明](docs/桌宠增强与性能构建.md)准备固定上游应用、专用 Python 环境和本地动作素材。

```bash
python3 scripts/prepare-full-pet.py fetch
python3 scripts/build-pet-runtime.py build --source-revision 8e5466d9a438deb6cb43f460e7f5a9bdb9d7a578 --local-test-font .local/pet-build/local-fonts/上首软糖体.ttf
./scripts/build.sh
./scripts/test.sh
./scripts/petctl.sh --check
```

本机增强版构建会强制校验 helper 中的 SSRuanTangTi 字体及 SHA-256；字体是本机测试授权素材，不能提交或分发。缺少字体时构建会在发布前停止，不会覆盖现有可用 App。

默认 helper 引用本机动作素材，不是可移植发行包。构建与测试命令不会启动桌宠或重启 Codex；`--check` 只检查配置和资源，
不等于真实桌面验收。

宿主应用会显示在 Dock 中，菜单栏使用专用透明窗口伴星线性标记，不会把方形 App 图标缩成状态栏图案。

需要主动预览完整桌宠时运行 `./scripts/preview-full-pet.sh`。该入口切换模式前可能退出现有桌宠实例；需要保留正在运行的实例时不要运行。
Codex 启动/观察模式和本地配置见[本地使用指南](docs/本地开发与使用指南.md)。

## 功能与边界

- 4K 视频与 Codex 同时启动：取得辅助功能授权后，新客户端窗口按视频16:9尺寸同步；如果 AX 窗口晚于首个稳定画面出现，宿主会重试并在动画结束时做最终校准。未授权时视频铺满实际窗口（裁边、不留黑边），但不会因此调整 Codex 自身窗口。非激活覆盖层保持99.9%不透明，并传入针对遮挡降速的Chromium开关。正常启动时视频播完立即交给 Codex 自身 loading 继续显示；官方客户端没有内容就绪接口，因此不把窗口可见误认为页面加载完成。已有进程不改尺寸、不补播。

- “实例管理 → 桌宠管理…”内置本地桌宠选择窗口，自动扫描项目的 `resources/pets`、`pets`、`.local/pets` 和已导入目录，也可选择其它目录或 `.petpack`，支持 ⌘/⇧ 多选；添加后保持停止，在实例管理中自行启动。无需独立宠物素材库应用。
- 角色统一显示“龙妹”，实例状态仅显示“运行中”等当前阶段，不再附加下次恢复提示；原有内部 ID 与自动恢复偏好保持兼容。
- 提供完整动画龙妹桌宠与多实例管理；工作区的实例管理在桌宠页内展开 Apple 风格实例卡片，显示状态、错误、启停、创建分身与删除分身操作，优先使用内置待机动画生成的透明首帧封面；原宠计入同时运行上限，默认最多3只；菜单职责与能力边界见[菜单说明](docs/菜单功能与交互边界.md)。
- 状态栏“互动气泡语音：已开启/已关闭”控制可见气泡的本地朗读。菜单或弹窗打开时暂存最新一条气泡，交互结束后再朗读；连续气泡只保留最后一条。余额卡片显示不变，语音摘要改为简洁中文并本地化常见币种。TTS cue 送出后，气泡会按文本长度估算朗读时长，在 3–30 秒范围内显示，不再使用单一固定时长；当前单向 cue 通道还没有精确的“播放完成”回调。主动生成的语音回复仍是独立行为，不受此开关控制；切换只保存本机偏好，不自动联网。
- 已开启互动气泡语音并配置有效本机模型/参考音频时，启动会预加载 TTS；`--preview-pet`、`--launch` 和 `--watch` 首次显示桌宠前等待模型 ready，最多等待12秒，加载失败或超时仍显示，目标应用的观察/启动保持并行。气泡模式不加载或导入 ASR、不提前合成或发声；首条 cue 复用模型，超时后点击也会等 ready 再提交。关闭朗读会在当前 cue 完成后释放模型，加载中则停止子进程；朗读期间的开关变化在 cue 结束后重新核对，快速关闭再开启不会打断当前朗读或丢失预热进程；主动语音聊天会先释放/停止气泡进程并串行交接。退出回调未完成前的连续保存会合并为一次替换预热，cue 完成后清理捕获对象的回调。首段合成与设备初始化仍有耗时，真实首音延迟和 RSS 收益待测量。
- 桌宠互动发出的单向语音提示可能在宿主回写确认前关闭本机控制连接；宿主现已在确认写入时抑制该 socket 的 `SIGPIPE`，避免客户端断开导致桌边小崽退出。隔离控制回归覆盖了此断连场景。
- `apps/live-runtime/` 是独立的直播消息基础模块，目前提供离线 JSONL 标准化、去重、限流、有界队列、可选的 `--announce` 本地朗读交接和平台无关的重连状态机，并可在 `status`/`ping` 中轮询来源状态；尚未连接 B 站或抖音，不读取凭证、不打开音频设备、不向直播间发言，也不依赖桌宠 helper 或语音运行时。
- 当前本机测试构建的桌宠普通消息气泡使用 SSRuanTangTi（上首软糖体）并水平、垂直居中；任务结果顶部标题始终左对齐，即使末行只有一个字也不会居中。额度与任务数据保持清晰易读，额度卡片使用自绘刷新按钮，长服务名不会与剩余额度重叠。该字体仅用于获准的本机测试构建，不得分发。
- 龙妹可见且处于待机时，会偶尔在头顶显示一条简短问候；工作、拖拽、菜单和鼠标靠近时会推迟。刚发生用户交互后会延长自主动作间隔、优先安静待机，并至少等待一段时间再问候；平静时按洗牌队列轮换互动和待机动作，遵循“自主活动”和减少动态效果设置。
- 用户数据保存在 `~/Library/Application Support/AnimeDesktopPets/`，与内置龙妹动画素材目录分离，但会存放用户导入的桌宠包及其中素材。新版首次运行会迁移旧 `DragonCodexCompanion` 目录并留下兼容符号链接；若新旧目录同时存在则不会自动合并。
- 完整35动作派生评估不改变正式素材：实际Qt预乘像素复核否决预缩小WebP替换；256/512px预乘帧压缩能精确还原，但两档全量载荷约1.87GiB，仍仅评估按需缓存，不承诺桌面CPU/RSS改善。只读工具与范围见[性能构建说明](docs/桌宠增强与性能构建.md)及[验证记录](docs/实际验证记录.md)。
- 增强版龙妹可从宿主状态栏直接创建首个同包分身，无需预建实例清单。确认后会把由本宿主启动的单宠交接给一个多宠 helper；新分身先停止且默认不随启动自动恢复，明确启动后才加入自动恢复。实例菜单显示已确认状态，并可删除已停止分身；删除不会清理素材或独立状态目录。helper 状态轮询无变化时不重复刷新菜单或写诊断日志。分身与原宠共享只读动画素材，但位置、尺寸和活动偏好独立。原宠计入在内，最多同时运行3只。
- macOS 宿主负责启动呈现与生命周期协调；独立 Python/PySide6 helper 负责动画和交互。
- 右键打开菜单时松手弹簧继续运行；再次左键拖拽会中断并重置旧轨迹。
- 松手甩动的跑步/飞行动画随弹簧物理持续到停稳，之后单独保留2秒再回待机；这段时间与20–34秒自主动作调度间隔互不影响。任务开始、暂停自主活动与减少动态效果仍可及时让位。
- 明确拖拽甩动属于用户直接操作，即使任务跟随处于工作态也继续推进；任务态仍禁止后台自主位移。
- 额度仅在用户主动请求时刷新：官方 Codex 账户支持读取 5 小时/每周订阅用量窗口；TiMi CC 复用 CC Switch 已启用且匹配当前服务的用量配置，显示中转 `USD` 余额，来源与查询时间在卡片底栏左右排列。见[额度说明](docs/额度气泡说明.md)。
- 任务跟随有界读取本机 rollout，在内存中只提取生命周期字段，不展示或保存正文；每个新任务轮次播放一次开场，之后持续轮换工作差分并显示对应简短文案气泡；不读取真实任务标题，也未绑定前台会话。见[任务跟随说明](docs/Codex任务跟随.md)。
- 不保存完整语音对话历史；角色身份和经用户确认的记忆单独保存在本机，默认不发送给在线模型。额度仍仅在显式请求时刷新。
- 语音聊天由本地 Qwen3-ASR 识别，并通过用户配置的 OpenAI-compatible 在线模型生成回复。管理窗口中的“模型管理”支持 OpenAI、DeepSeek 和自定义中转 Base URL/模型名；API Key 保存于 macOS 钥匙串，识别文本会发送给所选服务商。官方 Codex 订阅登录不等于 API Key；可通过兼容 chat-completions 的中转调用 Codex/Grok 等模型。配置的服务端支持工具调用时，天气查询使用 Open-Meteo。模型费用由服务商或中转站收取，连通性测试也可能产生少量费用。本地参考音色 TTS 仍可选用；TTS 输出流在连续朗读间保持常驻，减少重复初始化造成的首句延迟和卡顿。语音运行时和模型权重仅用于 checkout 演示，尚未打入安装包。见[直播语音桌宠方案](docs/直播语音桌宠方案.md)。
- 角色与记忆窗口已接入本轮临时文字聊天：用户掌控人格，记忆和目标按桌宠保存在本机；单条消息最多1,200字，超限会提示而不静默截断，当前窗口 transcript 最多12条、累计6,000字；在线回复失败可重试且不会重复追加用户消息。聊天先走本机身份/能力/记忆回答，再按需调用在线模型；本机回答不会先检查服务商配置或 macOS 钥匙串，只有需要在线模型的问题才读取凭证并生成请求。线上只带逐条授权且通过凭证/冲突门禁的相关记忆，安全候选会先过滤再取前N条，避免无权限资料占用上下文；凭证门禁覆盖记忆正文及来源、引用、版本，并在存储层拒绝写入；手动新增命中时即时显示原因并保留输入供修改；人格资料命中时仍可本机保存，但整份身份上下文不外发。角色知识单独标识，并支持按来源、引用/定位和版本/日期召回。本机回顾也支持知识依据定位，并隐藏含凭证关键词的历史记录及未解决冲突知识。在线上下文会把依据当作参考而非指令，旧格式资料仍可读取。聊天上下文不自动写入长期记忆；文字和语音中的“记住……”共用低风险自动保存、去重、冲突/敏感审核和凭证拒绝规则。凭证判断仍是有限关键词规则，不是完整扫描器。这不代表通用后台 Agent 或自动执行目标已实现。详见[数字个体与本地记忆方案](docs/数字个体与本地记忆方案.md)。
- 旧龙妹身份的空白字段可预览默认设定、补入表单后显式保存，保留已有名称、文字和分享设置。聊天可本机回答“我们现在推进到哪一步了”，相关目标须逐项授权才进入文字/语音在线上下文，聊天不执行或修改计划。记忆页支持粘贴或选择 UTF-8 `.txt`/`.md` 知识，单次32KiB、50段、每段1,000字，先预览再导入待审核，重复跳过且默认本地。知识可设有效期，过期不参与本机/在线回答；正文、依据或有效期改动会重新审核并关闭分享。操作步骤见[龙妹聊天与记忆验收](docs/龙妹聊天与记忆验收.md)；真实 UI、在线人格与语音听感仍需分别验收。
- 语音复查补齐音频线程失败/卡住、排空/关闭超时、stdin 断开、cue 超时后的子进程回收与下一条恢复、语音轮次上限和麦克风授权取消；语音共用文字聊天的角色规则，朗读与气泡使用同一份有界短文本，IPC 与 MLX PCM 转换移出界面/协议循环。关闭语音设置会取消待授权录音或当前语音/演示轮次。完整证据和真实设备、延迟、内存、打断及语音历史待办见[语音聊天闭环审查](docs/语音聊天闭环审查.md)。


- 海报生成及自动应用主题尚未启用。

## 验证

`./scripts/test.sh` 运行项目测试；专用环境已准备时，可用 `./scripts/test-multi-pet.sh` 运行多宠与 IPC 独立测试。
有测试套件跳过时不能报告为完整通过。自动化和离屏测试不等于真实桌面验收；范围与未完成项见[验证记录](docs/实际验证记录.md)。

专用 PySide6 环境可通过 `scripts/preview-pet-ui.py` 生成禁网离屏 UI 截图，命令见[本地指南](docs/本地开发与使用指南.md)。
离屏预览统一使用 Fusion，并覆盖继承的 Qt 样式设置，不代表 macOS 原生样式，也不改变真实桌面的外观。
项目测试包含预览、刷新按钮与反复启停生命周期回归；气泡使用应用级屏幕查询，避开本机复现的 PySide6 6.9.2 返回值父级关联问题；停止适配器时显式销毁独立气泡。
