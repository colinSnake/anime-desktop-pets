统一栈为 **Electron + React/TypeScript/CSS + Node.js/Fastify + Python**。服务最多管理三个自有桌宠，仅在拖拽真正松手时提交位置；运行、显示和行为确认不写配置修订。暂停联动先关门禁、回收自有窗口和任务、语音；解除暂停不会自动重开桌宠。「高级」只保留 Python 协议诊断，不再另启播放器。

工作区锁定 Electron `45.4.1`。其内置 Node 在 macOS 上仍过不了 DSH `0.2.2-rc.5` 的原生加载器检查，因此 Harness 使用独立 Node，不回退到模型直连。打包态只选取包内的 `Contents/Helpers/pet-harness-node`，不接受开发环境覆盖。构建后可运行 `node scripts/probe-pet-agent-relocated.mjs` 复跑搬移后的合成回合；macOS arm64 已有锁定版本 Electron 二进制时，可运行 `node scripts/probe-pet-agent-packaged.mjs` 验证一次性 ad-hoc 签名包。两个探针都不启动 Electron、不替换在用应用、不生成安装包。arm64 上可加 `--omit-web-source-maps` 对照跳过少量已核对的调试映射后的体积。开发环境为 Node.js 24.x（Harness 需要 24.9+）、pnpm 10.32.0、Python 3.10+；额度查询使用 Python 3.11+。在仓库根目录执行：

```bash
pnpm install --frozen-lockfile
pnpm run check:cross-platform
pnpm run dev:desktop --check   # macOS：离线核验本机原片及视频界面，不开窗口
pnpm run dev:desktop           # 构建并打开静态工作区
pnpm run dev:desktop:hmr       # 或：打开支持 React/CSS 热更新的工作区
```

日常改 UI 时，切换到 `dev:desktop:hmr` 一次即可。之后保存 `apps/workspace-ui` 中的 React 或 CSS 文件，无需重启 Electron、桌宠或本地服务。兼容的 React 更新会保留状态；如退回工作区页面重载，未保存草稿可能清空。主进程、preload、服务和桌宠视频窗口的改动仍需重启。生产构建按需加载聊天、模型管理及其余非首屏页面和样式。

先通过状态栏正常退出在用工作区，再执行新入口。可播放素材已就绪时，首次工作区打开即启动一只龙妹；已有工作区按保存的设置启动，未设置过的工作区会只为首只龙妹补一次默认值（该实例须启用）。可在「桌宠 → 设置 → 基本」关闭「随应用启动」。新分身默认关闭，最多同时运行三只。启动脚本只使用 `.local/pets/longmei/videos/` 中已核验的 `bailong-desktop-pet-v0.5.1-windows-x64-webm.zip`；不自动下载、不回退 Qt。缺素材可打开工作区但龙妹不可播放；导入的素材包仍只登记。Windows/Linux 可打开管理工作区，暂不支持播放。

`PET_PYTHON` 可为本地服务助手选择普通 Python。当前输出是 checkout 开发构建，不是安装包。播放器不需要 PySide6 或 Pillow。若 `PET_PYTHON` 仍指向旧项目虚拟环境，只能单独清理 Qt 包；保留 Python 和素材包导入所需的 Pillow。请保留原片归档、本机封面及语音环境。
